Auto-Tag-Regeln

Regeln in einfachen Worten.
Beantwortet auf deinem Computer.

Beschreibe, was eine Regel erkennen soll, füge genaue Bedingungen hinzu, und MailVault taggt passende Mail beim Eintreffen. Regeln werden auf deinem Computer beantwortet, außer du weist eine auf deinen eigenen Anbieter hin.

MailVault herunterladenLive-Demo ausprobieren ↗

So funktioniert es

  • Einfache WorteSag, was erkannt werden soll, so wie du es einer Person sagen würdest.
  • Erst VorschauSieh, was eine Regel in deiner vorhandenen Mail treffen würde, bevor du sie einschaltest.
  • Rückgängig machbarer VerlaufsdurchlaufWende eine Regel in einem Durchlauf auf vergangene Mail an, und mach es bei Bedarf rückgängig.

Kostenlos. Teil der kostenlosen App, ohne Testzeit-Uhr und ohne Konto.
