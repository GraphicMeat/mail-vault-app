MailVault für Windows

Dein Download startet.

Das Installationsprogramm ist unterwegs. Öffne es danach aus deinem Downloads-Ordner. Windows fragt vielleicht vorher nach; hier steht, warum, und wie du prüfst, dass die Datei von uns ist.

Für Windows herunterladen

Falls der Download nicht startet, nutze die Schaltfläche oben.

Warum Windows eine Warnung zeigen kann

Jedes heruntergeladene Installationsprogramm prüft Microsoft Defender SmartScreen. Es achtet auf zwei Dinge: wer die Datei signiert hat und wie viele Menschen sie schon heruntergeladen und ausgeführt haben.

Das Installationsprogramm von MailVault ist über Microsofts eigenen Dienst Azure Artifact Signing signiert. Microsoft prüft die Identität der Firma, bevor sie überhaupt etwas signieren darf, und Windows bestätigt vor dem Start, dass die Signatur unverändert ist.

Die Reputation braucht Zeit. MailVault für Windows ist neu, und jedes Release ist eine neue Datei. SmartScreen kennt sie daher vielleicht noch nicht und zeigt „Der Computer wurde durch Windows geschützt“. Das heißt nur, dass die Datei noch nicht weit verbreitet ist. Es heißt nicht, dass etwas Schädliches gefunden wurde.

  1. Wenn dein Browser nachfragt

    Edge meldet eventuell, dass die Datei „nicht häufig heruntergeladen“ wird. Öffne die Downloads, wähle die drei Punkte neben der Datei und dann Beibehalten.

  2. Wenn SmartScreen erscheint

    Klicke auf Weitere Informationen. Prüfe, dass als Herausgeber MODERNIOS APLIKACIJOS steht, die Firma hinter MailVault, und klicke dann auf Trotzdem ausführen.

  3. Wenn ein anderer Herausgeber steht

    Führe die Datei nicht aus, wenn dort Unbekannter Herausgeber oder ein anderer Name steht. Lösche sie und lade sie erneut von dieser Seite herunter.

Prüf es selbst

Du musst uns nicht einfach glauben. Klicke mit der rechten Maustaste auf das Installationsprogramm, wähle Eigenschaften und öffne den Tab Digitale Signaturen: Dort steht MODERNIOS APLIKACIJOS, und unter Details ist die Signatur gültig.

Jedes Release auf GitHub listet neben jeder Datei auch eine SHA-256-Prüfsumme. Führe in PowerShell Get-FileHash für das Installationsprogramm aus und vergleiche beide Werte.
