How to Back Up Gmail to EML Files

On this page
  • Save one Gmail message without installing anything
  • Back up a whole Gmail mailbox as individual EML files
  • Verify the archive before relying on it
  • Short demo: make a separate backup of your vault
  • Gmail EML backup vs Google Takeout

To back up Gmail to .eml, use Download message for an individual email, or archive your mailbox with a desktop app that stores each message as EML. Google Takeout is another useful backup route, but its mail export uses MBOX rather than individual EML files. Choose the format you need before starting.

Save one Gmail message without installing anything

  1. Open Gmail in a desktop browser and open the message you want.
  2. Use the message’s three-dot More menu, then Download message.
  3. Keep the downloaded .eml file and open it in a desktop mail app to check its contents. Repeat for other messages you need.

These steps follow Google’s message download instructions. This is a convenient option for a receipt or a few important messages; repeating it across an entire mailbox is slow.

Back up a whole Gmail mailbox as individual EML files

  1. Install MailVault and add your Google account using Google sign-in. Review the requested access. If this is a work or school account, your administrator may restrict third-party access.
  2. Choose the folders or labels you need. Include sent mail and older folders, not just Inbox. Check Gmail’s IMAP visibility settings if a label is missing.
  3. Open the bulk operations workflow, select your date range, and choose Archive. This saves mail locally without deleting the server copies. Start with a small range so you can check the result.
  4. Wait for the archive operation to finish before closing the computer or starting a cleanup. Large accounts may take multiple sessions because of provider download limits.
  5. Open MailVault’s mail storage settings to locate your vault. Archived messages are stored as .eml files in a Maildir structure; do not rename or move files inside the active vault. These file-layout instructions use the default Maildir format. Settings → Storage also offers JMAP storage, which keeps original message bytes with JSON records and deduplicates identical messages.

Verify the archive before relying on it

  1. Switch the message source to Vault, rather than Server or All. Search for an old message you recognize.
  2. Disconnect from the network and open a few archived messages from different folders and years. Open their attachments too. A subject line in a list is not proof that the message body is saved.
  3. In Settings, open Backup & Restore and use Export Backup. Choose a location on a second drive. The ZIP contains the vault, accounts and settings; it excludes messages that only exist on the server.
  4. Check that the ZIP opens, contains .eml files, and includes the folders you intended to preserve. For important mail, test restoring a copy in a separate installation before deleting anything.

Gmail EML backup vs Google Takeout

Use EML when you want individual message files and a searchable working archive. Use Google Takeout when you want an account export that Google prepares. Takeout mail is MBOX; downloading a ZIP from Takeout does not turn it into EML. MailVault also supports MBOX import in Backup & Restore if you already have an export.

Neither downloading messages nor moving them to Gmail’s Archive frees storage. To reclaim space, read how to free up Gmail storage without losing emails after verifying both local copies. For the broader format comparison, see download all Gmail emails.
