ダウンロードを開始しています。

MailVault はダウンロード フォルダーへ向かっています。以下の手順でインストールして開きます。

MailVaultをダウンロード

ダウンロードが始まらない場合は、上のボタンを使ってください。

macOS

Mac にインストール

Apple Silicon と Intel 用のダウンロードは一つです。macOS 11 以降。このアプリは Apple によって署名され、公証されています。

  1. .dmg を開く

    ダウンロード フォルダーから MailVault の .dmg ファイルを開きます。

  2. アプリケーションへドラッグ

    開いたウィンドウで MailVault を「アプリケーション」フォルダへドラッグします。

  3. MailVault を開く

    「アプリケーション」または Launchpad から開きます。macOS はインターネットからダウンロードしたアプリを開くかどうか一度だけ確認します。「開く」をクリックしてください。

Windows

Windows にインストール

64 ビットの Windows 10 または 11。ダウンロード フォルダーからインストーラーを実行し、スタート メニューから MailVault を開きます。

Windows版 MailVault は新しいため、SmartScreen がまだ認識していないことがあります。Windows が警告を表示する理由と、ファイルを確認する方法。

  1. ブラウザーに確認された場合

    Edge では、ファイルが「一般的にダウンロードされていません」と表示されることがあります。ダウンロード メニューを開き、ファイルの横の 3 つの点から「保存」を選んでください。

  2. SmartScreen が表示された場合

    「詳細情報」をクリックします。発行元が MailVault の開発元である MODERNIOS APLIKACIJOS になっていることを確認し、「実行」をクリックします。

  3. 発行元が違う場合

    「不明な発行元」やほかの名前が表示された場合は、ファイルを実行しないでください。削除して、このページからもう一度ダウンロードしてください。

Linux

Linux にインストール

Ubuntu 22.04 以降、または Debian 12 以降。Intel、AMD、ARM に対応しています。自動更新がよければ Snap Store から入手 ↗

  1. ダウンロード フォルダーでターミナルを開く

    または .deb ファイルをダブルクリックして、パッケージインストーラーで開きます。

  2. パッケージをインストール

    sudo apt install ./MailVault_*.deb を実行します。./ は、apt にローカルのファイルを使うよう伝えます。

  3. MailVault を開く

    アプリケーションメニューから MailVault を探します。

インストールできたら MailVault を開きましょう。

メールアカウントを接続して、最初のアーカイブを作成します。
