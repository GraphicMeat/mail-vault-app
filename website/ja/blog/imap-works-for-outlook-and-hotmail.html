Outlook.com と Hotmail で IMAP が再び使えるようになり、既定の接続方法になりました

3分で読めます

Microsoft のサインインを使った IMAP が、個人の Outlook.com、Hotmail、Live.com アカウントで動作するようになったため、MailVault は既定でこれを使います。Outlook.com や Hotmail のアカウントを追加すると、Microsoft 365 の職場・学校アカウントやほかのすべてのプロバイダーと同じように、IMAP で接続されます。

そもそもなぜ Graph に移ったのか

今年の初め、個人の Outlook アカウントに IMAP でサインインできなくなったため、私たちは Microsoft の Graph API を使う 2 つ目の接続方法を作りました。経緯はOutlook OAuth の長い旅に書いています。Graph のおかげでそれらのアカウントは使い続けられましたが、IMAP とは別の経路であるため、IMAP に頼る機能の一部は引き継がれませんでした。

IMAP で使えるもの

  • スヌーズ。Graph アカウントでは使えません。
  • MBOX ファイルをサーバーに復元すること.
  • 削除したメールのサーバーに復元。お使いのコンピューターへの復元だけではありません。
  • 接続テストのあと、アカウント追加ウィンドウに表示される受信トレイの件数。
  • 接続方法が 1 つに。Outlook.com アカウントも、ほかの IMAP アカウントと同じように動作します。

何が変わるか

  • 新しいアカウントは IMAP で接続します。アカウント追加ウィンドウの接続方法は IMAP になっており、Microsoft Graph もひとつ選ぶだけで使えます。
  • すでに Graph を使っているアカウントはそのまま動作し、変更されません。MailVault の起動時に、Graph のままのアカウントごとにバナーが表示され、IMAP に切り替えると今後は表示しないを選べます。後者を選ぶと、そのアカウントのバナーはずっと表示されなくなります。
  • 切り替えは設定 → アカウント → 接続で行います。接続方法を IMAP にして、切り替えて再サインインを選んでください。保存済みのメールはそのまま残ります。

確認が必要な設定がひとつあります

Outlook.com は、設定でデバイスとアプリで IMAP を使用できるようにするをオンにしないと、IMAP でメールボックスを提供しません。オフのままだと、Microsoft はサインインを受け付けたあと、「User is authenticated but not connected」と答えて接続を拒否します。直すのは 1 分で済みます。手順はOutlook.com や Hotmail のアカウントを IMAP で追加するには？を、すでにエラーが出ている場合はOutlook が IMAP を拒否したと MailVault に表示されますをご覧ください。

Graph がなくなるわけではありません。Graph のほうがよい場合や、Outlook.com 側で何もオンにしたくない場合は、接続方法で Microsoft Graph を選んでください。
