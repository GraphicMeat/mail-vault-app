MailVault と MailStore Home を並べて比較

6分で読めます

MailStore Home の代わりを探しているなら、このページでは 1 人のメールを対象に、2 つの無料のツールを直接比較します。MailStore Home は、Outlook、Thunderbird、Gmail、Outlook.com、IMAP のアカウント、PST ファイルからメールをコピーし、検索できる 1 つのアーカイブにまとめる Windows のプログラムです。MailVault は、メールのコピーをプレーンな .eml ファイルとしてコンピュータに保管する、macOS・Windows・Linux 向けの無料のメールアプリです。会社全体のアーカイブが必要なら、代わりに MailStore Server の代わりを読んでください。より幅広いツールの一覧は MailStore の代わりの比較を参照してください。

手短な答え

Windows で、PST ファイルや複数のローカルのメールプログラムから取り込むなら、MailStore Home のほうが合っています。Mac や Linux なら、あるいは普段メールを読んで返信するアプリの中に、アーカイブをプレーンな .eml ファイルとして持ちたいなら、MailVault のほうが合っています。

MailStore Home が勝る点

  • 取り込み元が多い、特に Windows で。Outlook のプロファイル、PST ファイル、Exchange Server のメールボックス、Windows メール、Thunderbird のプロファイルを読めます。MailVault は PST ファイルをまったく読めません。
  • 添付ファイルの検索が無料。MailStore Home は添付ファイルを無料でインデックス化します。MailVault では、PDF や Office の添付ファイル内の検索は Premium です。
  • 無料の削除ルール。アーカイブのプロファイルで、アーカイブした時点で、待機期間の後に、または経過期間によって、メールボックスからメールを削除でき、削除するのはアーカイブにあると確認できたメールだけです。フラグ付きのメッセージは、それも削除するオプションをオンにしない限り残ります。MailVault では、自動整理ルールとワンステップのアーカイブして削除は Premium です。
  • ポータブル版が無料。インストールせずに USB ドライブから動かせます。MailVault のポータブルモードは Windows 専用で Premium です。
  • メールを戻す方法が多い。アーカイブしたメールを Exchange、IMAP のメールボックス、Gmail に書き出せるので、移行ツールとしても使えます。
  • 長い実績。MailStore の製品は 2006 年から提供されており、Home は 2026 年にも更新されています。

MailVault が勝る点

  • Mac と Linux で動く。MailStore Home が挙げているのは Windows 10 と 11 だけです。MailVault は macOS 11 以降（Apple Silicon と Intel）、Windows、Linux で動作します。Mac の場合については Mac 向けの MailStore の代わりのガイドで説明しています。
  • アーカイブがプレーンなファイル。各メッセージは Maildir 形式のフォルダにある標準的な .eml ファイルで、MailVault がなくても Apple Mail、Thunderbird、テキストエディタで開けます。MailStore Home はメールを独自のアーカイブファイルに保管し、標準的なファイルを取り出すには書き出しが必要です。
  • メールを読むのも残すのも 1 つのアプリで。MailVault は本格的なメールクライアントです。読み、検索し、返信し、送信して、残したいものをアーカイブします。各行には、メッセージがサーバーにあるのか、保管庫にあるのか、その両方なのかが表示されます。
  • Microsoft 365 が取り込み元として明記されている。Microsoft 365 のアカウントは OAuth2 でサインインし、個人の Outlook.com、Hotmail、Live.com のアカウントは Microsoft Graph 経由で接続します。MailStore Home の製品ページには Outlook.com と Exchange Server 2003〜2019 が載っていますが、Microsoft 365 は載っていません。
  • ソースコードは GitHub で公開。 コードは GitHub にあるので、メールに対して何をしているかを確かめられます。

アーカイブの置き場所

MailStore Home では、アーカイブはデータフォルダにあり、組み込みのバックアップを使うか、プログラムを閉じた状態でフォルダをコピーしてバックアップします。MailStore は、Dropbox などの同期サービスにそのフォルダを置かないよう警告しています。MailStore Home がファイルを使っている間に、サービスがファイルに触れることがあるためです。

MailVault では、アーカイブは .eml ファイルのフォルダです。設定のバックアップと復元で、その場所が表示され、ファイルマネージャーで開くことも、別のドライブに移すこともできます。外付けドライブや NAS の共有フォルダに 2 つ目のコピーを加えることもでき、バックアップを実行するたびに書き出されます。

MailStore Home から MailVault への移行

MailVault は MailStore のアーカイブファイルを直接開けません。いちばん簡単なのは、MailVault を同じアカウントに接続し、まだサーバーにあるものをアーカイブする方法です。今は MailStore Home にしかないメールは、MailStore Home から IMAP や Gmail のメールボックスに書き出し、MailVault でアーカイブしてから、もう一度サーバーから削除します。書き出しによってそのメールがしばらくサーバーに戻るので、先にメールボックスの容量を確認してください。

どちらを選ぶべきか

  • Windows を使っていて、取り込む PST ファイルや Outlook と Thunderbird のプロファイルがあり、無料の添付ファイル検索と無料の削除ルールが欲しく、アーカイブ専用のツールで構わないなら、MailStore Home を選んでください。
  • Mac や Linux を使っていて、どこでも開けるプレーンなファイルとしてアーカイブを持ちたく、Gmail、Microsoft 365、Outlook.com、IMAP を使い、メールを読み、検索し、残すのを 1 つのアプリで済ませたいなら、MailVault を選んでください。
  • 会社に保持ポリシー、訴訟ホールド、監査ログが必要なら、どちらも選ばないでください。それはサーバーの領分です。

よくある質問

Mac 版の MailStore Home はありますか？

いいえ。MailStore は MailStore Home のシステム要件として Windows 10 と Windows 11 を挙げています。Mac では、MailVault やほかの Mac 向けの選択肢など、別のツールが必要です。

MailVault は MailStore Home のアーカイブを読み込めますか？

直接はできません。MailVault は MailStore のアーカイブファイルを読めません。MailStore Home から IMAP や Gmail のメールボックスにメールを書き出して MailVault でアーカイブするか、MailVault を元のアカウントに接続してください。

MailVault で PST ファイルを開けますか？

いいえ。MailVault は MBOX ファイルを読み込み、Gmail、Microsoft 365、Outlook.com、IMAP のアカウントに接続します。古いメールが PST ファイルにあるなら、Windows の MailStore Home でアーカイブできます。

MailStore Home は本当に無料ですか？

MailStore によると、家庭での個人利用なら無料です。商用利用には、有料の MailStore Server を案内しています。

次にすること

Windows で PST ファイルがあるなら、まず MailStore Home を試してください。Mac や Linux なら、あるいはプレーンなファイルが欲しいなら、MailVault を無料でダウンロードし、1 つのアカウントを接続して古い 1 年分をアーカイブし、どう動くかを確かめてください。アーカイブして削除のページで、何が無料で何が Premium かがわかります。

MailVault を Thunderbird や Apple Mail と比べたり、ローカル検索について読んだりもしてください。
