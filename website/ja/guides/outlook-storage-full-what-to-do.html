Outlook のストレージがいっぱい：何がいっぱいかを突き止めて対処する

8分で読めます · 2026年10月8日更新

Outlook でストレージがいっぱいと表示されたら、まずどのストレージがいっぱいなのかを突き止めてください。無料の Outlook.com のアカウント（Hotmail と Live.com のアドレスを含む）には 2 つの上限があります。メール用の 15 GB と、OneDrive と Outlook.com の添付ファイルで共有する Microsoft のクラウドストレージ 5 GB です。職場や学校のアカウントには、組織が設定するメールボックスの上限があります。無料の上限に達すると、Outlook.com ではメールの送受信が止まります。このページでは、何がいっぱいなのかを見つけて対処法を選ぶ手助けをします。実際の整理の手順は Hotmail と Outlook.com の空き容量を増やす方法を読んでください。短い概要は Outlook.com や Hotmail のメールボックスがいっぱいを参照してください。

手短な答え

  1. Outlook.com で設定 > アカウント > ストレージを開き、メール用ストレージを確認します。それから Microsoft のクラウドストレージも確認してください。
  2. 削除済みアイテムを空にします。空にするまでは容量に数えられます。
  3. まだいっぱいですか？ 古いメールのコピーをコンピュータに保存し、コピーを確認してから、そのメールを Outlook.com から削除します。
  4. ストレージを追加で購入するのは、すべてのデバイスで古いメールをすべてオンラインに置いておく必要がある場合だけにします。

変更が反映されるまで最大 24 時間かかることがあります。

Outlook のストレージがいっぱいになると起きること

Microsoft は 3 つの状況を説明しています。どれもメールを止めるので、その日のうちに対処する価値があります。

  • Outlook.com のメールボックスがいっぱい。Outlook.com でメールを送受信できません。あなた宛てに送られたメールは送信者に戻されます。あなたの容量が空いた後で、送信者がもう一度送る必要があります。
  • Microsoft のクラウドストレージがいっぱい。メールボックスにまだ余裕があっても、Outlook.com でメールを送受信できません。OneDrive のファイルは読み取り専用になり、新しいファイルはアップロードも同期もされません。Microsoft によると、6 か月後には OneDrive とその中のファイルが削除される可能性があります。
  • 職場や学校のメールボックスがいっぱい。メッセージを送受信できず、あなたにメールを送った人には、メールボックスがいっぱいだというエラーメッセージが届きます。その前に、メールボックスがいっぱいに近づくと、Microsoft が警告のメールとアプリ内のメッセージを送ります。

ステップ 1：アカウントの種類を確かめる

対処法は、誰が上限を設定しているかによります。表で自分の行を見つけてください。

アカウント 上限を決めるもの 確認する場所 上限を引き上げられる人
無料の Outlook.com、Hotmail、Live.com メール用の 15 GB と、Microsoft のクラウドストレージ 5 GB Outlook.com：設定 > アカウント > ストレージ。クラウドストレージ：Microsoft アカウントの Microsoft ストレージのページ 自分：整理する、アーカイブする、または Microsoft 365 を購入する
Microsoft 365 Basic、Personal、Family を使う Outlook.com メール用に 100 GB。クラウドストレージはプランによるので、現在の容量は Microsoft のプランのページで確認してください 無料のアカウントと同じページ 自分。ただし個人のメールボックスは 100 GB まで
職場や学校のアカウント（Microsoft 365 または Exchange） メールボックスあたり最大 100 GB。管理者がより低い上限を設定できます 新しい Outlook：設定 > アカウント > ストレージ。Outlook on the web：設定 > アカウント > ストレージ IT 管理者
従来の Outlook for Windows のデータファイル（.pst または .ost） PC 上のファイルのサイズ上限。Microsoft は既定で 50 GB としています ファイル > ツール > メールボックスの整理 自分または IT 管理者

Mac、PC、スマートフォンの Outlook アプリは、たいていウェブサイトと同じメールボックスを表示します。Outlook.com でメールボックスがいっぱいと表示されればアプリでも同じように表示され、どこかで空けた容量はすべての場所で空きます。

ステップ 2：メールボックスか、クラウドストレージか？

個人のアカウントでは、2 つの上限は別々の理由でいっぱいになります。メールボックスにはメール、連絡先、カレンダーが入ります。Microsoft のクラウドストレージには、OneDrive のファイルと写真、OneDrive のごみ箱、そして Microsoft によると Outlook.com の添付ファイルが入ります。そのため、写真でいっぱいの OneDrive が、受信トレイに一切触れていなくてもメールを止めることがあります。

Microsoft 自身のヘルプページでも、この分け方の説明は一様ではありません。推測しないでください。何かを削除する前に、両方の数字を見てください。

5 分でできる確認

  1. メール用ストレージを確認します。Outlook.com にサインインし、設定 > アカウント > ストレージを選びます。各フォルダが使っている容量が表示されます。
  2. クラウドストレージを確認します。Microsoft アカウントにサインインし、Microsoft ストレージのページを開きます。Microsoft のクラウドストレージとはのヘルプページで、何が容量に数えられるかを説明しています。
  3. 削除済みアイテムを見ます。空にするか、各アイテムが 30 日後に削除されるまでは容量に数えられます。
  4. 一括処理を使いましたか？一括処理で削除したメールは、削除済みアイテムからも削除されるまで容量は減りません。
  5. 迷惑メールを見ます。Outlook.com は迷惑メールのアイテムを 10 日後に削除するので、このフォルダが問題になることはめったにありません。
  6. いっぱいなのがクラウドストレージなら、OneDrive のごみ箱を確認します。これも容量に数えられます。

ストレージのページでは、フォルダ内のすべてのアイテム、または 3、6、12 か月より古いアイテムだけを完全に削除することもできます。手早いですが、元に戻せません。必要のないフォルダか、すでにコピーしたフォルダにだけ使ってください。

3 つの選択肢を順番に

1. 整理する

削除済みアイテムを空にし、読んでいないニュースレターを削除し、フィルター > 並べ替え > サイズで最も大きなメールを見つけます。無料で、上限を少し超えているだけならこれで足りることがよくあります。何を残すべきかを含めた手順の全体は、Hotmail と Outlook.com の空き容量を増やすにあります。

2. 古いメールをコンピュータに残してから、オンラインで削除する

いっぱいのメールボックスの多くは、めったに開かないけれど失いたくない古いメールでいっぱいです。そのメールのコピーをコンピュータにダウンロードし、コピーを確認してから、Outlook.com からメールを削除できます。容量が戻り、必要なときにはメールがまだそこにあります。

MailVault は、これを行う macOS・Windows・Linux 向けの無料のデスクトップアプリです。各メールを標準的な .eml ファイルとしてコンピュータに保存します。無料のアプリでは 2 つのステップで行います。アーカイブがメールを保管庫にコピーし、次にサーバーから削除が Outlook.com から削除します。各コピーを確認してからサーバーのコピーを削除するワンステップのアーカイブして削除は Premium に含まれます。アーカイブして削除の仕組みを参照してください。

3. ストレージを追加で購入する

Microsoft 365 Basic、Personal、Family では、メール用ストレージが 100 GB に増えます。100 GB のメールボックスは Microsoft 365 の試用版には含まれません。価格は国によって異なるので、Microsoft のサイトで確認してください。スマートフォンでもウェブでも古いメールをすべて見られる必要があるなら、これが正しい選択です。ただし、メールボックスが大きくなり続けることは止められません。2 つの考え方はローカルでのアーカイブとストレージの追加購入の比較で比べています。

選択肢 費用 その後の古いメール 向いている場合
整理する 無料 削除したものは消える 上限を少し超えている、または削除済みアイテムが大きい
ローカルにアーカイブしてから削除 MailVault なら無料（2 ステップ）。ワンステップのアーカイブして削除は Premium コンピュータ上にあり、オフラインで読めて検索できる めったに開かない何年分もの古いメール

どれを選ぶべきか

  • 今まさにメールが戻されている。まず削除済みアイテムを空にします。すぐに済み、削除されるのはすでに削除したメールだけです。それから今週のうちに、より長く効く対処を計画します。
  • メールボックスが古いメールでいっぱい。ローカルにアーカイブしてから、Outlook.com から削除します。何も失わずに多くの容量を空けられます。
  • クラウドストレージがいっぱいで、その大部分が OneDrive。メールを削除しても少ししか効きません。OneDrive のファイルを移動するか削除し、OneDrive のごみ箱を空にするか、ストレージを購入します。大きな添付ファイル付きの古いメールを削除するのも効果があります。
  • 職場や学校のアカウント。まず IT 管理者に相談してください。組織があなたのためのアーカイブメールボックスを用意している場合があります。会社の規則で認められていないなら、仕事のメールを個人のツールにコピーしないでください。
  • すべてをオンラインに置いておく必要がある。ストレージを購入し、請求が続くことを受け入れてください。

アーカイブを選ぶなら、まずコピーを作り、削除はその後です。Outlook.com のメールを Mac にバックアップするガイドでそのコピーの作り方を比べ、古いメールを失わずにメールの容量を空けるガイドで、どのプロバイダーにも通じる同じ考え方を説明しています。

Outlook のデスクトップアプリについての注意

  • 従来の Outlook for Windows にはファイル > ツール > メールボックスの整理があります。メールボックスとそのフォルダのサイズを表示し、指定した日付より古いアイテムや指定したサイズより大きいアイテムを見つけ、削除済みアイテムを空にします。
  • .pst や .ost のファイルは PC 上にあります。Microsoft はこれらのファイルの既定のサイズ上限を 50 GB としています。この上限は、Outlook.com や職場のメールボックスの上限とは別のものです。

よくある質問

Outlook.com の無料のストレージはどれくらいですか？

無料の Outlook.com のアカウントには、メール用の 15 GB と、Microsoft のクラウドストレージ 5 GB があります。クラウドストレージは、OneDrive のファイルと写真、Outlook.com の添付ファイル、Microsoft 365 のアプリで共有されます。

Outlook のストレージがいっぱいでもメールを受信できますか？

いいえ。Outlook.com のメールボックスか Microsoft のクラウドストレージがいっぱいになると、メールを送受信できません。あなた宛てのメッセージは送信者に戻され、あなたが容量を空けた後で、送信者がもう一度送る必要があります。

空けた容量が Outlook に表示されるまでどのくらいかかりますか？

Microsoft によると、変更が反映されるまで最大 24 時間かかることがあります。削除済みアイテムにあるメールはフォルダを空にするまで数えられるので、先に空にしてください。

Microsoft 365 を購入すれば、いっぱいの Outlook のメールボックスは解決しますか？

Microsoft 365 Basic、Personal、Family には 100 GB のメール用ストレージが含まれるので、当面は上限が問題でなくなります。100 GB のメールボックスは Microsoft 365 の試用期間中は使えません。メールが増え続ければ、大きな上限もいっぱいになることがあります。

Outlook.com から削除した後もメールは安全ですか？

どこか別の場所にコピーがある場合に限ります。削除済みアイテムのアイテムは 30 日後に削除されます。何かを削除する前に、まず古いメールのコピーをコンピュータに保存し、コピーが開けることを確認してください。

次にすること

今日のうちに 5 分でできる確認を済ませて、届いたメールが送信者に戻されないようにします。それから古いメールをどうするかを決めます。オンラインのストレージに追加で支払わずに残したいなら、MailVault が自分のコンピュータにプレーンな .eml ファイルとしてコピーを残し、無料のアプリで 2 つのステップでアーカイブしてサーバーから削除できます。MailVault のアカウントはなく、メールが MailVault のサーバーを通ることもありません。

古い Outlook のメールをコンピュータに残す

macOS・Windows・Linux 向けに無料。ソースコードは GitHub で公開。Premium ではワンステップのアーカイブして削除とスケジュールバックアップが加わります。
