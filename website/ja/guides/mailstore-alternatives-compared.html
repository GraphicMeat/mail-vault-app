MailStore の代わり：用途別に並べた 7 つの選択肢

7分で読めます

正しい MailStore の代わりは、どの MailStore を、なぜ置き換えるのかによります。MailStore Home は個人利用向けの無料の Windows のアーカイバーです。MailStore Server は企業向けの有料の Windows のアーカイブです。このまとめでは、実在する 7 つの選択肢を 4 つのグループに分けています。Mac や Linux での個人利用、Windows での個人利用、オープンソースのアーカイブサーバー、そして Microsoft 365 と Google Workspace にすでに組み込まれたツールです。私たちは 7 つのうちの 1 つである MailVault を作っており、その制限もほかのものと並べて載せています。特定の 2 つをより詳しく比べるには、MailVault と MailStore Home の比較や MailStore Server の代わりを読んでください。

手短な答え

  • Mac や Linux の個人：MailVault、または Mac なら Mail Archiver X。
  • 無料で自分で組み立てたい Windows の個人：Thunderbird と ImportExportTools NG、または MailVault。
  • 自社でサーバーを運用する会社：Piler、Mail-Archiver、または Open Archiver。
  • すでに Microsoft 365 や Google Workspace を使っている会社：Microsoft Purview または Google Vault。

Mac や Linux の個人向け

MailStore Home には Windows 10 か 11 が必要なので、Mac や Linux のユーザーはほかを探す必要があります。Mac の場合については Mac 向けの MailStore の代わりのガイドで詳しく説明しています。

1. MailVault

MailVault は、選んだメールのコピーを Maildir 形式のフォルダにプレーンな .eml ファイルとして、コンピュータ上のローカルの保管庫に保管する、macOS・Windows・Linux 向けの無料のメールアプリです。Gmail、Microsoft 365、Outlook.com、あらゆる IMAP のアカウントに接続し、Google Takeout の書き出しなどの MBOX ファイルを読み込み、持っているすべてをローカルのインデックスでオフラインで検索します。手動バックアップは無料で無制限です。アーカイブとサーバーから削除は別々のステップとしてなら無料で、各コピーを確認してからサーバーのコピーを削除するワンステップのアーカイブして削除は Premium です。

制限：PST の読み込み、Outlook や Thunderbird のプロファイルの読み込み、複数ユーザーでの共有アーカイブ、保持ポリシーや訴訟ホールドはありません。添付ファイル検索、スケジュールバックアップ、整理ルールは Premium です。

2. Mail Archiver X

Moth Software の Mail Archiver X は、Apple Mail、Outlook、Thunderbird、Postbox、そして Gmail や iCloud を含む IMAP のアカウントからアーカイブする有料の Mac アプリです。アーカイブは検索インデックス付きの内部データベースに保管され、PDF と MBOX に書き出せ、アーカイブは内蔵または外付けのドライブに置けます。開発元はネットワークストレージも挙げていますが、マニュアルでは標準版はローカルのアーカイブを前提にしているとしています。サーバーのコンポーネントを持つ Pro 版では、複数のコンピュータとユーザーからのアクセスが加わります。現在のバージョンは 8.2.4 です。

制限：Mac 専用で、アーカイブは 1 通につき 1 ファイルではなくデータベースなので、標準的なファイルを取り出すには書き出しが必要です。価格は開発元のマニュアルに記載されており、$49.95（税別）、Pro は $150 からです。

Windows の個人向け

Windows では、MailStore Home 自体は今も個人利用なら無料です。それでも離れるつもりなら、あるいはほかのシステムでも使える構成が欲しいなら、MailVault は Windows でも動きますし、無料で自分で組み立てる方法もあります。

3. Thunderbird と ImportExportTools NG

Thunderbird は Windows、macOS、Linux 向けの無料のメールクライアントです。アーカイブボタンでメッセージをアーカイブフォルダに移せ、そのフォルダをコンピュータのローカルフォルダに向け、年や月ごとに整理できます。無料の ImportExportTools NG のアドオンは、メッセージを EML、HTML、PDF、CSV、プレーンテキストとして、フォルダを mbox として書き出し、mbox と EML のファイルを読み込めます。

制限：Thunderbird は標準ではフォルダごとに 1 つの mbox ファイルとして保存します。Maildir での保存はアカウントごとに選ぶ方式で、Mozilla は試験的なものとし、有効にする前に不具合の報告の仕方とメールの復元の仕方を知っておくよう案内しています。アーカイブは手作業で、メールをローカルのフォルダに入れた後は、そのフォルダのバックアップは自分の仕事です。詳しくは MailVault と Thunderbird の比較を参照してください。

オープンソースのアーカイブサーバー

これらは MailStore Home より MailStore Server の代わりになるものです。3 つとも無料で使えますが、3 つともサーバーのインストール、更新、バックアップを誰かが行う必要があります。

4. Mail-Archiver

Mail-Archiver（Mail Archiver X とは別の製品）は GPL-3 のセルフホスト型のウェブアプリで、PostgreSQL のデータベースと並べて Docker で動かします。IMAP のアカウントと、Microsoft Graph 経由で Microsoft 365 を同期し、個人の Outlook.com のアカウントにも接続し、MBOX と ZIP 圧縮した EML を読み込み、同じ形式で書き出します。アカウントごとの権限を付けて複数のユーザーで共有できます。アカウントごとに設定した期間が過ぎるとサーバーからメールを削除でき、ログイン、検索、書き出しのアクセスログを残します。

制限：独自の HTTPS がないのでリバースプロキシが必要で、README には訴訟ホールドの記載がありません。

5. Piler

Piler は GPL-3 のオープンソースのアーカイブサーバーです。無料の Open Source Edition は、SMTP でメールを受け取り、Office 365 と Google のアカウントを取り込み、EML、Maildir、メールボックスのファイルを読み、アーカイブと保持のルール、訴訟ホールド、監査ログ、重複排除、圧縮、メッセージの暗号化を備えています。ユーザーは AD や LDAP、シングルサインオン、2 段階認証のコードでサインインします。Enterprise Edition は価格帯が公開された有料版で、電子情報開示、マルチテナント、任意の有償サポートが加わります。

制限：無料版は単一サーバー向けでコミュニティによるサポートのみ、Enterprise の価格は問い合わせのみです。

6. Open Archiver

Open Archiver は AGPL-3 のセルフホスト型のプラットフォームで、Docker Compose で起動します。Google Workspace、Microsoft 365、IMAP、PST ファイル、ZIP 圧縮した EML、MBOX を取り込み、メッセージと PDF や DOCX などの添付ファイルのテキストをインデックス化します。メールを重複排除、圧縮、保存時の暗号化を施した .eml ファイルとしてローカルのディスクか S3 互換のストレージに保存し、取り込み時に各メッセージのハッシュを記録し、監査証跡を残します。

制限：README では訴訟ホールドは今後対応予定とされており、既定の構成では少なくとも 4 GB の RAM が必要です。

企業向け：プロバイダーがすでに持っているアーカイブ

7. Microsoft Purview または Google Vault

会社のメールが Microsoft 365 にあるなら、Microsoft Purview の保持ポリシーとラベルによって、ユーザーが削除した後もメールボックスのアイテムのコピーが残り、電子情報開示で検索できます。必要な機能がどの Microsoft 365 のプランに含まれるか確認してください。メールが Google Workspace にあるなら、対応するエディションでは Google Vault が保持ルール、ホールド、検索、書き出し、Vault の操作の監査ログを扱います。

制限：コピーは同じプロバイダーのクラウドに残るので、独立したバックアップにはなりません。Google によると、Vault はデータのアーカイブではなく、ルールを設定するまでは何も保持しません。同じような管理機能を持つ、別の Windows ベースのアーカイブなら、MailStore Server 自体も引き続き選択肢です。

選び方

  1. アーカイブは誰のためのものか？1 人のメールはデスクトップの仕事です。多くの人のメールを、ほかの誰かが検索するならサーバーの仕事です。
  2. 保持ルール、訴訟ホールド、監査ログが必要か？必要なら、Piler、MailStore Server、またはプロバイダー自身のツールを見てください。ここにあるデスクトップの選択肢ではできません。
  3. 古いメールはどこにあるか？PST ファイルなら MailStore Home か Open Archiver です。MBOX ファイルと IMAP のアカウントは、ここにあるほぼすべてで使えます。
  4. 最終的にどんな形式で手元に残したいか？10 年後にツールなしで開けるプレーンなファイルが欲しいなら、.eml のような 1 通につき 1 ファイルの形式を選んでください。

よくある質問

MailStore の無料の代わりで最適なものは？

用途によります。Mac、Windows、Linux の個人なら、MailVault か、Thunderbird と ImportExportTools NG。自社サーバーでの会社のアーカイブなら、Piler Open Source Edition、Mail-Archiver、Open Archiver です。

MailStore のオープンソースの代わりはありますか？

はい。Piler と Mail-Archiver（どちらも GPL-3）、Open Archiver（AGPL-3）はオープンソースのアーカイブサーバーです。デスクトップでは Thunderbird がオープンソースで、MailVault のソースコードは GitHub で公開されています。

PST ファイルを読める MailStore の代わりはどれですか？

ここにあるツールのうち、Open Archiver は PST ファイルを取り込め、MailStore Home と MailStore Server も PST をアーカイブできます。MailVault、Mail-Archiver、Thunderbird と ImportExportTools NG、Piler の無料版には PST の取り込みの記載がありません。

Mail-Archiver と Mail Archiver X は同じものですか？

いいえ。Mail-Archiver は Docker で動く無料のセルフホスト型のウェブアプリです。Mail Archiver X は Moth Software の有料の Mac アプリです。

次にすること

自分の場合に合うグループを選び、すべてを移す前に 1 つのメールボックスで 1 つのツールを試してください。Mac、Windows、Linux の個人で、メールをプレーンなファイルとして持ちたいなら、MailVault を無料でダウンロードして、まず古い 1 年分をアーカイブしてください。IMAP バックアップツールのチェックリストを使えば、これらのどのツールも同じ方法で試せます。
