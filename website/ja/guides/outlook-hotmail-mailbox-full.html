Outlook.com / Hotmailの容量がいっぱい？ 解決法はこちら

6分で読めます

Outlook.com（かつてHotmailと呼ばれていたものの現在の名前）は、無料のアカウントにOneDriveと共有で15 GBの容量を与えます。いっぱいになると受信したメールが弾かれ、ウェブの画面やOutlookのデスクトップ・モバイルのアプリに容量の警告が出ます。Microsoft自身の対処法は、Microsoft 365のサブスクリプションで容量を売ることです — しかし、場所を無期限に借り続けるのではなく本当に問題を解決したいなら、全体像は次のとおりです。

1. 容量が実際どこへ消えたのかを確かめる

Outlook.comで、設定 → 全般 → ストレージ を開くと、メールとOneDriveの内訳が見えます。OneDriveのほうが多いなら、メールを片づけてもあまり効きません — OneDriveのファイルは別に対処することになります。メールが大半なら、原因はほぼ必ず添付ファイルであって、メールの文面ではありません。

2. 「削除済みアイテム」と「迷惑メール」を空にする

多くのプロバイダーと同じく、Outlook.comは削除したメッセージを、空にするまで「削除済みアイテム」のフォルダに置き、その間も容量に数えます。フォルダの一覧で「削除済みアイテム」と「迷惑メール」を右クリックし、「フォルダーを空にする」を選べば、その分の容量をすぐに取り戻せます。

3. サイズで並べ替えて、添付ファイルの多い古いメールを片づける

Outlook.comの検索でhasattachments:yesを使い、サイズで並べ替えると、いちばん大きなメールが見つかります。大きな添付ファイル — PDF、動画、ディスクイメージ — の付いた数年前のメールが数通あるだけで、たいていは短い文面のメール数千通の合計よりずっと多くの容量を占めています。

4. 本当にMicrosoft 365が必要か考える

Microsoft 365 Basicは低い月額から始まり、100 GBの容量とOfficeのアプリが付きます。もともとアプリが欲しいなら、それは十分価値があります。しかし、いっぱいのメールボックスを直すためだけに買うのなら、新しく増えた容量もいずれ埋まって戻ってくる問題を、継続的な料金で先送りしているだけです。

5. ローカルにアーカイブしてから、サーバーで削除する

この循環を実際に断ち切るやり方です。残しておきたい古いメールのコピーを自分のコンピューターにダウンロードし、コピーが完全であることを確かめてから、Outlook.comでそれらを削除します。メールボックスの割り当ては恒久的に空き、すべてのメッセージは検索でき、オフラインでも見られる状態で手元に残ります。しかも、履歴を保つための継続的な保存料はかかりません。

Outlook.comもHotmailもIMAPに対応しているので、IMAPを使うアーカイブのツールならどれでもこれができます。MailVaultは、macOSとLinux向けの無料・オープンソースの選択肢です。MicrosoftのOAuthのサインインでOutlook.comやHotmailのアカウントをつなぎ（パスワードで悩む必要はありません）、必要なフォルダを選ぶと、MailVaultはそれぞれのメッセージを、標準的なMaildirの構造に整理された1通ずつの.emlファイルとしてディスクにダウンロードします。アーカイブを確かめたら — いくつかメールを開き、添付ファイルを確認し、覚えのあるものを検索して — Outlook.comから元のメールを安心して削除し、容量を取り戻せます。

MailVaultでの手動のアーカイブは無料で無制限です。まとめてアーカイブするのではなくスケジュールで自動実行したい場合は、$4/月 または $25/年 のPremium機能です — 年額プランには14日間の無料トライアルが付きます。

MailVaultは、サーバーから何かを削除する前に、Outlook.comとHotmailのメールを個別の.emlファイルとしてお使いのディスクにアーカイブします。

よくある質問

Outlook.comの無料の保存容量はどれくらいですか？

15 GBで、メールとOneDriveで共有します。内訳は 設定 → 全般 → ストレージ で確認できます。

Outlook.comで「削除済みアイテム」を空にすると、すぐに容量が空きますか？

はい。決まった日数を待つプロバイダーもありますが、Outlook.comでは「削除済みアイテム」と「迷惑メール」のフォルダを手動で空にすれば、その容量はすぐに解放されます。

HotmailとOutlook.comは同じものですか？

実用上は同じです。Microsoftは何年も前にHotmailをOutlook.comに名称変更しました。古い @hotmail.com や @live.com のアドレスはいまも使え、同じOutlook.comの容量と設定を使います。

Microsoft 365に課金せずにOutlook.comのメールをアーカイブできますか？

はい。Outlook.comは標準のIMAPアクセスに対応しているので、MailVaultの無料の範囲を含め、どのIMAPのアーカイブツールでも、Microsoft 365のサブスクリプションなしでメールをローカルにダウンロードできます。
