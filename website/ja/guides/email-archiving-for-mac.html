How to Archive Your Email on a Mac and Keep It for Good

8分で読めます

Email archiving for Mac means saving a complete copy of your mail as files on your own disk, in an open format, so it stays readable after the provider deletes it, the account closes or the app you used is gone. This guide explains what archiving is and is not, the options macOS gives you, which file format to keep, and how to build and check an archive of a Gmail, Outlook.com, iCloud or IMAP account. If you already know all that and just want to pick a tool, read our shortlist of the best email archivers for Mac.

Quick answer

  • The Archive button in Apple Mail, Gmail or Outlook moves mail to another folder of the same account. It stays with your provider, and nothing new is saved for you.
  • A real archive is a copy you own: one file per message (.eml) or one file per folder (mbox), on your Mac or a drive you control.
  • Apple Mail can export a mailbox as mbox for a one-off copy. An archive that keeps up with new mail needs a tool that downloads repeatedly.
  • In MailVault, a free app: add the account, set What to back up to All emails, press Back up all accounts now, then check the icons on each row. Backups on a schedule are Premium.

Archive, backup and sync are not the same thing

The Archive button in your mail app is a move, not a copy. Apple's Mail guide says archiving moves the message into an Archive mailbox created for that email account. Gmail's help says an archived message can still be found under All Mail. Microsoft's Outlook help says the Archive button does not reduce your mailbox size. In all three cases the mail stays with the provider.

Sync mirrors the server, so a message deleted on your phone also leaves your Mac. A backup is a copy kept elsewhere so you can restore it. An archive, in the sense this page uses, is a backup you keep for years and can still read: complete, searchable and not tied to one app.

Your options on a Mac

  • Apple Mail's Export Mailbox. Select one or more mailboxes, choose Mailbox > Export Mailbox and pick a folder. Apple says the export is in mbox format, and that Mail does not overwrite an earlier export but creates a new .mbox file next to it. File > Import Mailboxes brings it back. It is free and built in, but it is a snapshot you repeat by hand.
  • Thunderbird. Free and open source, with a macOS download. Mozilla says Thunderbird stores mail as one mbox file per folder by default, with an optional file-per-message (Maildir) store that Mozilla still treats as experimental. The ImportExportTools NG add-on exports messages as EML, PDF and other formats, and folders as mbox.
  • Command-line backup tools. Got Your Back (GYB) is an open source tool that backs up Gmail and Google Workspace accounts to a local folder through Gmail's API, and can restore them. It suits people happy in Terminal and covers Google accounts only.
  • Dedicated archivers. Mail Archiver X, MailSteward and EagleFiler are paid Mac apps that pull mail into a searchable archive or library, each stored its own way. Our best email archiver for Mac page compares them by use case.
  • MailVault. A free mail app for macOS, Windows and Linux that keeps a copy of your mail on your computer as plain .eml files in Maildir-style folders, signs in to Gmail, Microsoft 365, Outlook.com and any IMAP account, and has no MailVault account or server in the path of your mail. The rest of this guide uses it for the step-by-step.

Which format to keep your mail in

The format matters more than the tool, because the archive should outlive the tool.

  • .eml files. One message per file, in the internet message format (RFC 5322): headers, body and attachments together. Many mail apps open them directly, and a damaged file affects one message. Maildir is the folder layout that organises them.
  • mbox. One file per folder with the messages one after another. It is the most widely supported import format, which is why Apple Mail exports it. You usually have to import it into an app before you can browse it, and one damaged file touches a whole folder.
  • An app's own database. Dedicated archivers often use one, and it can make search fast. The trade-off is that reading the archive depends on that app. Before you commit, check that it can export everything to mbox or .eml.

A practical rule: keep at least one copy of your archive in .eml or mbox, whatever else you use. For more on what to check before trusting a tool, see our IMAP backup tool checklist.

How to check the archive is complete

Check the copy before you delete anything on the server.

  • Read the row icons. Every message shows whether it is on the server only, in your vault, your only copy, or also on your backup drive. The Vault switch above the folder list shows only what is saved on your Mac.
  • Go offline. Turn off Wi-Fi, then open a few old messages with attachments and run a search. Everything that opens now is on your disk.
  • Open the files elsewhere. Settings > Backup & Restore > Backup Settings > Open Folder shows the vault in Finder. Open a few .eml files in Apple Mail. If they read correctly there, the archive does not depend on MailVault.
  • Compare counts (Premium). Backup health shows server, app and external counts per folder, so you can see which folders are fully saved.

When you are ready to clear the server, MailVault's Archive & Delete (Premium) copies each message into your vault, checks the copy, and only then deletes the server copy. Deleting from the server on its own is free, but then the checking is up to you.

Frequently asked questions

Does the Archive button in Apple Mail save my email to my Mac?

No. Apple's Mail guide says archiving moves the message into an Archive mailbox created for that email account. It is a move inside the account, not a copy on your disk. To keep a copy you own, export the mailbox or use an archiving tool.

What is the best file format for an email archive?

Plain .eml files or mbox. Both are open formats that many mail apps can read. Eml keeps one message per file, so one damaged file affects one message. Mbox keeps one file per folder and is the most common import format.

How long does it take to archive a large Gmail account?

Google limits IMAP downloads to 2,500 MB per day per account, so a mailbox larger than that takes more than one day with any IMAP tool. MailVault stops when the limit is reached and continues from where it stopped on the next run.

Is email archiving on a Mac free?

It can be. Apple Mail's export and Thunderbird cost nothing, and MailVault is free, including unlimited manual backups. In MailVault, backups that run on a schedule are part of Premium.

Can I delete mail from the server after archiving it?

Yes, once you have checked the archive. Archived copies in MailVault stay on your disk whatever the server does afterwards. MailVault Premium can archive and delete in one step, checking each saved copy before the server copy is removed.
