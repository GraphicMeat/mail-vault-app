Mac 向けの MailStore の代わり：MailVault

6分で読めます

メールのアーカイブソフトを探したことがあるなら、おそらく MailStore Home を見つけたでしょう。Windows でメールをローカルにアーカイブするツールとして、最も人気のあるものの 1 つです。問題は、MailStore Home が Windows 10 と 11 でしか動かず、Mac 版がないことです。macOS（や Linux）を使っているなら、代わりが必要です。

MailVault は、メールを自分のディスクにアーカイブする、macOS・Windows・Linux 向けの無料のメールアプリです。Gmail、Microsoft 365、Outlook.com、IMAP のメールのコピーを Mac（Intel または Apple Silicon）に残し、標準的なオープンな形式で保存し、基本のアプリは無料です。

このページは Mac についてのものです。Windows 版との直接比較は MailVault と MailStore Home の比較を読んでください。会社全体のアーカイブが必要なら MailStore Server の代わりを、すべての選択肢の比較は MailStore の代わりの比較を参照してください。

MailStoreがうまくやっていること

MailStore Homeは、Windowsのユーザーにとって堅実な製品です。その強みを公平に挙げます。

  • 成熟していて、よく試されています — MailStoreは2006年からあります。端の場合をうまく扱い、幅広いメールの提供元に対応しています。
  • 全文検索 — MailStoreはアーカイブしたメールに索引を作り、アーカイブ全体を素早く全文検索できます。
  • 複数の取り込み元 — IMAPだけでなく、OutlookのPSTファイル、Exchangeのサーバー、ほかのローカルのメールクライアントからもアーカイブできます。
  • 企業向けの版 — MailStore Serverは、コンプライアンスの機能、監査の記録、保管の方針を備えた集中的なメールのアーカイブを必要とする組織のために作られています。

MailStore Server は中小企業向けで、Windows と Windows Server で動きます。Mac での個人利用には、どちらの版も選択肢になりません。

MailVaultが優れているところ

Macで動きます。これが最も分かりやすい違いです。macOSをお使いなら、MailStoreは選択肢になりません。MailVaultはmacOS（IntelとApple Silicon）とLinuxでネイティブに動きます。Wineも、仮想マシンも、回り道も要りません。

オープンで標準的な保存形式。MailStore はアーカイブしたメールを独自のアーカイブファイルに保存し、EML や MSG のファイルとして取り出すには書き出しが必要です。MailStore の開発が止まれば、そのメールにアクセスするのは難しくなります。MailVault はすべてのメールを、ほかのメールクライアントでも開ける RFC 5322 形式の標準的な .eml ファイルとして保存します。アーカイブはファイルの入ったフォルダにすぎません。Apple Mail、Thunderbird、どんなテキストエディタでも開けます。

ソースコードは GitHub で公開。 MailVault のソースコードは GitHub で公開されています。読んで、メールに対して何をしているかを確かめられます。個人のメールを扱うソフトウェアだからこそ、何をしているのかを正確に知れることが大切です。

メールクライアントでもあります。MailStoreはアーカイブのためだけのツールです — メールをアーカイブしたあと、読むには別のクライアントを使います。MailVaultはその両方です。アプリの中で直接メールを読み、検索し、作成し、返信し、転送でき、恒久的に残したいものはローカルのディスクへアーカイブできます。

オフラインでのローカル検索。MailVault は Mac 上のメールの全文インデックスを作り、接続なしで検索します。送信者、日付、フォルダ、タグで絞り込めます。公開している検索テストでは、50,000 通のメッセージを対象にした最も遅い検索でも 14 ミリ秒でした。

Mac にどれだけ残すか。MailVault は既定で直近の数か月分のメールをコンピュータに残し、1、3、6、12 か月から選べます。アーカイブしたメールとバックアップがこの設定で削除されることはありません。すべて保存（Premium）は、すべてのフォルダと全期間のメールを残します。

確認付きでアーカイブしてから削除。メッセージのアーカイブとサーバーからの削除は、別々のステップとしてなら無料です。アーカイブして削除（Premium）は両方を一度に行います。各メッセージを保管庫にコピーし、コピーを確認し、そのあとで初めてサーバーから削除します。

MailStoreが優れているところ

違いについて正直に書きます。

  • 無料の添付ファイル検索：MailStore Home は、メッセージだけでなく添付ファイルも無料でインデックス化します。MailVault にもローカルの全文インデックスがありますが、PDF や Office の添付ファイル内の検索は Premium です。
  • PST と Exchange からの取り込み：Outlook の PST ファイルがある場合や、Exchange サーバーから直接アーカイブする必要がある場合、MailStore はこれらの取り込み元に対応しています。MailVault は IMAP か Microsoft Graph で接続し、MBOX ファイルを読み込めますが、PST ファイルは読めません。
  • 企業のコンプライアンス：MailStore Server（有料版）は、組織がコンプライアンスのために必要とする、集中管理されたアーカイブ、保持ポリシー、監査証跡、訴訟ホールドの機能を提供します。MailVault は個人と小規模事業者の利用を想定しており、企業のコンプライアンス向けではありません。
  • 成熟度：MailStore は 2006 年から、約 20 年にわたって提供されています。MailVault がまだ経験していないほど多くの例外的なケース、メールプロバイダー、利用場面を扱ってきました。

代わりにMailVaultを使うべきなのは誰か

次に当てはまるなら、MailVaultが適した選択です。

  • macOSまたはLinuxを使っていて、ローカルでのメールのアーカイブが必要な方。
  • アーカイブしたメールを（独自形式のデータベースではなく）標準の公開された形式で持ちたい方。
  • ソースコードを読める無料のソフトウェアを使いたい。
  • メールクライアントとアーカイブのツールを兼ねるアプリが欲しい方 — 読み、送り、アーカイブするのを1か所で。
  • 企業向けの複雑さなしに個人のメールのアーカイブが必要な、フリーランス、コンサルタント、小規模事業の経営者の方。
  • ローカルにアーカイブしてサーバーから削除することで、メールの保存容量を空けたい方。

会社のためのコンプライアンス機能が必要なら、MailStore Server の代わりを読んでください。古いメールが PST ファイルにあるなら、Windows の MailStore Home で読めます。Mac での個人のメールのアーカイブなら MailVault で用が足り、基本のアプリは無料です。

そのほかの選択肢

念のため、Macのユーザーがときどき検討するほかの選択肢も挙げておきます。

  • Apple Mail とローカルのフォルダ：Apple Mail ではメールをローカルのメールボックスにドラッグでき、メールボックス > メールボックスを書き出す で mbox 形式で保存できます。サーバーから削除する前にローカルのコピーを確認する手順はなく、Maildir での書き出しもありません。
  • Thunderbird：無料でクロスプラットフォームです。アーカイブボタンで Mac のローカルフォルダにメールを移せ、ImportExportTools NG のアドオンで EML、mbox、PDF に書き出せます。アーカイブは手作業で、ローカルの保存は標準ではフォルダごとに 1 つの mbox ファイルです。MailVault と Thunderbird の比較を参照してください。
  • Google Takeout / プロバイダーの書き出し：.mbox ファイルへの 1 回限りの一括書き出しです。それだけでは検索も差分の更新もできず、.mbox は 1 つのファイルにまとめる形式です。MailVault は Takeout の .mbox ファイルを保管庫に読み込めます。
  • Mail Archiver X：Moth Software の有料の Mac アプリで、Apple Mail、Outlook、Thunderbird、IMAP のアカウントを独自のデータベースにアーカイブし、PDF や MBOX に書き出せます。これを含むツールは MailStore の 7 つの代わりの比較にまとめています。

MailVault はこの隙間を埋めます。Mac、Windows、Linux 向けの、ローカルのアーカイブを持つメールアプリで、オープンな形式を使い、基本のアプリは無料です。

MailVaultを試す — Mac向けの無料のMailStore代替

Gmail、Outlook、IMAP のメールを標準的な .eml ファイルとしてローカルにアーカイブ。ソースコードは GitHub で公開、macOS・Windows・Linux にネイティブ対応、アカウント登録は不要です。
