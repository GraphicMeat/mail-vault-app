Mac におすすめのメールアーカイバーを用途別に選ぶ

8分で読めます · 最終確認：2026年10月

Mac にとって唯一最良のメールアーカイバーはありません。正しい選択は、今メールがどこにあり、10 年後にどう読みたいかによります。要するに、複数のメールアプリの専用アーカイブなら Mail Archiver X、プロバイダーのアカウントを無料でプレーンなファイルとして残すなら MailVault、無料のオープンソースの構成なら Thunderbird と ImportExportTools NG です。このページでは、現在の macOS で動く 7 つのツールを用途別に比較し、価格と制限は各社のサイトから取っています。MailVault は私たちのアプリで、制限も含めて一覧に一度だけ載せています。まずアーカイブそのもの、形式、アーカイブの確かめ方を理解したいなら、Mac のためのメールアーカイブのガイドを読んでください。

すぐに選ぶなら

  • 複数のメールアプリの専用アーカイブ：Mail Archiver X。
  • 無料で、プロバイダーのアカウントをプレーンな .eml ファイルとして残す：MailVault。
  • すでに Thunderbird を使っているなら、無料でオープンソース：Thunderbird と ImportExportTools NG。
  • Apple Mail や Gmail のデータベース：MailSteward。
  • メールと文書を 1 つのライブラリに：EagleFiler。
  • 何もインストールせずに 1 回限りのコピー：Apple Mail の「メールボックスを書き出す」。
  • ターミナルから Gmail：Got Your Back（GYB）。

評価の基準

  • 保存形式。プレーンな .eml や mbox のファイルは、何年たってもほかのアプリで開けます。独自のデータベースは検索が速いこともありますが、1 つのアプリに縛られるので、書き出せるかどうかを確認しています。
  • 検索。2014 年のメッセージを、本文や添付ファイルの中の言葉で見つけられるか？
  • 取り込み元。プロバイダー（Gmail、Outlook.com、iCloud、IMAP）から読むのか、デスクトップアプリのローカルの保存場所から読むのか、その両方か？
  • 自動化。覚えておかないと更新されないアーカイブは、古くなっていくアーカイブです。
  • 価格とライセンス。買い切りか、サブスクリプションか、無料か。そして支払いをやめたらアクセスがどうなるか。
  • オープンソース。メールを扱うコードを読めるかどうか。
  • Apple Silicon。ネイティブか、Rosetta 2 に頼っているか。

用途別のおすすめ

1. Mail Archiver X：複数のメールアプリの専用アーカイブに最適

Moth Software の Mail Archiver X（バージョン 8.2.4、2026年9月）は、Apple Mail、Outlook、Thunderbird、Postbox、Gmail や iCloud を含む IMAP のアカウント、mbox ファイルからメールを取り込んで 1 つのアーカイブにまとめ、差出人、件名、本文、添付ファイルを対象にした簡易検索と絞り込み検索ができます。mbox と PDF に書き出せるので、アプリなしで読める記録が必要なときに便利です。一覧の中で最も充実した純粋なアーカイバーで、メールが複数のデスクトップアプリに散らばっているなら選ぶべきものです。

注意点：アーカイブはアプリ独自の内部データベースにあるので、いつか乗り換えるときには書き出す計画を立てておいてください。標準ライセンスは $49.95 です。Pro のサーバー版は年額のサブスクリプションで、有効な Pro のライセンスがないと、アプリはメールを表示できてもアーカイブや書き出しはできません。Easy 版はアーカイブあたり 10,000 通が上限で、スケジュール機能はありません。

2. MailVault：プロバイダーのアカウントをプレーンなファイルとして残す無料の方法に最適

MailVault は、メールのコピーを Maildir 形式のフォルダに 1 通につき 1 つの .eml ファイルとしてコンピュータに保管する、macOS・Windows・Linux 向けの無料のメールアプリです。Gmail と Microsoft 365 にはそれぞれのページでサインインし、個人の Outlook.com には Microsoft Graph 経由で接続し、iCloud を含むあらゆる IMAP のアカウントを扱えます。MailVault のアカウントはなく、メールの経路に MailVault のサーバーはありません。検索はローカルのインデックスでオフラインでも動き、公開しているテストでは、50,000 通のメッセージを対象にした最も遅い検索でも 14 ミリ秒でした。手動バックアップは無料で無制限、保管庫は mbox として書き出せます。

注意点：MailVault がアーカイブするのはアカウントからで、ほかのアプリのローカルの保存場所からではありません。そのため、Apple Mail の「このMac内」フォルダにしかないメールは、mbox として書き出して読み込む必要があります。既定のバックアップはすでに保管庫にあるメールだけが対象なので、完全なコピーにはバックアップの対象をすべてのメールに切り替えてください。スケジュールバックアップ、バックアップの健全性の件数、ワンステップのアーカイブして削除、PDF と Office の添付ファイル内の検索は Premium です（最初の 100 人の購読者向けの早期アクセス価格で月額 $4 または年額 $25、その後は $6 または $39）。Outlook.com のアカウントでは、mbox ファイルをサーバーに復元することと、削除したメールをサーバーに復元することはまだできません。MailVault は早期アクセス中です。

3. Thunderbird と ImportExportTools NG：無料で完全にオープンソースの構成に最適

Thunderbird は無料のオープンソースで、Mozilla によると現在のバージョンは Apple Silicon でネイティブに動作します。標準ではフォルダごとに 1 つの mbox ファイルとして保存します。1 通ごとに 1 ファイルの保存方式もありますが、Mozilla はまだ試験的なものとしています。ImportExportTools NG のアドオン（GPL-3.0、Thunderbird 140〜157 向け）は、メッセージを EML、HTML、PDF、CSV、プレーンテキストとして書き出し、フォルダとサブフォルダを mbox として書き出し、終了時にスケジュールでプロファイル全体をバックアップできます。すでに Thunderbird でメールを読んでいるなら、費用はかからず、すべてをオープンな形式で残せます。

注意点：自分で組み立てるアーカイブです。IMAP のアカウントでは Thunderbird はサーバーを映すだけなので、アーカイブの完全さは最後の書き出しやプロファイルのバックアップ次第です。詳しくは MailVault と Thunderbird の比較を参照してください。

4. MailSteward：Apple Mail や Gmail の検索できるデータベースに最適

MailSteward（バージョン 18.2.2、2026年9月リリース）は、Apple Mail のアカウントと Gmail のメールを Mac 上のリレーショナルデータベースにコピーします。版は 3 つあります。Lite（$24.95、保存した検索と書き出しはなし）、標準（$49.95）、Pro（$99.95、企業規模のアーカイブ向けで MySQL サーバーが必要）です。開発元によると Apple Silicon 向けに最適化されており、macOS 12 以降が必要で、無料版は 15,000 通まで扱えるので、試すにはちょうどよい方法です。

注意点：取り込み元は Apple Mail と Gmail に限られ、アーカイブはデータベースなので、購入する版の書き出しの選択肢を確認してください。

5. EagleFiler：メールと文書を 1 つのライブラリにまとめるのに最適

C-Command の EagleFiler（バージョン 1.9.22、2026年10月）は、メール、ウェブページ、PDF などのファイルのための汎用のアーカイブです。Apple Mail、Outlook、.eml などの形式のメールを標準の mbox に変換し、ライブラリをほかのアプリでも開ける通常のファイルとフォルダとして保管します。ライブ検索はメッセージと添付ファイルを対象にします。請求書のメールを、関連する PDF やウェブページの隣に置きたいなら、ほかのツールではできません。30 日間の試用期間があり、ライセンスは $69.99 です。

注意点：Apple Mail、Outlook、ファイルにすでにあるメールを元に動きます。プロバイダーから直接ダウンロードすることについて、開発元は説明していません。C-Command によると、EagleFiler は現在 Apple Silicon では Rosetta 2 に頼っており、macOS 28 より前に完全にネイティブになる見込みです。

6. Apple Mail の「メールボックスを書き出す」：何もインストールせずに 1 回限りのコピーに最適

メールで 1 つ以上のメールボックスを選び、メールボックス > メールボックスを書き出す を選びます。Apple によると、結果は mbox 形式で、後の書き出しが前の書き出しを上書きすることはなく、番号付きの新しいファイルが作られます。無料で、すでに Mac に入っています。アーカイバーではありません。スケジュールはなく、書き出したものを読むにはメールアプリに読み込み直す必要があります。

7. Got Your Back（GYB）：ターミナルから Gmail を扱うのに最適

GYB はオープンソース（Apache-2.0）のコマンドラインツールで、Gmail の API を通じて Gmail と Google Workspace のアカウントをコンピュータ上のフォルダにバックアップし、mbox と .eml のファイルをアカウントに復元できます。macOS にはスクリプトでインストールでき、コマンドラインツールなので自分のスクリプトに組み込めます。対象は Google のアカウントだけで、すべてターミナルで操作します。

一覧にないもの：人気のある無料のアーカイバー MailStore Home は Windows 専用です。MailStore は対応するシステムとして Windows 10 と Windows 11 を挙げています。MailStore から移ってくるなら、MailStore の代わりの比較を参照してください。

よくある質問

Mac に最適な無料のメールアーカイバーは？

Gmail、Outlook.com、iCloud、IMAP のアカウントをプレーンなファイルとして残すなら、MailVault は無料で、ソースコードは GitHub で公開されています。すでに Thunderbird を使っているなら、無料の ImportExportTools NG のアドオンで、フォルダを mbox として、メッセージを EML として書き出せます。Apple Mail の「メールボックスを書き出す」は無料ですが手作業です。

MailStore Home は Mac で動きますか？

いいえ。MailStore は MailStore Home の対応 OS として Windows 10 と Windows 11 を挙げています。Mac では、代わりにこのページのツールのどれかを使ってください。

これらのメールアーカイバーは Apple Silicon でネイティブに動きますか？

MailVault と Thunderbird はネイティブに動作し、MailSteward は Apple Silicon 向けに最適化されているとしています。EagleFiler は現在 Rosetta 2 に頼っており、開発者は macOS 28 より前にネイティブ版を出す見込みです。Mail Archiver X は macOS 11〜27 を挙げ、Intel 版と Apple Silicon 版を提供しています。

メールのアーカイブはデータベースとプレーンなファイルのどちらにすべきですか？

データベースなら 1 つのアプリの中で検索を速くできます。プレーンな .eml や mbox のファイルは、どのツールがなくなった後でも、ほかのアプリで開けます。アーカイバーがデータベースを使っているなら、ときどき mbox や eml にコピーを書き出してください。

次にすること

表の中から、メールがある場所に合う行を選び、そのツールを 1 つのアカウントで試し、信頼する前にアーカイブしたメッセージをいくつかそのツールの外で開いてください。試すべき点は IMAP バックアップツールのチェックリストにまとめています。MailVault が合うなら、作成するアカウントもない無料のダウンロードです。
