Macですべてのメールをダウンロードする方法

Macですべてのメールをダウンロードするには、Apple Mailのメールボックス書き出しと、専用のローカルアーカイブから選びます。大切なのは、漏れがないことです。受信トレイだけでアカウント全体を網羅することはほとんどなく、同期されたメールボックスではサーバー側の削除が反映されることもあります。

方法1：Apple Mailからメールボックスを書き出す

  1. Apple Mailにアカウントを接続し、メールの取得が終わるまで待ちます。受信トレイ、送信済み、必要なすべてのフォルダを、古いメールも含めて確認してください。
  2. サイドバーで必要なメールボックスを選択し、メールボックス → メールボックスを書き出すを選びます。
  3. Mac内または外付けドライブのフォルダを選びます。Apple MailはメールボックスのデータをMBOX形式で書き出します。
  4. 別のコピーを保管し、ファイル → メールボックスを読み込むで読み込みを試します。読み込んだコピーから、代表的なメールや添付ファイルを開いてください。

これらのメニュー名とMBOX形式は、Appleのメールボックス読み込み・書き出しガイドに記載されています。書き出したメールボックスは独立したデータです。Mailにアカウントを接続したままにするだけでは、同じバックアップにはなりません。

方法2：MailVaultで検索できるEMLアーカイブを作成する

  1. はじめにからmacOS版をダウンロードし、メールアカウントを追加します。利用できる場合はGoogleまたはMicrosoftのログインを使ってください。
  2. 受信トレイ、送信済み、独自のフォルダ、受信トレイ以外のメールを含むラベルの一覧を作ります。必要に応じて、プロバイダーのアーカイブ済みフォルダや非表示フォルダを接続先から見えるようにします。
  3. 一括操作で必要なフォルダと日付を選び、アーカイブを選択します。完了まで待ち、失敗やスキップされたフォルダがあれば調べてください。
  4. 表示元を保管庫に切り替え、独立したローカルコピーを確認します。保管庫内のメールは.emlファイルです。「サーバー」にしか表示されないメールは、まだアーカイブに含まれていません。

アーカイブを頼りにする前に検証する

  1. メールの表示元を、サーバーやすべてではなく保管庫に切り替えます。見覚えのある古いメールを検索してください。
  2. ネットワークを切断し、異なるフォルダや年のアーカイブ済みメールをいくつか開きます。添付ファイルも開いてください。一覧に件名があるだけでは、メール本文が保存されている証拠にはなりません。
  3. 設定でバックアップと復元を開き、バックアップを書き出すを使います。別のドライブ上の保存先を選んでください。ZIPには保管庫、アカウント、設定が含まれます。サーバーにしかないメールは含まれません。
  4. ZIPが開けること、.emlファイルがあること、保管する予定のフォルダが含まれることを確認します。重要なメールについては、何かを削除する前に、別のインストール環境でコピーの復元を試してください。

短いデモ：ローカルアーカイブを検索する

既存のmacOSデモ録画を編集した、架空のメールによるデモです。アカウントへのログインと一部の準備は録画外で行っています。実際のプロバイダーへのライブ接続ではありません。

デモの説明を読む

このデモでは、準備済みの保管庫にある架空のメールを検索します。ご自身のアーカイブは、接続を切って古いメールや添付ファイルを開いて検証し、別のドライブにもコピーを保管してください。

「すべてのメール」にフォルダのチェックリストが必要な理由

デスクトップからの接続でアーカイブできるのは、プロバイダーが公開している範囲だけです。Gmailの非表示ラベル、別のアカウント、オンラインアーカイブ、管理者の制限により、漏れが生じる場合があります。プロバイダーのWebアプリとアプリのフォルダ一覧を照合し、重要な各フォルダで最も古いメールと新しいメールをいくつか確認してください。Gmailのラベルの重複で、単純な件数が実態と合わないこともあります。同じメールが複数のラベルに表示されるためです。

アカウント別の手順は、GmailからEMLへ、OutlookからEMLへ、iCloud Mailの書き出しをご覧ください。Windows用アーカイブツールから移行する場合は、Mac向けMailStore代替アプリから始めてください。
