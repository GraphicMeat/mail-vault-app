MailStore Server の代わり：アーカイブを誰のために使うかで選ぶ

7分で読めます

このページは、MailStore Server の代わりを探しているすべての人のためのものです。MailStore Server は企業向けの有料版で、多くのメールボックスのための 1 つの中央アーカイブに、保持ルール、訴訟ホールド、監査ログを備えています。それが必要なら、正直な答えは別のサーバー製品、たとえば Piler、Mail-Archiver、Open Archiver か、Microsoft 365 や Google Workspace にすでに組み込まれた保持のツールです。MailVault はそのどれでもありません。1 人の自分のメールのためのデスクトップアプリです。無料の家庭向けの版と比べているなら、MailVault と MailStore Home の比較を読んでください。すべての選択肢の比較は MailStore の代わりの比較を参照してください。

手短な答え

  • コンプライアンス、保持、訴訟ホールドを備えた会社のアーカイブ：自社サーバー上の Piler Open Source Edition、Mail-Archiver、Open Archiver、またはメールがすでに Microsoft 365 や Google Workspace にあるなら Microsoft Purview と Google Vault。
  • 個人、または各自が自分のメールボックスを管理する小さなチーム：おそらくサーバーは要りません。MailVault のようなデスクトップのアーカイバーで十分です。

MailStore Server でできること

MailStore は Server を、中小企業向けのメールアーカイブソフトウェアと説明しています。現在の製品ページに記載されている内容は次のとおりです。

  • プラットフォーム：Windows 11 と Windows Server 2016〜2025。
  • 価格：5 ユーザーのスターターキットで 295 EUR（税別）から。1 年間の Standard Update & Support が付きます。最小注文数は 5 ユーザーで、1 つのインストールで最大 2,000 ユーザーまで対応します。30 日間の試用期間があります。
  • 取り込み元：Microsoft 365、Exchange Server、Google Workspace、あらゆる IMAP や POP3 のサーバー、PST と EML のファイル、そしてジャーナリング。ジャーナリングにより、メールがメールボックスに届く前にアーカイブできます。
  • コンプライアンス：保持ポリシー、訴訟ホールド、監査ログ、外部の監査人のための Auditor というユーザー種別。内容の SHA ハッシュ値を保存し、アーカイブを AES-256 で暗号化します。
  • アクセス：従業員は、Outlook のアドインか、スマートフォンでも使えるウェブインターフェイスからアーカイブを検索します。

MailStore は OpenText の子会社です。これらの機能こそ企業が購入する理由であり、本当の代わりになるものには、その大部分が必要です。

組織向けの MailStore Server の代わり

Piler

MailStore Server のコンプライアンスの面に最も近いオープンソースの選択肢は Piler です。Open Source Edition は無料です。SMTP でメールを受け取り、Office 365 と Google のアカウントを取り込み、EML、Maildir、メールボックスのファイルを読み、アーカイブと保持のルール、訴訟ホールド、監査ログ、重複排除、メッセージの暗号化を備えています。Enterprise Edition は価格帯が公開された有料版で、電子情報開示、マルチテナント、任意の有償サポートが加わります。

Mail-Archiver

Mail-Archiver（Mac アプリの Mail Archiver X ではありません）は、複数の人がアーカイブしたメールを検索できる 1 つのウェブページが欲しい小さなオフィスに向いています。IMAP のアカウントと、Microsoft Graph 経由で Microsoft 365 を同期し、MBOX と ZIP 圧縮した EML のファイルを読み込み、同じ形式で書き出します。ユーザーにはアカウントごとの権限が付き、OpenID Connect でサインインさせることもできます。アカウントごとに設定した期間が過ぎるとサーバーからメールを削除でき、1 つの設定でアーカイブからの手動での削除を禁止できます。HTTPS を自分では提供しないので、前段にリバースプロキシが必要です。

Open Archiver

Open Archiver は、Google Workspace、Microsoft 365、IMAP、そして PST、MBOX、EML のファイルを取り込みます。メッセージのテキストと PDF や DOCX などの添付ファイルをインデックス化し、変更を検出できるよう取り込み時に各メールのハッシュを保存し、監査証跡を残します。README では訴訟ホールドがまだ今後の対応とされているので、紛争のために頼る前に現在の状況を確認してください。

プロバイダーがすでに持っているツール

会社がすでに Microsoft 365 や Google Workspace に支払っているなら、まずそこを見てください。Microsoft Purview の保持ポリシーは、ユーザーが削除した後も、メールボックスの回復可能なアイテムのフォルダにメールボックスのアイテムのコピーを残し、電子情報開示で見つけられるようにします。必要な機能がどの Microsoft 365 のプランに含まれるか確認してください。Google Vault は、Gmail やほかの Workspace のデータの保持、ホールド、検索、書き出しを扱います。Google は、Vault はデータのアーカイブではないとはっきり述べています。ルールを設定するまでは何も保持せず、ホールドされていない期限切れのデータは通常どおり削除されます。

MailVault が答えにならないとき

私たちは MailVault を作っているので、はっきり言います。MailVault は MailStore Server の代わりにはなりません。次のものがありません。

  • 中央のアーカイブサーバーも、ユーザー間で共有するアーカイブもありません。
  • ほかの人のメールボックスへの管理者のアクセスも、ジャーナリングもありません。
  • 保持ポリシー、訴訟ホールド、監査証跡、監査人の役割はありません。
  • PST の読み込みはありません。

監査人、規制当局、法務チームが会社のメールについて質問してくるなら、上のサーバーの選択肢のどれかを選んでください。

MailVault が合う人

MailStore Server の代わりを探す人の多くは、サーバーをまったく必要としていません。メールボックスがいっぱいになった個人、クライアントとのすべてのスレッドを残したいフリーランス、各自が自分の受信トレイを管理する 3 人のチームなどです。そうした人にとって、サーバーは余計な手間です。動かすマシン、適用する更新、そしてアーカイブ自体のバックアップが必要になります。

MailVault は macOS・Windows・Linux 向けの無料のデスクトップアプリです。各自がインストールし、自分の Gmail、Microsoft 365、Outlook.com、または IMAP のアカウントにサインインして、メールのコピーを自分のコンピュータに保管します。MailVault のアカウントはなく、メールの経路に MailVault のサーバーは存在しません。ソースコードは GitHub で公開されています。このケースはフリーランスと小規模事業者のためのメールアーカイブガイドで詳しく説明しています。

MailVault でできること

プレーンなファイルによるローカルのアーカイブ

残すメッセージはすべて、Maildir 形式のフォルダに置かれた標準的な .eml ファイルで、1 通につき 1 ファイルなので、ほかのメールアプリでも開けます。保管庫は外付けドライブや NAS のマウント先に移せます。MailVault はすべてをコピーし、すべてのファイルが届いたことを確認してから、元のファイルを削除します。この移動は Mac App Store 版では使えません。バックアップの実行時に、選んだフォルダに 2 つ目のコピーを書き出すこともできます。

自分のコンピュータでの検索

ローカルの全文インデックスで、接続の有無にかかわらず、保存したすべてのメッセージを検索できます。送信者、日付、フォルダ、タグで絞り込めます。公開している検索テストでは、50,000 通のメッセージを対象にした最も遅い検索でも 14 ミリ秒でした。PDF や Office の添付ファイル内の検索は Premium の機能です。

バックアップ

すべてのアカウントの手動バックアップは無料で無制限です。フォルダごとのサーバー、ローカル、外部の件数表示を備えたスケジュールバックアップは Premium に含まれます。

間に確認を挟んで、アーカイブしてから削除

アーカイブはメールを保管庫にコピーし、サーバーのコピーには手を付けません。サーバーから削除はサーバーのコピーを削除します。どちらも無料です。アーカイブして削除（Premium）は両方をワンステップで行います。各メッセージを保管庫にコピーし、コピーがあることを確認し、そのあとで初めてサーバーから削除します。確認に通らなかったものはサーバーに残ります。アーカイブ・バックアップして削除（Premium）は、バックアップフォルダにもコピーを書き出し、何かを削除する前に両方のコピーを確認します。

サーバーなしの小さなチームの構成

同僚のメールを検索する必要が誰にもない 2〜5 人のチームなら、これで十分です。

  1. 各自が MailVault をインストールし、自分のアカウントを追加します。
  2. 各自が、設定のバックアップと復元で、外付け SSD や NAS の共有フォルダなど自分で管理するドライブに 2 つ目のコピーのフォルダを選びます。
  3. バックアップを実行してから、古い年をアーカイブします。サーバーから削除するのは保管庫にあるものだけにします。Premium なら、アーカイブして削除がその確認を代わりに行います。

あきらめるもの：ほかの人のアーカイブを検索することはできず、誰が何をしたかの中央の記録もありません。どちらかが必要なら、サーバーが必要です。

よくある質問

MailStore Server の無料の代わりはありますか？

はい、サーバーを運用できるなら。Piler Open Source Edition、Mail-Archiver、Open Archiver は無料のオープンソースのアーカイブサーバーで、Piler の無料版には保持ルール、訴訟ホールド、監査ログが含まれます。ライセンスは無料ですが、サーバーのインストール、更新、バックアップは自分で行います。

会社が MailStore Server の代わりに MailStore Home を使えますか？

MailStore によると、Home は家庭での個人利用なら無料で、商用利用には MailStore Server を案内しています。仕事で Home を使う前に、MailStore のライセンス条件を読んでください。

MailVault はコンプライアンスや訴訟ホールドのためのアーカイブですか？

いいえ。MailVault は、自分のメールの個人的なコピーを自分のコンピュータに残すものです。保持ポリシー、訴訟ホールド、監査証跡、中央のアーカイブはないので、コンプライアンスの目的では MailStore Server の代わりになりません。

Linux で動く MailStore Server の代わりはどれですか？

MailStore Server は Windows 11 と Windows Server で動きます。Mail-Archiver と Open Archiver は Docker で動き、Piler は Ubuntu 向けの .deb パッケージの作り方を説明しています。

次にすること

要件がコンプライアンスなら、サーバー製品の試用を始めるか、テスト用のマシンに Piler か Mail-Archiver を入れて 1 つのメールボックスをアーカイブしてください。1 人につき 1 つのメールボックスなら、MailVault を無料でダウンロードして、まず 1 つのアカウントで試してください。後からスケジュールバックアップやワンステップのアーカイブして削除が欲しくなったら、Premium は早期アクセス価格で月額 $4 または年額 $25 です（料金を参照）。
