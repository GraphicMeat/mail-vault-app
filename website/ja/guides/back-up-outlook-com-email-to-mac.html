Outlook.com と Hotmail のメールを Mac にバックアップする方法

9分で読めます · 2026年10月8日更新

Outlook.com や Hotmail のメールを Mac にバックアップする方法で、今使えるものは 4 つあります。従来の Outlook for Mac から .olm ファイルを書き出す、Apple Mail から .mbox ファイルを書き出す、アドオンを使って Thunderbird から書き出す、または MailVault ですべてのメッセージを .eml ファイルとして保存する方法です。このページではそれらを比較し、それぞれで何が得られるかを示し、頼る前にバックアップを確認する方法を説明します。バックアップの後にオンラインのメールを削除したいなら、Hotmail と Outlook.com の空き容量を増やす方法を読んでください。

手短な答え

  • 今あるもので、今日、コピーを 1 つ：Apple Mail にアカウントを追加し、メールボックス > メールボックスを書き出すを使います。
  • すでに Outlook for Mac を使っている：従来の Outlook から .olm ファイルを書き出します。
  • 最新の状態を保てて検索もできるコピー：MailVault（無料）または Thunderbird（無料）。
  • どれを選ぶにしても：オンラインで何かを削除する前に、バックアップから古いメールと添付ファイルを開いてください。

始める前に

  • Microsoft 自身の書き出しにはデスクトップ版の Outlook が必要です。Microsoft のヘルプページによると、Outlook.com のメールボックスはデスクトップ版の Outlook で書き出します。Windows なら .pst ファイル、従来の Outlook for Mac なら .olm ファイルです。Outlook を持っていない場合、Microsoft は Microsoft 365 の 30 日間の無料試用版をすすめています。
  • ほかのアプリは先進認証を使う必要があります。Microsoft によると、2024年9月16日以降、ほかのメールアプリが Outlook.com にアクセスするには、ユーザー名とパスワードだけでなく、先進認証（OAuth）を使う必要があります。Apple Mail、Thunderbird、MailVault はいずれも対応しています。
  • ディスクの空き容量を確認してください。Outlook.com で設定 > アカウント > ストレージを見てください。バックアップには、Mac にそれと同じくらいの空き容量が必要です。

方法 1：従来の Outlook for Mac（.olm ファイル）

  1. Outlook for Mac に Outlook.com のアカウントを追加し、同期が終わるのを待ちます。
  2. 従来の Outlook に切り替えます。Microsoft がエクスポートを説明しているのは従来の Outlook for Mac だけで、従来の Outlook for Mac のサポートは 2026年10月に終了するとしています。ヘルプページには新しい Outlook for Mac でのエクスポートの説明がないので、この方法に頼る前に Microsoft のページで現在の状況を確認してください。
  3. ツールタブでエクスポートを選びます。見当たらない場合はアップデートを確認してから、ファイルメニューを見てください。
  4. アーカイブ ファイル (.olm) にエクスポートで必要な項目にチェックを入れ、続行を選んで、ファイルの保存先を選びます。

得られるもの：メールと、チェックを入れた場合は連絡先とカレンダーを含む 1 つの .olm ファイルです。ツール > インポートで Outlook for Mac に取り込み直すためのものです。向いている人：すでに Outlook for Mac を使っている人。

方法 2：Apple Mail（.mbox ファイル）

  1. メールでメール > アカウントを追加を選び、Outlook.com のアドレスを入力して手順に従います。Microsoft によると、アカウントを Outlook.com として設定すれば、Apple Mail は先進認証を使います。
  2. メール > 設定 > アカウント > アカウント情報を選び、添付ファイルをダウンロードをすべてにします。メールは画像、PDF、ビデオ、オーディオを常にダウンロードします。最近の場合、ほかの種類の添付ファイルは過去 15 か月分しかダウンロードされません。
  3. すべてのフォルダのダウンロードが終わるまで待ちます。念のため、最も古いメールをいくつか開いてください。
  4. 1 つ以上のメールボックスを選び、メールボックス > メールボックスを書き出すを選びます。フォルダを選んで確定します。

得られるもの：メールボックスごとに 1 つの .mbox パッケージです。もう一度書き出すと、メールは古いファイルを置き換えず、My Mailbox 3.mbox のような新しいファイルを隣に作ります。後でバックアップを読むにはファイル > メールボックスを読み込むを使います。メッセージは読み込みという名前の新しいメールボックスに表示されます。向いている人：何もインストールせずに手早くコピーを取りたい人。書き出しはその時点のスナップショットなので、新しいメールには新しい書き出しが必要です。

方法 3：Thunderbird（.mbox または .eml ファイル）

  1. Thunderbird をインストールし、Outlook.com のアカウントを追加します。Mozilla の 2026 年のガイドでは、認証方式を OAuth2 にし、Thunderbird 自体の設定で Microsoft のサイトからの Cookie を許可するよう案内しています。
  2. アカウント設定 > 同期とディスク領域で、このアカウントのメッセージをこのコンピューターに保存するをオンにします。これがないと、Thunderbird はメッセージのヘッダーだけを保存し、残りはサーバーから取得します。
  3. すべてのフォルダをダウンロードさせます。
  4. ImportExportTools NG のアドオンをインストールします。フォルダを .mbox ファイルとして、またはフォルダ内のメッセージを .eml、HTML、PDF、CSV、プレーンテキストのファイルとして書き出せます。

向いている人：日々の利用にも使える、無料でオープンソースのメールアプリが欲しい人。職場や学校のアカウントでは、先に管理者が Thunderbird を承認する必要がある場合があります。

方法 4：MailVault（検索できる .eml ファイル）

MailVault は、メールのコピーをコンピュータ上の保管庫に保管する、macOS・Windows・Linux 向けの無料のメールアプリです。MailVault のアカウントはなく、メールが MailVault のサーバーを通ることもありません。以下の手順は、私たちのウェブサイトからダウンロードする版のものです。Mac App Store 版は、バックアップ設定や保管庫の移動など、いくつかの点で異なります。

Outlook.com のアカウントを接続する

  1. MailVault をダウンロードして開きます。Outlook.com のアカウントのアーカイブを修正したバージョン 2.19.1 以降を使ってください。
  2. アカウントを追加を選び、Outlook / Microsoft 365 を選んで、アドレスを入力します。
  3. Microsoft でサインインを選びます。ブラウザで Microsoft のサインインページが開きます。戻ってくると、MailVault が自動的にアカウントを追加します。

MailVault は outlook.com、hotmail.com、live.com のアドレス（と地域ごとの版）を認識し、Microsoft のメール API である Microsoft Graph 経由で接続します。IMAP の設定やアプリパスワードを入力する必要はありません。職場や学校の Microsoft 365 のアカウントは、代わりに IMAP 上の OAuth2 でサインインします。ルールの厳しい組織は、詳細設定（法人向け）で独自のクライアント ID とテナント ID を設定できます。

バックアップを作る

  1. 設定 > バックアップと復元 > バックアップ設定を開きます。
  2. バックアップの対象ですべてのメール（サーバーから取得）を選びます。もう一方のアーカイブ済みメールのみは、すでに保管庫にあるメールだけをコピーします。
  3. 外付けドライブがあるなら、2 つ目のコピーのフォルダを選んでください。MailVault が日常的には読まない、別のコピーです。
  4. バックアップのスケジュールタブですべてのアカウントを今すぐバックアップを選びます。手動バックアップは無料で、上限はありません。

得られるもの：アカウントとフォルダごとに整理された Maildir のフォルダに、1 通につき 1 つの .eml ファイル。Mac での既定の場所は ~/Library/Containers/com.mailvault.app/Data/Library/Application Support/com.mailvault.app/ です。Mac App Store 版を除き、保管庫は別のドライブに移せます。2 回目以降のバックアップは差分で、新しいメールだけがダウンロードされます。メールは MailVault で検索でき、オフラインでも使えます。

無料と Premium：アカウントの接続、閲覧、検索、アーカイブ、手動バックアップは無料です。スケジュール自動バックアップ、バックアップの健全性チェック、すべて保存（すべてのフォルダと全期間のメールをバックグラウンドでダウンロードして保存します）、ワンステップのアーカイブして削除は Premium で、現在は早期アクセス価格で月額 $4 または年額 $25 です。

Outlook.com のアカウントの既知の制限：これらのアカウントは Microsoft Graph を使うため、スヌーズはまだ使えず、MBOX ファイルをサーバーに復元できず、削除したメールはコンピュータには復元できてもサーバーには戻せず、接続テストの後の受信トレイの件数は表示されません。閲覧、削除、移動、マーク、バックアップは、ほかのアカウントと同じように使えます。

バックアップが完全か確認する方法

  1. 件数を比べます。Outlook.com で大きなフォルダごとのメールの件数を書き留め、バックアップと比べてください。MailVault では、各フォルダのヘッダーに、そのメールのうち何件が保管庫にあるかが表示されます。たとえば保管庫に 79 / 79 のようにです。すべてのフォルダのサーバーと保管庫の件数の表は Premium（バックアップの健全性チェック）に含まれます。
  2. 最近のメールだけでなく、最も古いメールを開きます。抜けが隠れているのは古いフォルダです。
  3. PDF、写真、Office の文書など、何種類かの添付ファイルを開きます。
  4. 名前や注文番号など、何年も前の覚えているものを検索します。
  5. 作ったアプリの外でファイルを開きます。.eml ファイルはダブルクリックすると Apple Mail で開きます。.mbox はファイル > メールボックスを読み込むで読み込みます。
  6. 別のドライブに2 つ目のコピーを置きます。1 台のノートパソコンにコピーが 1 つだけでは、バックアップとは言えません。

よくある質問

Outlook なしで Hotmail のメールを Mac に書き出せますか？

はい。Apple Mail は Outlook.com のメールをダウンロードし、各メールボックスを .mbox ファイルとして書き出せます。Thunderbird も書き出し用のアドオンで同じことができ、MailVault は各メッセージを .eml ファイルとして保存します。Microsoft 自身の書き出しにはデスクトップ版の Outlook が必要です。

メールのバックアップに最適なファイル形式は？

ほかのアプリで開ける形式です。.eml ファイルは 1 通のメッセージを添付ファイルごと収め、.mbox ファイルはメールボックス全体を収めます。Apple Mail は .eml ファイルを開け、.mbox ファイルを読み込めます。.olm ファイルは Outlook for Mac に取り込み直すためのものです。

MailVault は Hotmail や Live.com のアドレスでも使えますか？

はい。MailVault は outlook.com、hotmail.com、live.com のアドレスを個人の Microsoft アカウントとして扱います。ブラウザで Microsoft にサインインすると、MailVault は Microsoft Graph 経由で接続するので、入力する IMAP の設定はありません。

メールのバックアップは最新の状態に保たれますか？

Apple Mail や Outlook からの書き出しはその時点のスナップショットなので、新しいメールを含めるにはもう一度書き出します。MailVault ではバックアップをもう一度実行すれば、新しいメールだけがダウンロードされます。スケジュール自動バックアップは MailVault Premium に含まれます。

Outlook.com にはまだ「メールボックスのエクスポート」ボタンがありますか？

Microsoft の現在のヘルプページでは、デスクトップ版の Outlook による書き出しだけを説明しています。古いガイドには、Outlook.com の設定にある「メールボックスのエクスポート」ボタンが出てきます。自分のアカウントで見当たらない場合は、このページの方法のどれかを使ってください。

次にすること

方法を 1 つ選んで今週のうちに最初のコピーを作り、上の一覧で確認してください。メールボックスがすでにいっぱいなら、届いたメールが送信者に戻されないよう、先にOutlook のストレージがいっぱいになったときの対処法を読んでください。Outlook.com や Hotmail のメールボックスがいっぱいの短い概要と、プロバイダーを問わないメールの容量を空けるガイドでは、ローカルのコピーがあればメールを失わずにオンラインで削除できる仕組みを説明しています。ローカルのコピーと大きなプランを比べるには、ローカルでのアーカイブとストレージの追加購入の比較を参照してください。

無料で、ソースコードは GitHub で公開。各メールはディスク上のプレーンな .eml ファイルです。手動バックアップは無料、スケジュールバックアップは Premium です。
