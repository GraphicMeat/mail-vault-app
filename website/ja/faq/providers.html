メールプロバイダ

Gmail、Microsoft 365、Outlook.com、Proton Mailの接続と、エイリアスからの送信について。

MailVaultはGmailやOutlookで使えますか？

はい。MailVault は Gmail、Outlook、そのほか IMAP に対応したあらゆるメールサービスで使えます。Gmail では OAuth2 で Google アカウントから直接サインインでき、IMAP の手動設定は不要です。Microsoft 365 Business と Enterprise のアカウントは OAuth2 で Microsoft アカウントから直接サインインでき、2 段階認証ともそのまま使えます。個人の Outlook.com、Hotmail、Live.com のアカウントは Microsoft Graph API 経由で接続します。

Outlook.com のアカウントを接続するには？

MailVault は、個人の Outlook.com、Hotmail、Live.com のアカウントを Microsoft Graph API 経由で接続します。アカウントを追加し、「Microsoft でサインイン」を選んで、ブラウザでサインインを完了してください。MailVault は個人の Microsoft アカウントを認識して自動的に Graph を使うので、入力する IMAP の設定はありません。

これらのアカウントで IMAP を使わないのは、2024 年後半に始まった、OAuth2 でのサインインに関する Microsoft の IMAP の問題があるためです。メールの閲覧、削除、既読・未読の設定、移動、バックアップは、ほかのアカウントと同じように使えます。

Graph のアカウントでまだ使えないもの：

  • スヌーズ
  • MBOX ファイルをサーバーに復元すること
  • 削除したメールのサーバーに復元。ローカルに復元は、すでにこのコンピュータにあるメールに対して使えます
  • 接続テストの後にアカウント追加ウインドウが表示する受信トレイの件数

Microsoft 365 Business と Enterprise のアカウントは OAuth2 による IMAP を使うため、これらの制限は受けません。このサインインは Mozilla Thunderbird と同じ方式で、PKCE と XOAUTH2 の認証を使います。

Proton MailでMailVaultを使うにはどうすればよいですか？

Proton Mailはメールを端から端まで暗号化するため、IMAPを直接には公開していません。MailVault（やほかの第三者のメールクライアント）につなぐにはProton Mail Bridgeが必要です — Protonが提供するデスクトップアプリで、自分のコンピューター上で動き、暗号化されたメールボックスを127.0.0.1の標準的なIMAPとSMTPとして見せます。Bridgeには有料のProton Mailのプランが必要で、Protonの無料の枠では使えません。

設定の手順:

  1. ProtonのウェブサイトからProton Mail Bridgeをインストールします
  2. Protonアカウントで Bridge にサインインします
  3. BridgeはアカウントごとのIMAP／SMTPの認証情報を表示します — 表示されるパスワードはBridgeが生成したアプリパスワードで、いつものProtonのアカウントのパスワードではありません
  4. MailVaultで、プロバイダーの一覧から Proton Mail Bridge を選びます（一覧にない場合は Custom IMAP ）。そして次を入力します:
    • サーバー: 127.0.0.1
    • IMAPのポート: 1143、セキュリティ: STARTTLS
    • SMTPポート: 1025
    • ユーザー名: Protonのメールアドレス
    • パスワード: 手順3でBridgeが生成したパスワード

MailVaultが同期するあいだ、Proton Mail Bridgeは背後で動いている必要があります — Bridgeが閉じていると、MailVaultはメールボックスに届きません。すでにアーカイブしたメールは、Bridgeが閉じていてもMailVaultの中でそのまま読め、検索できます。MailVaultはローカルを主とし、Bridgeから直接ではなく自身の.emlの保存領域から読むからです。

Bridgeは、自身のローカルのIMAPとSMTPのサーバーを自己署名のTLS証明書で保護します。MailVaultはローカル（127.0.0.1）の接続についてこれを自動で扱うので、証明書を手でインストールする必要はありません。

ログインに使うアドレスとは別のアドレスから送信できますか？

はい。エイリアスから送信するには？の説明どおりにアドレスをアカウントのエイリアスとして追加し、メールを書くときに送信者の行で選ぶか、既定にします。Fastmailや、サインインに使うアドレスと人に伝えるアドレスが違う提供元では、よくあることです。

変わるのは、送信するメールのFromのアドレスだけです。ユーザー名とパスワードはそのままで、MailVaultは設定したアカウントとしてIMAPとSMTPにサインインし続けます。また、Reply-Toのヘッダーは追加されません — 返信は、送信に使ったアドレスへ届きます。

エイリアスから送信するには？

設定 → アカウントを開き、アカウントを選んでエイリアスのセクションに進みます。アカウントが送信に使うすべてのアドレスが、ログインアドレス、続いて各エイリアスの順に並びます。新しいメッセージの送信者の行にあるアドレスを追加リンクからも同じセクションが開きます。

エイリアスの追加と設定:

  • Google アカウント: Google でサインインした場合、Gmail で送信が許可されているアドレスを MailVault が取得して一覧にします。
  • その他の提供元: 送信に使ったアドレスやメールが届くアドレスなど、あなた自身のメールで見つかったアドレスを MailVault が提案します。どのアドレスも手動で追加できます。
  • 名前: 各エイリアスに受信者に表示する名前を付けます。エイリアスから送るメールはその名前で送信されます。
  • 既定: 新しいメッセージをどのアドレスで始めるかを選びます。
  • 確認: エイリアスからテストメッセージを 1 通送り、使い始める前に提供元が受け付けるかどうかを確かめられます。

そのアドレスは提供元で許可されている必要があります:

  • Fastmail: 先に Fastmail でアドレスをエイリアスまたは ID として追加します。
  • Gmail: Gmail の 設定 → アカウントとインポート → Send mail as で追加します。
  • Microsoft 365 と Outlook.com: エイリアスは Microsoft アカウントで追加します。追加するのはあなた自身か、職場または学校のアカウントでは管理者です。

変わるのは差出人のアドレスと名前だけです。MailVault は設定したアカウントでサインインし続け、Reply-To ヘッダーは追加されないため、返信はエイリアスに届きます。
