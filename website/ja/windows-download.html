Windows版 MailVault

ダウンロードを開始しています。

インストーラーをダウンロードしています。完了したら、ダウンロード フォルダーから開いてください。その前に Windows が確認を求めることがあります。このページでは、その理由と、ファイルが私たちのものか確かめる方法を説明します。

Windows版をダウンロード

ダウンロードが始まらない場合は、上のボタンを使ってください。

Windows が警告を表示することがある理由

ダウンロードしたインストーラーはすべて Microsoft Defender SmartScreen がチェックします。見るのは 2 点です。誰がファイルに署名したか、そしてどれだけの人がすでにダウンロードして実行したかです。

MailVault のインストーラーは、Microsoft 自身の署名サービスである Azure Artifact Signing で署名されています。Microsoft は企業の身元を確認してからでないと署名を許可せず、Windows はインストーラーを実行する前に署名が改ざんされていないことを確認します。

時間がかかるのは評判のほうです。Windows版 MailVault は新しく、リリースごとに新しいファイルになるため、SmartScreen がまだ認識しておらず「Windows によって PC が保護されました」と表示することがあります。これはファイルがまだ広く知られていないという意味で、有害なものが見つかったという意味ではありません。

  1. ブラウザーに確認された場合

    Edge では、ファイルが「一般的にダウンロードされていません」と表示されることがあります。ダウンロード メニューを開き、ファイルの横の 3 つの点から「保存」を選んでください。

  2. SmartScreen が表示された場合

    「詳細情報」をクリックします。発行元が MailVault の開発元である MODERNIOS APLIKACIJOS になっていることを確認し、「実行」をクリックします。

  3. 発行元が違う場合

    「不明な発行元」やほかの名前が表示された場合は、ファイルを実行しないでください。削除して、このページからもう一度ダウンロードしてください。

ご自身で確かめる

私たちの言葉をそのまま信じる必要はありません。インストーラーを右クリックして「プロパティ」を選び、「デジタル署名」タブを開くと MODERNIOS APLIKACIJOS が表示され、「詳細」で署名に問題がないことを確認できます。

GitHub の各リリースには、ファイルごとに SHA-256 チェックサムも記載されています。PowerShell でインストーラーに対して Get-FileHash を実行し、2 つの値を比べてください。
