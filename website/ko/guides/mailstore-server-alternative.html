MailStore Server 대안: 보관본이 누구를 위한 것인지로 고르기

7분 분량

이 페이지는 MailStore Server 대안을 찾는 모든 분을 위한 것입니다. MailStore Server는 회사용 유료판입니다. 여러 메일함을 위한 하나의 중앙 보관 시스템이며, 보존 규칙, 소송 보존, 감사 로그를 갖추고 있습니다. 필요한 것이 그것이라면 솔직한 답은 다른 서버 제품입니다. Piler, Mail-Archiver, Open Archiver, 또는 Microsoft 365와 Google Workspace에 이미 들어 있는 보존 도구입니다. MailVault는 거기에 속하지 않습니다. 한 사람의 자기 메일을 위한 데스크톱 앱입니다. 무료 Home판과 비교하고 있다면 MailVault vs MailStore Home을 읽으십시오. 모든 선택지를 나란히 보려면 MailStore 대안 비교를 보십시오.

빠른 답

  • 규정 준수, 보존, 소송 보존을 갖춘 회사용 보관 시스템: 자체 서버의 Piler Open Source Edition, Mail-Archiver, Open Archiver, 또는 메일이 이미 Microsoft 365나 Google Workspace에 있다면 Microsoft Purview와 Google Vault.
  • 개인, 또는 각자 자기 메일함을 관리하는 작은 팀: 아마 서버는 필요 없을 것입니다. MailVault 같은 데스크톱 보관 도구로 충분합니다.

MailStore Server가 하는 일

MailStore는 Server를 중소기업을 위한 메일 보관 소프트웨어라고 소개합니다. 현재 제품 페이지에 나와 있는 내용은 다음과 같습니다.

  • 플랫폼: Windows 11과 Windows Server 2016~2025.
  • 가격: 사용자 5명용 스타터 키트가 295 EUR(부가세 별도)부터이며, 1년간의 Standard Update & Support가 포함됩니다. 최소 주문은 사용자 5명이고, 설치 하나로 사용자 2,000명까지 지원합니다. 30일 체험판이 있습니다.
  • 원본: Microsoft 365, Exchange Server, Google Workspace, 모든 IMAP 또는 POP3 서버, PST와 EML 파일, 그리고 메일이 메일함에 닿기 전에 보관할 수 있는 저널링.
  • 규정 준수: 보존 정책, 소송 보존, 감사 로그, 외부 감사인을 위한 Auditor 사용자 유형. 내용의 SHA 해시 값을 저장하고 보관본을 AES-256으로 암호화합니다.
  • 접근: 직원들은 Outlook 추가 기능이나 휴대전화에서도 작동하는 웹 인터페이스로 보관본을 검색합니다.

MailStore는 OpenText의 자회사입니다. 회사들이 이 제품을 사는 이유가 이런 기능이며, 진짜 대체품이라면 대부분을 갖춰야 합니다.

Piler

Piler는 MailStore Server의 규정 준수 측면에 가장 가까운 오픈소스 대안입니다. Open Source Edition은 무료입니다. SMTP로 메일을 받고, Office 365와 Google 계정을 받아들이며, EML, Maildir, 메일함 파일을 읽고, 보관 및 보존 규칙, 소송 보존, 감사 로그, 중복 제거, 메시지 암호화를 갖추고 있습니다. Enterprise Edition은 가격 등급이 공개된 유료판이며, eDiscovery, 멀티 테넌시, 선택형 유료 지원을 더합니다.

Mail-Archiver

Mail-Archiver(Mac 앱 Mail Archiver X와는 다름)는 여러 사람이 보관된 메일을 검색하는 웹 페이지 하나를 원하는 작은 사무실에 맞습니다. IMAP 계정과, Microsoft Graph를 통한 Microsoft 365를 동기화하고, MBOX와 압축된 EML 파일을 가져오며, 같은 형식으로 내보냅니다. 사용자는 계정별 권한을 받고, OpenID Connect로 로그인할 수 있습니다. 계정마다 정한 기간이 지나면 서버에서 메일을 지울 수 있고, 설정 하나로 보관본에서의 수동 삭제를 막을 수 있습니다. 자체적으로 HTTPS를 제공하지 않으므로 앞에 리버스 프록시가 필요합니다.

Open Archiver

Open Archiver는 Google Workspace, Microsoft 365, IMAP, 그리고 PST, MBOX, EML 파일을 받아들입니다. 메시지 텍스트와 PDF, DOCX 같은 첨부 파일을 색인하고, 변경을 감지할 수 있도록 받아들일 때 메일마다 해시를 저장하며, 감사 기록을 남깁니다. README에는 소송 보존이 아직 할 일로 나와 있으므로, 분쟁에 대비해 의존하기 전에 현재 상태를 확인하십시오.

제공업체가 이미 갖춘 도구

회사가 이미 Microsoft 365나 Google Workspace에 비용을 내고 있다면 거기부터 보십시오. Microsoft Purview 보존 정책은 사용자가 지운 뒤에도 메일함 항목의 사본을 메일함의 복구 가능한 항목 폴더에 보존하며, eDiscovery로 여전히 찾을 수 있습니다. 필요한 기능이 어느 Microsoft 365 요금제에 들어 있는지 확인하십시오. Google Vault는 Gmail과 다른 Workspace 데이터의 보존, 보존 조치, 검색, 내보내기를 처리합니다. Google은 Vault가 데이터 보관소가 아니라고 분명히 말합니다. 규칙을 정하기 전까지는 아무것도 보존하지 않고, 보존 조치가 걸리지 않은 만료 데이터는 평소처럼 삭제됩니다.

MailVault가 답이 아닐 때

MailVault는 저희가 만들기에 분명히 말씀드립니다. MailVault는 MailStore Server를 대신하지 못합니다. MailVault에는 다음이 없습니다.

  • 중앙 보관 서버도, 사용자 간에 공유하는 보관본도 없습니다.
  • 다른 사람의 메일함에 대한 관리자 접근도, 저널링도 없습니다.
  • 보존 정책, 소송 보존, 감사 기록, 감사인 역할이 없습니다.
  • PST 가져오기가 없습니다.

감사인, 규제 기관, 또는 법무팀이 회사 메일에 관해 질문할 일이 있다면 위의 서버 선택지 중 하나를 고르십시오.

MailVault가 맞는 사람

MailStore Server 대안을 찾는 사람 중 많은 이들에게는 서버가 전혀 필요 없습니다. 메일함이 가득 찬 개인, 모든 고객 스레드를 간직하고 싶은 프리랜서, 각자 자기 받은편지함을 챙기는 세 명짜리 팀입니다. 이들에게 서버는 일거리만 늘립니다. 돌려야 할 컴퓨터, 적용해야 할 업데이트, 그리고 보관본 자체의 백업.

MailVault는 macOS, Windows, Linux용 무료 데스크톱 앱입니다. 각자 설치하고, 자기 Gmail, Microsoft 365, Outlook.com, IMAP 계정에 로그인해, 메일 사본을 자기 컴퓨터에 간직합니다. MailVault 계정이 없고 메일이 오가는 경로에 MailVault 서버도 없으며, 소스 코드는 GitHub에 있습니다. 이 경우는 프리랜서와 소규모 사업자를 위한 메일 보관 가이드에서 더 자세히 다룹니다.

MailVault가 하는 일

일반 파일로 된 로컬 보관본

간직하는 모든 메시지는 Maildir 방식 폴더 안의 표준 .eml 파일이며, 메일 한 통에 파일 하나이므로 다른 메일 앱에서도 열 수 있습니다. 볼트는 외장 드라이브나 NAS 마운트로 옮길 수 있습니다. MailVault가 모든 것을 복사하고, 파일이 모두 도착했는지 확인한 다음에야 원본을 지웁니다. 이 옮기기는 Mac App Store판에서는 쓸 수 없습니다. 백업을 실행할 때 고른 폴더에 두 번째 사본을 쓸 수도 있습니다.

내 컴퓨터에서 검색

로컬 전문 인덱스가 연결이 있든 없든 저장된 모든 메시지를 검색합니다. 보낸 사람, 날짜, 폴더, 태그로 범위를 좁힐 수 있습니다. 저희가 공개한 검색 시험에서 메시지 50,000개를 대상으로 가장 느린 검색이 14밀리초였습니다. PDF와 Office 첨부 파일 내부 검색은 Premium 기능입니다.

백업

모든 계정의 수동 백업은 무료이고 무제한입니다. 폴더마다 서버, 로컬, 외부 개수를 보여 주는 예약 백업은 Premium에 들어 있습니다.

보관, 확인, 그리고 삭제

보관은 메일을 볼트에 복사하고 서버 사본은 건드리지 않습니다. 서버에서 삭제는 서버 사본을 지웁니다. 둘 다 무료입니다. 보관 후 삭제(Premium)는 둘을 한 번에 합니다. 메시지를 하나씩 볼트에 복사하고, 사본이 있는지 확인한 다음에야 서버에서 지웁니다. 확인을 통과하지 못한 메시지는 서버에 남습니다. 보관, 백업 후 삭제(Premium)는 백업 폴더에도 사본을 쓰고, 무엇이든 지우기 전에 두 사본을 모두 확인합니다.

서버 없는 작은 팀 구성

동료의 메일을 검색할 필요가 없는 2~5명 팀이라면 이것으로 충분합니다.

  1. 각자 MailVault를 설치하고 자기 계정을 추가합니다.
  2. 각자 설정, 백업 및 복원에서 외장 SSD나 NAS 공유 폴더처럼 자신이 관리하는 드라이브에 두 번째 사본 폴더를 정합니다.
  3. 백업을 실행한 다음 오래된 연도를 보관합니다. 서버에서는 볼트에 있는 것만 지웁니다. Premium에서는 보관 후 삭제가 그 확인을 대신 해 줍니다.

포기하는 것: 한 사람이 다른 사람의 보관본을 검색할 수 없고, 누가 무엇을 했는지에 대한 중앙 기록이 없습니다. 둘 중 하나라도 필요하다면 서버가 필요합니다.

자주 묻는 질문

MailStore Server의 무료 대안이 있습니까?

예, 서버를 운영할 수 있다면 있습니다. Piler Open Source Edition, Mail-Archiver, Open Archiver는 무료 오픈소스 보관 서버이며, Piler 무료판에는 보존 규칙, 소송 보존, 감사 로그가 들어 있습니다. 라이선스 비용은 없지만 서버 설치, 업데이트, 백업은 직접 해야 합니다.

회사가 MailStore Server 대신 MailStore Home을 써도 됩니까?

MailStore는 Home이 가정의 개인 용도로 무료라고 하며, 상업적 용도에는 MailStore Server를 안내합니다. 업무에 Home을 쓰기 전에 MailStore의 라이선스 조건을 읽으십시오.

MailVault는 규정 준수용 또는 소송 보존용 보관 시스템입니까?

아니요. MailVault는 자신의 메일의 개인 사본을 자신의 컴퓨터에 간직합니다. 보존 정책, 소송 보존, 감사 기록, 중앙 보관본이 없으므로 규정 준수 목적으로 MailStore Server를 대신하지 못합니다.

어떤 MailStore Server 대안이 Linux에서 실행됩니까?

MailStore Server는 Windows 11과 Windows Server에서 실행됩니다. Mail-Archiver와 Open Archiver는 Docker에서 실행되고, Piler는 Ubuntu용 .deb 패키지를 만드는 방법을 문서로 제공합니다.

다음에 할 일

요구 사항이 규정 준수라면 서버 제품의 체험판을 시작하거나, 시험용 컴퓨터에 Piler나 Mail-Archiver를 올려 메일함 하나를 보관해 보십시오. 한 사람에 메일함 하나라면 MailVault를 무료로 다운로드하고 먼저 계정 하나로 써 보십시오. 나중에 예약 백업이나 한 번에 하는 보관 후 삭제를 원하면 Premium은 얼리 액세스 가격으로 월 $4 또는 연 $25입니다(가격 참고).
