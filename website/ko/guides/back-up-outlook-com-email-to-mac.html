Outlook.com과 Hotmail 메일을 Mac에 백업하는 방법

9분 분량 · 2026년 10월 8일 업데이트

지금 쓸 수 있는, Outlook.com이나 Hotmail 메일을 Mac에 백업하는 방법은 네 가지입니다. 기존 Mac용 Outlook에서 .olm 파일을 내보내거나, Apple Mail에서 .mbox 파일을 내보내거나, 추가 기능을 써서 Thunderbird에서 내보내거나, MailVault가 모든 메시지를 .eml 파일로 저장하게 하는 것입니다. 이 페이지는 네 가지를 비교하고, 각각 무엇을 얻는지 보여 주고, 백업에 의존하기 전에 확인하는 방법을 설명합니다. 백업한 뒤 온라인에서 메일을 지우고 싶다면 Hotmail과 Outlook.com의 공간을 비우는 방법을 읽으십시오.

빠른 답

  • 지금 가진 것으로 오늘 사본 하나: 계정을 Apple Mail에 추가한 다음 메일상자 > 메일상자 내보내기를 쓰십시오.
  • 이미 Mac용 Outlook을 쓴다면: 기존 Outlook에서 .olm 파일을 내보내십시오.
  • 최신 상태로 유지하고 검색할 수 있는 사본: MailVault(무료) 또는 Thunderbird(무료).
  • 무엇을 고르든: 온라인에서 무언가를 지우기 전에 백업에서 오래된 메일과 첨부 파일을 열어 보십시오.

시작하기 전에

  • Microsoft의 자체 내보내기에는 데스크톱 Outlook이 필요합니다. Microsoft 도움말 페이지에 따르면 Outlook.com 메일함은 데스크톱 버전 Outlook으로 내보냅니다. Windows에서는 .pst 파일, 기존 Mac용 Outlook에서는 .olm 파일입니다. Outlook이 없다면 Microsoft는 30일 무료 Microsoft 365 체험판을 권합니다.
  • 다른 앱은 최신 로그인 방식을 써야 합니다. Microsoft에 따르면 2024년 9월 16일부터 다른 메일 앱은 사용자 이름과 비밀번호만이 아니라 최신 로그인 방식(OAuth)으로 Outlook.com에 접속해야 합니다. Apple Mail, Thunderbird, MailVault 모두 이를 지원합니다.
  • 디스크 공간을 확인하십시오. Outlook.com에서 설정 > 계정 > 스토리지를 보십시오. 백업에는 Mac에 대략 그만큼의 여유 공간이 필요합니다.

방법 1: 기존 Mac용 Outlook(.olm 파일)

  1. Outlook.com 계정을 Mac용 Outlook에 추가하고 동기화가 끝날 때까지 기다리십시오.
  2. 기존 Outlook으로 전환하십시오. Microsoft는 기존 Mac용 Outlook의 내보내기만 안내하며, 기존 Mac용 Outlook 지원이 2026년 10월에 끝난다고 밝힙니다. 도움말 페이지는 새 Mac용 Outlook의 내보내기를 설명하지 않으므로, 이 방법에 의존하기 전에 Microsoft 페이지에서 현재 상태를 확인하십시오.
  3. 도구 탭에서 내보내기를 고르십시오. 보이지 않으면 업데이트를 확인한 다음 파일 메뉴를 보십시오.
  4. Export to Archive File (.olm)에서 원하는 항목을 선택하고 Continue를 고른 다음 파일을 저장할 위치를 고르십시오.

얻는 것: 메일이 담긴 .olm 파일 하나이며, 선택했다면 연락처와 캘린더도 들어 있습니다. 도구 > 가져오기로 Mac용 Outlook에 다시 가져오도록 만들어진 파일입니다. 적합한 사람: 이미 Mac용 Outlook을 쓰는 사람.

방법 2: Apple Mail(.mbox 파일)

  1. Mail에서 Mail > 계정 추가를 고르고, Outlook.com 주소를 입력한 뒤 단계를 따르십시오. Microsoft에 따르면 계정을 Outlook.com으로 설정하면 Apple Mail이 최신 로그인 방식을 씁니다.
  2. Mail > 설정 > 계정 > 계정 정보를 고르고 첨부 파일 다운로드를 모두로 설정하십시오. Mail은 사진, PDF, 동영상, 오디오는 항상 내려받습니다. 최근으로 두면 다른 종류의 첨부 파일은 지난 15개월 치만 내려받습니다.
  3. 모든 폴더가 내려받아질 때까지 기다리십시오. 확실히 하려면 가장 오래된 메일 몇 통을 열어 보십시오.
  4. 메일상자를 하나 이상 선택하고 메일상자 > 메일상자 내보내기를 고르십시오. 폴더를 고르고 확인하십시오.

얻는 것: 메일상자마다 .mbox 패키지 하나. 다시 내보내면 Mail은 기존 파일을 바꾸지 않고 My Mailbox 3.mbox처럼 그 옆에 새 파일을 만듭니다. 나중에 백업을 읽으려면 파일 > 메일상자 가져오기를 쓰십시오. 메시지는 가져오기라는 새 메일상자에 나타납니다. 적합한 사람: 아무것도 설치하지 않고 빠르게 사본을 만들고 싶은 사람. 내보내기는 매번 스냅샷이므로 새 메일이 오면 다시 내보내야 합니다.

방법 3: Thunderbird(.mbox 또는 .eml 파일)

  1. Thunderbird를 설치하고 Outlook.com 계정을 추가하십시오. Mozilla의 2026년 가이드는 인증 방식을 OAuth2로 설정하고, Thunderbird 자체 설정에서 Microsoft 사이트의 쿠키를 허용하라고 안내합니다.
  2. 계정 설정 > 동기화 및 저장 공간에서 이 컴퓨터에 이 계정의 메시지 보관을 켜십시오. 이것을 켜지 않으면 Thunderbird는 메시지 헤더만 두고 나머지는 서버에서 가져옵니다.
  3. 모든 폴더가 내려받아지게 두십시오.
  4. ImportExportTools NG 추가 기능을 설치하십시오. 폴더를 .mbox 파일로 내보내거나, 폴더 안의 메시지를 .eml, HTML, PDF, CSV, 일반 텍스트 파일로 내보냅니다.

적합한 사람: 무료 오픈소스 메일 앱을 일상적으로도 쓰고 싶은 사람. 회사나 학교 계정은 관리자가 먼저 Thunderbird를 승인해야 할 수 있습니다.

방법 4: MailVault(검색할 수 있는 .eml 파일)

MailVault는 macOS, Windows, Linux용 무료 메일 앱으로, 메일 사본을 컴퓨터의 볼트에 간직합니다. MailVault 계정이 없고, 메일이 MailVault 서버를 거치지 않습니다. 아래 단계는 저희 웹사이트에서 내려받는 버전 기준입니다. Mac App Store판은 백업 설정과 볼트 옮기기 등 몇 군데가 다릅니다.

Outlook.com 계정 연결하기

  1. MailVault를 다운로드하고 여십시오. Outlook.com 계정의 보관 문제를 고친 버전 2.19.1 이상을 쓰십시오.
  2. 계정 추가를 고른 다음 Outlook / Microsoft 365를 고르고 주소를 입력하십시오.
  3. Microsoft 계정으로 로그인을 선택하십시오. 브라우저에서 Microsoft 로그인 페이지가 열립니다. 돌아오면 MailVault가 알아서 계정을 추가합니다.

MailVault는 outlook.com, hotmail.com, live.com 주소(와 지역별 주소)를 알아보고 Microsoft의 메일 API인 Microsoft Graph로 연결합니다. IMAP 설정이나 앱 암호를 입력하지 않습니다. 회사와 학교의 Microsoft 365 계정은 대신 IMAP 위에서 OAuth2로 로그인하며, 규정이 엄격한 조직은 고급(기업용)에서 자체 클라이언트 ID와 테넌트 ID를 설정할 수 있습니다.

백업 만들기

  1. 설정 > 백업 및 복원 > 백업 설정을 여십시오.
  2. 백업 대상에서 모든 메일(서버에서 내려받기)를 고르십시오. 다른 선택지인 보관된 메일만은 이미 볼트에 있는 메일만 복사합니다.
  3. 외장 드라이브가 있다면 두 번째 사본용 폴더를 고르십시오. MailVault가 평소에 읽지 않는 별도의 사본입니다.
  4. 백업 일정 탭에서 모든 계정 지금 백업을 선택하십시오. 수동 백업은 무료이며 한도가 없습니다.

얻는 것: 계정과 폴더별로 정리된 Maildir 폴더 안에 메시지마다 .eml 파일 하나. Mac의 기본 위치는 ~/Library/Containers/com.mailvault.app/Data/Library/Application Support/com.mailvault.app/입니다. Mac App Store판을 제외하면 볼트를 다른 드라이브로 옮길 수 있습니다. 이후 백업은 증분 방식이라 새 메일만 내려받습니다. 메일은 MailVault에서 오프라인으로도 검색됩니다.

무료와 Premium: 계정 연결, 읽기, 검색, 보관, 수동 백업은 무료입니다. 예약 자동 백업, 백업 상태 점검, 모두 보관(모든 폴더와 전체 기록을 백그라운드에서 내려받아 간직함), 한 번에 하는 보관 후 삭제는 Premium이며, 현재 얼리 액세스 가격으로 월 $4 또는 연 $25입니다.

Outlook.com 계정의 알려진 제한: 이 계정들은 Microsoft Graph를 쓰므로 다시 알림은 아직 쓸 수 없고, MBOX 파일을 서버로 복원할 수 없으며, 삭제한 메일은 컴퓨터로는 복구되지만 서버로는 복구되지 않고, 연결 테스트 뒤 받은편지함 메일 수가 표시되지 않습니다. 읽기, 삭제, 이동, 표시, 백업은 다른 계정과 똑같이 작동합니다.

백업이 완전한지 확인하는 방법

  1. 개수를 비교하십시오. Outlook.com에서 큰 폴더마다 메일이 몇 통인지 적어 두고 백업과 비교하십시오. MailVault에서는 폴더마다 머리글에 그 폴더의 메일 중 몇 통이 볼트에 있는지 표시됩니다. 예: 보관함에 79 / 79. 모든 폴더의 서버 개수와 볼트 개수를 보여 주는 표는 Premium(백업 상태 점검)에 들어 있습니다.
  2. 최근 메일만이 아니라 가장 오래된 메일을 여십시오. 빈틈은 오래된 폴더에 숨어 있습니다.
  3. PDF, 사진, 오피스 문서처럼 몇 가지 종류의 첨부 파일을 여십시오.
  4. 이름이나 주문 번호처럼 몇 년 전의 기억나는 것을 검색하십시오.
  5. 파일을 만든 앱이 아닌 곳에서 여십시오. .eml 파일을 두 번 클릭하면 Apple Mail에서 열립니다. .mbox는 파일 > 메일상자 가져오기로 가져오십시오.
  6. 다른 드라이브에 두 번째 사본을 두십시오. 노트북 한 대에 있는 사본 하나는 백업이 아닙니다.

자주 묻는 질문

Outlook 없이 Hotmail 메일을 Mac으로 내보낼 수 있습니까?

예. Apple Mail은 Outlook.com 메일을 내려받아 메일상자마다 .mbox 파일로 내보낼 수 있습니다. Thunderbird는 내보내기 추가 기능으로 같은 일을 할 수 있고, MailVault는 메시지마다 .eml 파일로 저장합니다. Microsoft의 자체 내보내기에는 데스크톱 버전 Outlook이 필요합니다.

메일 백업에는 어떤 파일 형식이 가장 좋습니까?

다른 앱에서도 열 수 있는 형식입니다. .eml 파일에는 메시지 하나와 첨부 파일이, .mbox 파일에는 메일함 하나 전체가 들어 있습니다. Apple Mail은 .eml 파일을 열 수 있고 .mbox 파일을 가져올 수 있습니다. .olm 파일은 Mac용 Outlook에 다시 가져오도록 만들어진 형식입니다.

MailVault는 Hotmail과 Live.com 주소에서도 작동합니까?

예. MailVault는 outlook.com, hotmail.com, live.com 주소를 개인 Microsoft 계정으로 다룹니다. 브라우저에서 Microsoft로 로그인하면 MailVault가 Microsoft Graph로 연결하므로 입력할 IMAP 설정이 없습니다.

메일 백업은 최신 상태로 유지됩니까?

Apple Mail이나 Outlook에서 내보낸 것은 스냅샷이므로, 새 메일을 넣으려면 다시 내보내야 합니다. MailVault에서는 백업을 다시 실행하면 새 메일만 내려받습니다. 예약 자동 백업은 MailVault Premium에 들어 있습니다.

Outlook.com에 아직 메일함 내보내기 버튼이 있습니까?

Microsoft의 현재 도움말 페이지는 데스크톱 버전 Outlook으로 내보내는 방법만 설명합니다. 예전 가이드에는 Outlook.com 설정의 메일함 내보내기 버튼이 나옵니다. 계정에서 보이지 않는다면 이 페이지의 방법 중 하나를 쓰십시오.

다음에 할 일

방법 하나를 골라 이번 주에 첫 사본을 만들고, 위 목록으로 확인하십시오. 메일함이 이미 가득 찼다면 메일이 반송되지 않도록 먼저 Outlook 저장 공간이 가득 찼을 때 할 일을 읽으십시오. Outlook.com 또는 Hotmail 메일함이 가득 찼을 때의 짧은 개요와 제공업체에 상관없는 메일 저장 공간 비우기 가이드는 로컬 사본이 있으면 메일을 잃지 않고 온라인에서 지울 수 있는 이유를 설명합니다. 로컬 사본과 더 큰 요금제를 견주어 보려면 로컬 보관 vs 저장 공간 추가 구매를 보십시오.
