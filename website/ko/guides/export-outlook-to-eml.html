Outlook 이메일을 EML로 내보내는 방법

이 페이지의 내용

  • 짧은 데모: 보관함에서 메일을 열 수 있는지 확인하기
  • 이미 PST나 MSG 파일이 있다면 어떻게 합니까?

Outlook 내보내기는 사용하는 Outlook에 따라 다릅니다. 새 Outlook과 웹용 Outlook에서는 개별 메시지를 저장할 수 있습니다. 클래식 Outlook은 다른 내보내기 절차를 사용하며 PST 메일함 백업은 EML 파일 폴더와 다릅니다. 전체 메일함을 개별 EML 파일로 보관하려면 호환되는 데스크톱 앱으로 현재 계정을 보관하십시오.

새 Outlook이나 웹용 Outlook에서 개별 메시지 저장하기

  1. 읽기 창이나 별도 창에서 메시지를 여십시오.
  2. 새 Outlook에서 기타 작업 → 다른 이름으로 저장을 선택하십시오. 웹에서는 메시지의 기타 작업 메뉴를 열고 화면에 따라 다른 이름으로 저장 또는 다운로드를 찾으십시오.
  3. 요청이 나타나면 저장 위치를 선택하십시오. 저장된 파일의 확장자를 확인하고 메일 앱에서 열어 메시지와 첨부 파일을 검증하십시오.

메뉴가 다르면 Microsoft의 버전별 저장 안내를 확인하십시오. 메시지 하나를 저장해도 나머지 대화나 메일함까지 내보내지는 않습니다.

Outlook.com 또는 Microsoft 365 메일함을 EML로 내보내기

  1. MailVault를 설치하고 Microsoft 로그인으로 계정을 추가하십시오. MailVault에서 Outlook.com 계정은 Microsoft Graph를 사용하며 Microsoft 365는 앱의 OAuth 계정 연결도 지원합니다. 조직 정책에 따라 접근이 차단될 수 있습니다.
  2. 받은편지함, 보낸편지함, 사용자 지정 폴더를 살펴보십시오. 필요한 메일이 연결된 계정에서 실제로 제공되는지 확인하십시오. 온라인 보관함이나 공유 메일함에는 별도로 지원되는 접근 방법이 필요할 수 있습니다.
  3. 일괄 작업에서 폴더와 날짜를 선택하고 보관을 선택한 뒤 다운로드가 끝날 때까지 기다리십시오. 첫 백업에는 보관만 사용하십시오.
  4. 보관함 소스로 전환해 오래된 메시지와 첨부 파일을 확인하십시오. 보관한 메시지는 개별 .eml 파일로 로컬에 저장됩니다.

보관한 메일을 신뢰하기 전에 검증하기

  1. 메시지 소스를 서버나 전체가 아닌 보관함으로 전환하십시오. 기억나는 오래된 메시지를 검색하십시오.
  2. 네트워크 연결을 끊고 서로 다른 폴더와 연도의 보관된 메시지를 몇 개 열어 보십시오. 첨부 파일도 열어 보십시오. 목록에 제목이 보인다는 것만으로 메시지 본문이 저장되었다고 할 수는 없습니다.
  3. 설정에서 백업 및 복원을 열고 백업 내보내기를 사용하십시오. 두 번째 드라이브의 위치를 선택하십시오. ZIP에는 보관함, 계정, 설정이 포함되며 서버에만 있는 메시지는 제외됩니다.
  4. ZIP이 열리는지, .eml 파일이 들어 있는지, 보존하려던 폴더가 포함되어 있는지 확인하십시오. 중요한 메일이라면 무엇이든 삭제하기 전에 별도로 설치한 앱에서 사본을 복원해 보십시오.

짧은 데모: 보관함에서 메일을 열 수 있는지 확인하기

기존 macOS 데모 녹화 영상을 편집한 가상 메일 시연입니다. 계정 로그인과 일부 준비 과정은 화면 밖에서 진행되며 실제 제공업체에 연결한 영상이 아닙니다.

데모 설명 읽기

영상에서는 미리 준비한 로컬 보관함을 검색합니다. 백업을 신뢰하기 전에 저장된 검색 결과를 열고 오프라인에서 첨부 파일을 확인하십시오. 영상 전체에 가상 데모 메일을 사용합니다.

이미 PST나 MSG 파일이 있다면 어떻게 합니까?

PST는 Outlook 데이터 컨테이너이고 MSG는 별도의 단일 메시지 형식입니다. 둘 중 어느 것이든 이름을 .eml로 바꾼다고 변환되지는 않습니다. 원본 파일을 보관하고 Outlook이나 해당 형식을 명시적으로 지원하는 변환 도구를 사용하십시오. 전체 파일을 처리하기 전에 일부를 변환해 검증하십시오. 여기서 설명하는 MailVault의 계정 보관 절차는 PST 파일을 가져오거나 변환하지 않습니다. 이 파일 구조 설명은 기본 Maildir 형식을 기준으로 합니다. 설정 → 저장소에서는 원본 메시지 바이트를 JSON 레코드와 함께 보관하고 동일한 메시지의 중복을 제거하는 JMAP 저장소도 선택할 수 있습니다.

Microsoft의 기본 메일함 백업 방법은 Outlook 이메일 백업하기를 참조하십시오. Mac 작업 절차는 Outlook.com 이메일을 Mac에 백업하기를 참조하십시오. 저장공간이 문제라면 Outlook.com 공간 확보하기로 이어 가십시오.

MailVault를 무료로 다운로드하고 첫 로컬 보관함을 만드십시오. 수동 보관은 무료입니다. 자동 보관, 예약 백업, 보관 후 삭제에는 Premium이 필요합니다.
