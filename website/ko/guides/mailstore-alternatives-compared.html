MailStore 대안: 용도별로 정리한 일곱 가지 선택지

7분 분량

알맞은 MailStore 대안은 어떤 MailStore를, 왜 바꾸려는지에 따라 다릅니다. MailStore Home은 개인 용도의 무료 Windows 보관 도구입니다. MailStore Server는 회사를 위한 유료 Windows 보관 시스템입니다. 이 정리 글은 실제 선택지 일곱 가지를 네 그룹으로 나눕니다. Mac이나 Linux의 개인 용도, Windows의 개인 용도, 오픈소스 보관 서버, 그리고 Microsoft 365와 Google Workspace에 이미 들어 있는 도구입니다. 일곱 가지 중 하나인 MailVault는 저희가 만들며, 그 제한도 다른 도구들 옆에 함께 적었습니다. 한 쌍을 더 깊이 보려면 MailVault vs MailStore Home 또는 MailStore Server 대안을 읽으십시오.

빠른 답

  • Mac이나 Linux의 개인 사용자: MailVault, 또는 Mac이라면 Mail Archiver X.
  • 무료로 직접 꾸리고 싶은 Windows의 개인 사용자: ImportExportTools NG를 붙인 Thunderbird, 또는 MailVault.
  • 자체 서버를 운영할 회사: Piler, Mail-Archiver, Open Archiver.
  • 이미 Microsoft 365나 Google Workspace를 쓰는 회사: Microsoft Purview 또는 Google Vault.

Mac이나 Linux의 개인 사용자에게

MailStore Home은 Windows 10이나 11이 필요하므로 Mac과 Linux 사용자는 다른 곳을 찾아야 합니다. Mac의 경우는 Mac용 MailStore 대안 가이드에서 더 자세히 다룹니다.

1. MailVault

MailVault는 macOS, Windows, Linux용 무료 메일 앱으로, 고른 메일의 사본을 컴퓨터의 로컬 볼트에 Maildir 방식 폴더 안의 일반 .eml 파일로 간직합니다. Gmail, Microsoft 365, Outlook.com, 모든 IMAP 계정에 연결하고, Google Takeout 내보내기 같은 MBOX 파일을 가져오며, 가지고 있는 모든 것을 로컬 인덱스로 오프라인에서 검색합니다. 수동 백업은 무료이고 무제한입니다. 보관과 서버에서 삭제는 따로 하면 무료이고, 서버 사본을 지우기 전에 사본을 하나하나 확인하는 한 번에 하는 보관 후 삭제는 Premium입니다.

제한: PST 가져오기, Outlook이나 Thunderbird 프로필 가져오기, 여러 사용자를 위한 공유 보관본, 보존 정책이나 소송 보존(legal hold)이 없습니다. 첨부 파일 검색, 예약 백업, 정리 규칙은 Premium입니다.

2. Mail Archiver X

Moth Software의 Mail Archiver X는 Apple Mail, Outlook, Thunderbird, Postbox, Gmail과 iCloud를 포함한 IMAP 계정에서 보관하는 유료 Mac 앱입니다. 보관본을 검색 인덱스가 딸린 내부 데이터베이스에 두고, PDF와 MBOX로 내보낼 수 있으며, 보관본을 내장 또는 외장 드라이브에 둘 수 있습니다. 업체는 네트워크 저장소도 언급하지만, 매뉴얼에는 표준판이 로컬 보관본을 전제로 한다고 나와 있습니다. 서버 구성 요소가 있는 Pro판은 여러 컴퓨터와 사용자의 접근을 더합니다. 현재 버전은 8.2.4입니다.

제한: Mac 전용이며, 보관본이 메시지마다 파일 하나가 아니라 데이터베이스이므로 표준 파일을 꺼내려면 내보내야 합니다. 가격은 업체 매뉴얼에 나와 있습니다. $49.95에 세금 별도, Pro는 $150부터입니다.

Windows의 개인 사용자에게

Windows에서는 MailStore Home 자체가 여전히 개인 용도로 무료입니다. 그래도 떠나려 하거나 다른 시스템에서도 통하는 구성을 원한다면, MailVault도 Windows에서 실행되고, 직접 꾸리는 무료 방법도 있습니다.

3. ImportExportTools NG를 붙인 Thunderbird

Thunderbird는 Windows, macOS, Linux용 무료 메일 클라이언트입니다. 보관 버튼은 메시지를 보관 폴더로 옮기며, 그 폴더를 컴퓨터의 로컬 폴더로 지정해 연도별이나 월별로 정리할 수 있습니다. 무료 ImportExportTools NG 추가 기능은 메시지를 EML, HTML, PDF, CSV, 일반 텍스트로 내보내고, 폴더를 mbox로 내보내며, mbox와 EML 파일을 가져옵니다.

제한: Thunderbird는 기본적으로 폴더마다 mbox 파일 하나로 저장합니다. Maildir 저장은 계정마다 직접 켜야 하며, Mozilla는 이를 실험 단계라고 하면서 켜기 전에 버그 신고 방법과 메일 복원 방법을 알아 두라고 합니다. 보관은 수동이고, 메일이 로컬 폴더에 들어간 뒤에는 그 폴더의 백업은 사용자의 몫입니다. 자세한 내용은 MailVault vs Thunderbird를 보십시오.

오픈소스 보관 서버

이것들은 MailStore Home보다는 MailStore Server를 대신합니다. 세 가지 모두 무료로 쓸 수 있지만, 세 가지 모두 누군가 서버를 설치하고, 업데이트하고, 백업해야 합니다.

4. Mail-Archiver

Mail-Archiver(Mail Archiver X와는 다른 제품)는 GPL-3 라이선스의 자체 호스팅 웹 앱으로, Docker에서 PostgreSQL 데이터베이스와 함께 실행됩니다. IMAP 계정과, Microsoft Graph를 통한 Microsoft 365를 동기화하고, 개인 Outlook.com 계정에 연결하며, MBOX와 압축된 EML을 가져오고 같은 형식으로 내보냅니다. 여러 사용자가 계정별 권한으로 함께 쓸 수 있습니다. 계정마다 정한 기간이 지나면 서버에서 메일을 지울 수 있고, 로그인, 검색, 내보내기의 접근 기록을 남깁니다.

제한: 자체 HTTPS가 없어 리버스 프록시가 필요하며, README에 소송 보존(legal hold)이 나와 있지 않습니다.

5. Piler

Piler는 GPL-3 라이선스의 오픈소스 보관 서버입니다. 무료 Open Source Edition은 SMTP로 메일을 받고, Office 365와 Google 계정을 받아들이며, EML, Maildir, 메일함 파일을 읽고, 보관 및 보존 규칙, 소송 보존, 감사 로그, 중복 제거, 압축, 메시지 암호화를 갖추고 있습니다. AD나 LDAP, 싱글 사인온, 2단계 인증 코드로 사용자를 로그인시킵니다. Enterprise Edition은 가격 등급이 공개된 유료판이며, eDiscovery, 멀티 테넌시, 선택형 유료 지원을 더합니다.

제한: 무료판은 커뮤니티 지원이 따르는 단일 서버용이며, Enterprise 가격은 문의해야만 알 수 있습니다.

6. Open Archiver

Open Archiver는 AGPL-3 라이선스의 자체 호스팅 플랫폼으로, Docker Compose로 시작합니다. Google Workspace, Microsoft 365, IMAP, PST 파일, 압축된 EML과 MBOX를 받아들이고, 메시지와 PDF, DOCX 같은 첨부 파일의 텍스트를 색인합니다. 메일을 중복 제거, 압축, 저장 시 암호화를 거친 .eml 파일로 로컬 디스크나 S3 호환 저장소에 저장하며, 받아들일 때 메시지마다 해시를 기록하고, 감사 기록을 남깁니다.

제한: README에 소송 보존(legal hold)이 아직 예정 기능으로 나와 있고, 기본 구성에서 RAM이 최소 4 GB 필요합니다.

기업: 제공업체가 이미 갖춘 보관 기능

7. Microsoft Purview 또는 Google Vault

회사 메일이 Microsoft 365에 있다면, Microsoft Purview 보존 정책과 레이블이 사용자가 지운 뒤에도 메일함 항목의 사본을 보존하고, eDiscovery로 검색할 수 있습니다. 필요한 기능이 어느 Microsoft 365 요금제에 들어 있는지 확인하십시오. 메일이 Google Workspace에 있다면, Google Vault가 이를 포함하는 버전에서 보존 규칙, 보존 조치, 검색, 내보내기, Vault 활동 감사 로그를 처리합니다.

제한: 사본이 같은 제공업체의 클라우드에 머무르므로 독립된 백업이 아닙니다. Google에 따르면 Vault는 데이터 보관소가 아니며, 규칙을 정하기 전까지는 아무것도 보존하지 않습니다. 같은 종류의 관리 기능을 갖춘 별도의 Windows 기반 보관 시스템으로는 MailStore Server 자체도 여전히 선택지입니다.

고르는 방법

  1. 보관본은 누구를 위한 것입니까? 한 사람의 메일은 데스크톱의 일입니다. 여러 사람의 메일을 다른 누군가가 검색한다면 서버의 일입니다.
  2. 보존 규칙, 소송 보존, 감사 로그가 필요합니까? 그렇다면 Piler, MailStore Server, 또는 제공업체 자체 도구를 보십시오. 여기 나온 데스크톱 선택지는 이런 기능을 하지 않습니다.
  3. 오래된 메일은 어디에 있습니까? PST 파일이라면 MailStore Home이나 Open Archiver가 맞습니다. MBOX 파일과 IMAP 계정은 여기 나온 거의 모든 도구와 함께 쓸 수 있습니다.
  4. 결국 어떤 형식으로 남기고 싶습니까? 도구 없이도 10년 뒤에 열 수 있는 일반 파일을 원한다면, .eml처럼 메시지마다 파일 하나인 형식을 고르십시오.

자주 묻는 질문

MailStore의 가장 좋은 무료 대안은 무엇입니까?

하려는 일에 따라 다릅니다. Mac, Windows, Linux의 개인 사용자라면 MailVault 또는 ImportExportTools NG를 붙인 Thunderbird. 자체 서버에 두는 회사용 보관 시스템이라면 Piler Open Source Edition, Mail-Archiver, Open Archiver입니다.

MailStore의 오픈소스 대안이 있습니까?

예. Piler와 Mail-Archiver(둘 다 GPL-3), Open Archiver(AGPL-3)는 오픈소스 보관 서버입니다. 데스크톱에서는 Thunderbird가 오픈소스이고, MailVault의 소스 코드는 GitHub에 있습니다.

어떤 MailStore 대안이 PST 파일을 읽을 수 있습니까?

여기 나온 도구 중에서는 Open Archiver가 PST 파일을 가져오며, MailStore Home과 MailStore Server도 PST를 보관합니다. MailVault, Mail-Archiver, ImportExportTools NG를 붙인 Thunderbird, Piler 무료판은 PST 가져오기를 밝히고 있지 않습니다.

Mail-Archiver와 Mail Archiver X는 같은 것입니까?

아니요. Mail-Archiver는 Docker에서 실행되는 무료 자체 호스팅 웹 앱입니다. Mail Archiver X는 Moth Software의 유료 Mac 앱입니다.

다음에 할 일

자신의 상황에 맞는 그룹을 골라, 모든 것을 옮기기 전에 메일함 하나로 도구 하나를 시험해 보십시오. Mac, Windows, Linux의 개인 사용자로서 메일을 일반 파일로 원한다면 MailVault를 무료로 다운로드하고 먼저 오래된 한 해를 보관해 보십시오. IMAP 백업 도구 체크리스트를 쓰면 이 도구들을 모두 같은 방식으로 시험할 수 있습니다.
