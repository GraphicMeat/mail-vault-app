누가 MailVault를 쓰는가

MailVault가 실제 사용자에게 풀어 주는 실제 문제들입니다.

소규모 사업체의 메일 보존

물류 회사, 회계사, 운영팀은 지울 수 없는 청구서와 배송 확인서, 규정 관련 서류를 다룹니다. MailVault는 이 모든 것을 볼트에 복사해 두므로, 법적으로 보관해야 하는 기록을 잃지 않고도 메일함을 비울 수 있습니다.

  • 규정에 안전한 보존
  • 기간별 일괄 보관
  • 법정에서도 읽을 수 있는 표준 .eml 파일

메일함 정리

10GB 메일함이 또 가득 찼습니다. 서버 저장 공간을 더 사거나 오래된 메일을 아무렇게나 지우는 대신, MailVault로 로컬에 보관하십시오. 서버 공간을 비우고, 모든 메일을 오프라인에서도 검색할 수 있게 유지하십시오.

  • 보관 후 서버에서 삭제
  • 즉각적인 로컬 검색
  • 반복되는 저장 비용 없음

프라이버시를 중시하는 사용자

메일에는 가장 개인적인 데이터가 담겨 있습니다. MailVault는 모든 것을 사용자의 컴퓨터에 저장합니다 — 클라우드 동기화도, 텔레메트리도, 추적도 없습니다. 인증 정보는 OS 키체인에 남습니다. 오픈소스이므로 코드를 한 줄까지 확인할 수 있습니다.

  • 클라우드 없음, 추적 없음
  • macOS 키체인 / Linux Secret Service
  • 오픈소스

오프라인 메일 접근

여행 중이거나, 원격으로 일하거나, 인터넷을 믿지 못하십니까? 한 번 보관해 두면 메일 기록 전체를 오프라인에서 쓸 수 있습니다 — 연결 없이도 전부 검색됩니다.

  • 완전한 오프라인 접근
  • 인터넷 없이도 동작
  • 모든 계정을 아우르는 로컬 검색
