Mac용 이메일 백업 소프트웨어: 복구를 기준으로 선택하기

  • 관련 가이드

Mac용 이메일 백업 소프트웨어는 복구를 예측 가능하게 만들어야 합니다. 무엇이 복사되었고 어디에 저장되었으며 어떻게 다시 여는지 알아야 ‘백업 완료’라는 표시가 의미 있습니다. 특히 가득 찬 메일상자를 정리하거나 계정을 닫기 전에는 복구 시험을 기준으로 선택합니다.

이 가이드는 MailVault 제작자가 작성했습니다. MailVault는 검색 가능한 이메일 보관함과 직접 관리하는 백업이 필요한 사람에게 적합합니다. 한 번의 내보내기나 Mac 전체 백업도 알맞은 구성의 일부가 될 수 있습니다.

세 가지 방법, 세 가지 역할

메일상자 내보내기는 한 번 사본을 만들거나 이전할 때 유용합니다. Apple Mail은 선택한 메일상자를 MBOX 패키지로 내보냅니다. Apple의 내보내기 안내를 참고합니다. 어떤 폴더와 메시지가 포함되는지 확인하고, 최신 사본이 필요할 때 다시 내보냅니다.

Mac 백업은 이미 컴퓨터에 있는 파일을 보호합니다. Apple의 Time Machine 가이드는 Mac의 백업과 복구를 설명합니다. 메일 앱에서 완전히 다운로드하지 않은 이메일까지 시스템 백업에 들어 있다고 가정해서는 안 됩니다. 보관함 위치가 백업 대상에 포함되어 있는지 확인합니다.

별도 백업을 갖춘 이메일 보관함은 메일을 일상적으로 사용할 수 있게 하면서 복구용 사본을 하나 더 제공합니다. MailVault는 보관된 메시지를 .eml 파일로 저장하며, 원하는 위치에 백업할 수 있습니다. 하나의 장애로 보관함과 백업을 모두 잃게 되는 구성은 피해야 합니다. 이 파일 구조 설명은 기본 Maildir 형식을 기준으로 합니다. 설정 → 저장소에서는 원본 메시지 바이트를 JSON 레코드와 함께 보관하고 동일한 메시지의 중복을 제거하는 JMAP 저장소도 선택할 수 있습니다.

Mac App Store 버전에서는 사용 중인 보관함을 다른 폴더로 옮길 수 없습니다. 별도의 백업 위치는 선택할 수 있습니다.

MailVault에서 확인할 사항

작업을 실행하기 전에 백업 범위를 검토합니다. 보관된 메일만 백업하면 이미 보관함에 저장된 내용이 대상이 됩니다. 아직 서버에만 있는 메시지도 포함하려면 더 넓은 범위를 선택하고, 해당 메시지를 다운로드하는 동안 계정 연결을 유지합니다.

디스크 고장에 대비하려면 별도 드라이브에 두 번째 저장 위치를 선택합니다. 같은 디스크의 다른 폴더는 그 디스크를 잃는 상황에 대비할 수 없습니다. 평소에 백업 드라이브를 분리해 둔다면 작업 전에 연결하고, 결과를 확인한 뒤 다시 보관합니다.

수동 백업과 예약 백업 중 무엇을 선택할까요?

MailVault의 수동 백업은 횟수 제한 없이 무료입니다. 한 번의 보관 작업이나 이미 정기적인 백업 습관이 있는 사람에게 적합합니다. 예약 백업은 Premium 기능이며 매일 바뀌는 메일상자에 적합합니다. 예약하면 반복 작업을 줄일 수 있지만, 실행 시 원본과 저장 위치에 접근할 수 있어야 합니다.

작은 규모의 복구 연습하기

  1. 오래된 메시지, 최근 메시지, 첨부 파일이 있는 폴더를 백업합니다.
  2. 작업이 끝났는지 확인하고 백업 저장 위치를 살펴봅니다.
  3. 백업에서 샘플 메시지를 꺼내 복사한 뒤 호환되는 메일 앱에서 엽니다.
  4. 첨부 파일을 열고 보낸 사람, 날짜, 본문을 원본과 비교합니다.
  5. 백업이 있는 위치와 다른 Mac에서 접근하는 방법을 적어 둡니다.

서버 메시지를 삭제하기 전에 이 과정을 수행합니다. Premium의 보관과 삭제를 결합한 작업에는 이 절차를 위한 확인 과정이 추가되지만, 전체 복구 계획도 여전히 중요합니다. 무료 수동 백업으로 시작해 결과물을 사용할 수 있는지 확인한 뒤, 자동화에 비용을 지불할 가치가 있는지 결정합니다.

자신의 메일 폴더 하나로 시험해 봅니다.

무료 수동 보관, 로컬 메시지 검색, 수동 백업으로 시작합니다. 자동화가 필요해지면 요금제를 비교합니다.
