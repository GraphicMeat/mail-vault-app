MailVault vs MailStore Home 나란히 보기

6분 분량

MailStore Home 대안을 원한다면, 이 페이지는 한 사람의 메일을 위한 두 무료 도구를 직접 비교합니다. MailStore Home은 Outlook, Thunderbird, Gmail, Outlook.com, IMAP 계정, PST 파일의 메일을 하나의 검색 가능한 보관본으로 복사하는 Windows 프로그램입니다. MailVault는 메일 사본을 일반 .eml 파일로 컴퓨터에 간직하는 macOS, Windows, Linux용 무료 메일 앱입니다. 회사 전체를 위한 보관 시스템이 필요하다면 대신 MailStore Server 대안을 읽으십시오. 더 넓은 도구 목록은 MailStore 대안 비교를 보십시오.

빠른 답

Windows에서 PST 파일이나 여러 로컬 메일 프로그램에서 가져와야 한다면 MailStore Home이 더 잘 맞습니다. Mac이나 Linux를 쓰거나, 메일을 읽고 답장하는 앱 안에 보관본을 일반 .eml 파일로 두고 싶다면 MailVault가 더 잘 맞습니다.

MailStore Home이 앞서는 부분

  • 더 많은 원본, 특히 Windows에서. Outlook 프로필, PST 파일, Exchange Server 메일함, Windows 메일, Thunderbird 프로필을 읽습니다. MailVault는 PST 파일을 전혀 읽지 못합니다.
  • 무료 첨부 파일 검색. MailStore Home은 첨부 파일을 무료로 색인합니다. MailVault에서 PDF와 Office 첨부 파일 내부 검색은 Premium입니다.
  • 무료 삭제 규칙. 보관 프로필은 보관이 끝난 뒤, 일정 대기 기간이 지난 뒤, 또는 기간 기준으로 메일함에서 메일을 제거할 수 있으며, 보관본에 있다고 확인된 메일만 제거합니다. 플래그가 지정된 메시지는 함께 지우는 옵션을 켜지 않는 한 남겨 둡니다. MailVault에서 자동 정리 규칙과 한 번에 하는 보관 후 삭제는 Premium입니다.
  • 무료 포터블. 설치하지 않고 USB 드라이브에서 실행됩니다. MailVault의 포터블 모드는 Windows 전용이며 Premium입니다.
  • 메일을 되돌려 놓는 방법이 더 많습니다. 보관한 메일을 Exchange, IMAP 메일함, Gmail로 내보낼 수 있어 이전 도구로도 쓸 수 있습니다.
  • 오랜 실적. MailStore 제품은 2006년부터 시장에 있었고, Home은 2026년에도 업데이트를 받았습니다.

MailVault가 앞서는 부분

  • Mac과 Linux에서 실행됩니다. MailStore Home은 Windows 10과 11만 명시합니다. MailVault는 macOS 11 이상(Apple Silicon과 Intel), Windows, Linux에서 실행됩니다. Mac의 경우는 Mac용 MailStore 대안 가이드에서 다룹니다.
  • 보관본이 일반 파일입니다. 메시지마다 Maildir 방식 폴더 안의 표준 .eml 파일이며, Apple Mail, Thunderbird, 텍스트 편집기로 MailVault 없이 열 수 있습니다. MailStore Home은 메일을 자체 보관 파일에 두며, 표준 파일을 꺼내려면 내보내야 합니다.
  • 메일을 읽고 간직하는 앱 하나. MailVault는 완전한 메일 클라이언트입니다. 읽고, 검색하고, 답장하고, 보낸 다음, 간직하고 싶은 것을 보관합니다. 각 행에 메시지가 서버에 있는지, 볼트에 있는지, 둘 다에 있는지 표시됩니다.
  • Microsoft 365가 명시된 원본입니다. Microsoft 365 계정은 OAuth2로 로그인하고, 개인 Outlook.com, Hotmail, Live.com 계정은 Microsoft Graph로 연결됩니다. MailStore Home 제품 페이지에는 Outlook.com과 Exchange Server 2003~2019는 나와 있지만 Microsoft 365는 없습니다.
  • 소스 코드는 GitHub에 있습니다. 코드가 GitHub에 있으므로 메일을 어떻게 다루는지 직접 확인할 수 있습니다.

보관본이 있는 곳

MailStore Home에서 보관본은 데이터 폴더에 있으며, 내장 백업 기능으로 백업하거나 프로그램을 닫은 상태에서 폴더를 복사해 백업합니다. MailStore는 그 폴더를 Dropbox 같은 동기화 서비스에 두지 말라고 경고합니다. MailStore Home이 파일을 쓰는 동안 서비스가 파일을 건드릴 수 있기 때문입니다.

MailVault에서 보관본은 .eml 파일이 든 폴더입니다. 설정, 백업 및 복원에서 위치를 보여 주고, 파일 관리자로 열며, 다른 드라이브로 옮길 수 있습니다. 외장 드라이브나 NAS 공유 폴더에 두 번째 사본을 추가할 수 있으며, 백업을 실행할 때마다 기록됩니다.

MailStore Home에서 MailVault로 옮기기

MailVault는 MailStore의 보관 파일을 직접 열지 못합니다. 가장 간단한 방법은 MailVault를 같은 계정들에 연결하고 아직 서버에 있는 것을 보관하는 것입니다. 이제 MailStore Home에만 있는 메일은 MailStore Home에서 IMAP이나 Gmail 메일함으로 내보내고, MailVault가 보관하게 한 다음, 다시 서버에서 지우십시오. 내보내기를 하면 그 메일이 한동안 다시 서버에 올라가므로, 먼저 메일함 용량을 확인하십시오.

누가 무엇을 골라야 할까

  • Windows를 쓰고, 가져올 PST 파일이나 Outlook과 Thunderbird 프로필이 있고, 무료 첨부 파일 검색과 무료 삭제 규칙을 원하며, 보관 전용 도구로 만족한다면 MailStore Home을 고르십시오.
  • Mac이나 Linux를 쓰고, 어디서든 열 수 있는 일반 파일로 보관본을 원하고, Gmail, Microsoft 365, Outlook.com, IMAP을 쓰며, 메일을 읽고 검색하고 간직하는 앱 하나를 원한다면 MailVault를 고르십시오.
  • 회사에 보존 정책, 소송 보존, 감사 로그가 필요하다면 둘 다 고르지 마십시오. 그것은 서버의 영역입니다.

자주 묻는 질문

Mac용 MailStore Home이 있습니까?

아니요. MailStore는 MailStore Home의 시스템 요구 사항으로 Windows 10과 Windows 11을 밝히고 있습니다. Mac에서는 MailVault나 다른 Mac용 선택지 같은 다른 도구가 필요합니다.

MailVault로 MailStore Home 보관본을 가져올 수 있습니까?

직접은 안 됩니다. MailVault는 MailStore의 보관 파일을 읽지 못합니다. MailStore Home에서 메일을 IMAP이나 Gmail 메일함으로 내보내 MailVault로 보관하거나, MailVault를 원래 계정들에 연결하십시오.

MailVault는 PST 파일을 열 수 있습니까?

아니요. MailVault는 MBOX 파일을 가져오고 Gmail, Microsoft 365, Outlook.com, IMAP 계정에 연결합니다. 오래된 메일이 PST 파일에 있다면 Windows의 MailStore Home이 보관할 수 있습니다.

MailStore Home은 정말 무료입니까?

MailStore에 따르면 가정의 개인 용도로는 무료입니다. 상업적 용도에는 유료 MailStore Server를 안내합니다.

다음에 할 일

Windows에서 PST 파일이 있다면 MailStore Home부터 써 보십시오. Mac이나 Linux를 쓰거나 일반 파일을 원한다면, MailVault를 무료로 다운로드하고, 계정 하나를 연결하고, 오래된 한 해를 보관해 작동 방식을 보십시오. 무엇이 무료이고 무엇이 Premium인지는 보관 후 삭제 페이지에 있습니다.

MailVault를 Thunderbird, Apple Mail과도 비교해 보거나, 로컬 검색에 관해 읽어 보십시오.
