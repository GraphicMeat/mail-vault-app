필요한 모든 기능

MailVault는 macOS와 Linux를 위한 메일 클라이언트이자 백업 도구입니다. 통합 받은편지함과 스레드 대화부터 로컬 보관까지, MailVault가 할 수 있는 일을 모두 정리했습니다.

메일 관리 스레드 채팅 보기 보안 저장 일괄 작업 다중 계정 사용자 설정 성능 Premium

메일 관리

메일을 읽고, 쓰고, 정리하는 데 필요한 모든 것을 갖췄습니다. 한 번의 클릭으로 로그인하고, 정확하게 검색하고, 받은편지함을 손쉽게 관리하십시오.

  • 첨부파일과 함께 작성, 답장, 전체 답장, 전달
  • Gmail & Microsoft 365 OAuth2 원클릭 로그인
  • Outlook.com용 Microsoft Graph API — IMAP 회귀 버그를 우회합니다
  • 필터를 갖춘 고급 검색 — 발신자, 기간, 첨부파일, 폴더
  • 검색 기록 & 자주 쓰는 필터 제안
  • 읽음/읽지 않음 표시, 별표/중요 표시
  • 발송 취소 — 전역 기본값과 작성 창별 개별 설정(15초에서 5분)
  • 보낼 편지함 — 로컬에 담아 두었다가 보내며, 전송 중인 메일도 취소하고 다시 시도할 수 있습니다
  • 보낸 편지함 동기화 — SMTP로 발송한 뒤 서버의 보낸 편지함에 복사됩니다
  • 폴더로 이동 — 서버 폴더 사이에서 메일을 다시 정리합니다
  • 메일 템플릿 — 자주 쓰는 문구를 저장해 다시 사용합니다
  • 연락처 선택기 — 작성, 수신자 지정, 답장 시 계정별로 걸러지고 우선순위가 매겨진 제안
  • 발신자별 묶기 — 받은편지함을 연락처 기준으로 정리하고, 보낸 답장도 같은 줄기에 함께 표시합니다
  • DNS 기반 서버 자동 감지 — SRV 레코드, Mozilla autoconfig, MX 대체 조회, 알려진 제공업체 매핑
  • 인라인 임베드 이미지 — CID로 참조된 로고와 사진이 본문 안에서 표시됩니다
  • 링크 안전성 — 피싱 링크와 발신자 사칭을 감지해 눈에 띄게 경고합니다

JWZ 알고리즘으로 구현한 Gmail 스타일 스레드 대화입니다. 관련된 메일이 한데 묶여 보이고, 접기 기능이 알아서 화면을 정돈해 줍니다.

  • JWZ 알고리즘을 쓰는 Gmail 스타일 스레드 대화
  • 스레드 대화 보기 — 모든 메일이 시간순으로 쌓입니다
  • 정렬 순서 선택 — 오래된 순 또는 최신 순
  • 인용문 접기 — 인용된 답장을 접어 읽기 좋게 만듭니다
  • 서명 접기 — 스마트, 항상 표시, 항상 숨김, 접힘의 4가지 모드

  • 보낸 메일과 받은 메일이 하나의 대화로 합쳐집니다

보안 & 프라이버시

메일은 사용자의 컴퓨터에 남습니다. MailVault는 발신자를 검증하고, 인증 정보를 macOS 키체인이나 Linux Secret Service에 저장하며, 샌드박스 안에서 실행됩니다. 클라우드 서비스도, 텔레메트리도 없습니다.

  • 링크 안전성 — 표시된 문구와 실제 URL 목적지가 다른 피싱 링크를 감지합니다
  • 메일 추적기 차단 Premium — 광고 메일이 열람 시점을 알리는 데 쓰는 숨은 1×1 픽셀을 찾아, 메시지가 그려지기 전에 HTML에서 걷어냅니다
  • 발신자 사칭 감지 — 표시 이름이 다른 주소나 도메인을 흉내 내면 경고합니다
  • 클릭 확인 — 의심스러운 링크를 열기 전에 URL을 비교해 보여 주는 경고 창
  • 발신자 검증 배지 — SPF, DKIM, DMARC 검사
  • 헤더 불일치 감지 — From과 Reply-To가 어긋나면 위조 경고
  • macOS 키체인 & Linux Secret Service 인증 정보 저장
  • macOS App Sandbox — 안전한 컨테이너 안에서 실행됩니다
  • 클라우드 없음, 추적 없음, 텔레메트리 없음
  • 오픈소스 — 코드를 한 줄까지 직접 확인할 수 있습니다

저장 & 백업

메일이 어디서든 읽을 수 있는 표준 형식으로 저장됩니다. 한 번의 클릭으로 로컬에 보관하고, ZIP으로 내보내고, 어떤 컴퓨터에서든 복원하십시오. 특정 업체에 묶이는 일은 없습니다.

  • 표준 Maildir + .eml(RFC 5322) 형식 — 어디에도 묶이지 않습니다
  • 클릭 한 번으로 로컬 저장소에 보관
  • ZIP 백업 내보내기 — 보관된 메일만 또는 전체 메일, 설정 포함
  • 이식 가능한 가져오기 — 어떤 컴퓨터에서도 복원
  • 외부 백업 폴더 — .eml 파일을 Dropbox, iCloud Drive 등 원하는 외부 위치에 복사하며, macOS 보안 범위 북마크로 접근 권한이 유지됩니다
  • 빈 캐시로 인한 손상 방지 — 이전 캐시에 데이터가 있었는데 서버가 갑자기 빈 결과를 돌려주면 이를 거부해 메일함 구조와 헤더를 지킵니다
  • 캐시 크기 한도와 보관 기간 설정
  • 백그라운드 캐싱 파이프라인 — 조용히 동기화합니다
  • 백그라운드 헬퍼 — 앱 창을 닫아도 메일 동기화가 계속됩니다

일괄 작업

수백에서 수천 통의 메일을 한 번에 선택해 보관하거나 삭제하거나, 두 가지를 한 번에 처리하십시오. 기간을 고르고, 진행 상황을 보고, 언제든 취소할 수 있습니다.

  • 떠 있는 작업 막대와 함께 다중 선택
  • 일괄 보관, 삭제, 또는 보관 후 삭제
  • 기간 선택 — 연도별 또는 직접 지정
  • 취소 버튼이 있는 진행 막대
  • 비정상 종료에도 안전한 작업 복구

다중 계정

모든 메일 계정을 한곳에서 관리합니다. 기다림 없이 즉시 전환하고, 통합 받은편지함으로 합치거나, 계정마다 표시 이름과 색을 따로 지정할 수 있습니다.

  • 메일 계정을 개수 제한 없이 추가
  • 통합 받은편지함 — 모든 계정을 하나의 목록에서 확인
  • Gmail, Outlook, Yahoo, iCloud, ProtonMail(Bridge), Fastmail, Zoho 등 모든 IMAP 제공업체
  • 표시 이름과 아바타 색 직접 지정
  • 계정 순서 변경과 숨기기/보이기
  • LRU 상태 캐시를 활용한 즉시 계정 전환
  • 계정별 메일함 기억 — 마지막으로 본 폴더를 기억합니다
  • 발신자 정보 — 연락처별 주고받은 기록과 빈도

레이아웃 & 사용자 설정

MailVault를 자신에게 맞추십시오. 테마를 고르고, 창을 재배치하고, 날짜 형식을 정하고, 일하는 방식에 맞게 인터페이스를 다듬을 수 있습니다.

  • 다크 모드와 라이트 모드, 그리고 메시지 본문에만 적용되는 별도의 테마 전환
  • 크기를 조절할 수 있는 3단 또는 2단 레이아웃
  • 아이콘만 표시하는 모드를 갖춘 접이식 사이드바
  • 기본형 또는 간결형 메일 목록
  • 날짜 형식 선택 — 미국식, 유럽식, ISO, 사람이 읽기 쉬운 형식, 또는 직접 지정
  • 데스크톱 알림과 독 배지
  • 모든 핵심 동작에 대한 단축키, 원하는 대로 변경 가능
  • 알림 세부 설정 — 계정별, 폴더별 제어
  • 소스 보기 — RFC 5322 원본 메일을 그대로 확인
  • 새 창에서 메일 열기

성능 & 기술

네이티브 속도와 낮은 자원 사용을 위해 Rust와 Tauri로 만들었습니다. 똑똑한 동기화 프로토콜, 가상 스크롤, 미리 가져오기가 모든 동작을 빠르게 유지합니다.

  • Rust(Tauri)로 제작 — Electron이 아닙니다
  • async-imap 기반 네이티브 IMAP — Node.js 사이드카 없음
  • CONDSTORE 증분 동기화 — 바뀐 것이 없으면 IMAP 호출이 전혀 없습니다
  • COMPRESS=DEFLATE — 대역폭 70-80% 절감
  • 가상 스크롤 — 17,000통이 넘어도 부드럽게 처리
  • 본문 미리 가져오기 — 다음 메일 3통이 즉시 열립니다
  • macOS의 네이티브 Sparkle 자동 업데이터 — 서명된 appcast, 앱 안에서 내려받아 설치
  • 크로스 플랫폼 — macOS(Apple Silicon & Intel)와 Linux(.deb, AppImage, Snap, Flatpak)
  • 시스템 트레이 — 백그라운드에서 조용히 동기화

Premium 기능

Premium 구독으로 고급 기능을 사용하십시오. 연간 요금제는 14일 무료 체험으로 시작합니다.

  • 예약 자동 백업 Premium — 계정마다 매일, 매주 또는 원하는 주기로 예약하고 실행 시각과 폴더 단위 체크포인트까지 지정합니다
  • 백업 상태 점검 — 폴더별로 서버, 로컬, 외부 사본의 개수를 상태 표시와 함께 보여 주는 검증 보기
  • 계정 간 메일함 이전 Premium — 폴더 매핑과 진행 상황 표시를 갖추고 IMAP 계정 사이로 메일을 옮깁니다
  • 안내에 따른 서버 변경 — 메일 호스트를 옮깁니까? 새 서버를 한 번만 입력하십시오. IMAP과 SMTP를 검증하고, 볼트를 새 서버로 올릴 수 있으며, DNS 상태 점검(MX/SPF/DKIM/DMARC)이 배달 문제를 미리 알려 줍니다
  • 나이브 베이즈 분류기를 쓰는 메일 정리 Premium — 메일을 뉴스레터, 홍보, 거래, 개인, 업무, 스팸으로 분류하는 법을 배우며, 분류마다 유지/보관/삭제 동작을 지정할 수 있습니다
  • Time Capsule Premium — 어떤 메일함이든 특정 시점의 스냅샷을 만들고, 지난 어느 날짜의 상태였는지 그대로 살펴봅니다
  • 메일 추적기 차단 Premium — 모든 메시지가 그려지기 전에 추적 픽셀을 걷어내므로, 보낸 사람은 당신이 열었다는 것을 알지 못합니다. 추적기를 찾아내는 것은 누구에게나 무료이고, 그것을 없애는 것이 구독으로 더해지는 부분입니다. 차단 전과 후를 보십시오
  • 자동 정리 규칙 — 계정과 폴더마다 정해 둔 기간보다 오래된 메일을 자동으로 지우거나 보관합니다
  • 이미지 또는 HTML로 내보내기 Premium — 메시지 하나나 스레드 전체를 PNG로, 또는 스레드를 날짜순 목록으로 접어 메시지마다 펼쳐 볼 수 있는 자족적인 HTML 파일 하나로 저장합니다. 원격 이미지도 파일 안에 함께 담기므로 몇 년 뒤 네트워크가 끊긴 상태에서도 그대로 읽힙니다
  • 기기 5대 구독 — 자동 기기 관리와 함께 최대 5곳의 설치 환경에서 Premium을 쓸 수 있습니다
