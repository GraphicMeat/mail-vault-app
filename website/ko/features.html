채팅 보기

메신저 같은 독특한 메일 경험입니다. 보낸 메일과 받은 메일이 하나의 이어지는 대화로 합쳐져, 즐겨 쓰는 메신저처럼 말풍선으로 표시됩니다.

  • 메신저 스타일의 독특한 메일 보기
  • 보낸 메일과 받은 메일이 하나의 대화로 합쳐집니다
  • 발신자 아바타가 붙은 말풍선
  • 말풍선마다 스피너가 도는 점진적 본문 로딩

Explorer

같은 메일함을 다니는 두 번째 방법입니다. Explorer는 이미 가지고 있는 메시지를 — 날짜별로, 보낸 사람별로, 대화별로 — 그룹으로 묶어 주므로, 나머지를 전부 지나치며 스크롤하는 대신 찾는 것으로 곧장 내려갈 수 있습니다.

  • 날짜로 분류해 월 또는 일 단위로 살펴보기
  • 보낸 사람으로 분류 — 한 사람이 보낸 모든 메시지가 한 그룹에
  • 날짜 → 대화 — 한 달을 열면 그 안의 스레드가 나옵니다
  • 모든 그룹이 담고 있는 메시지 수, 볼트에 있는 수, 읽지 않은 수를 함께 보여 줍니다
See all 8 capabilities
  • 지금 서 있는 그룹 안에서 검색하거나, 곧바로 전체 편지함 검색으로 빠져나갑니다
  • 그룹을 체크하면 그 안의 모든 메시지가 선택되고, 한꺼번에 보관, 삭제 또는 내보내기를 할 수 있습니다
  • 탐색 경로가 폴더별, 계정별로 있던 자리를 기억하며 재시작 후에도 남습니다
  • 키보드: j와 k로 목록을 벗어나지 않고 그룹과 메시지를 오갑니다

메일 분석

실제로 누구와 연락을 주고받는지 보여 주는 그림입니다. 메일 분석은 이미 디스크에 있는 메시지 헤더를 — 누가 썼는지, 누구에게 썼는지, 언제였는지 — 읽어서 주고받은 메일을 세 가지 보기로 그립니다. 본문은 읽지 않으며 아무것도 업로드하지 않습니다.

  • 발신자 지도 — 모든 상대가 하나의 원이 되고, 크기는 얼마나 많이 쓰는지를, 자리는 얼마나 최근인지를 나타냅니다
  • 타임라인 — 보낸 사람마다 한 줄씩, 실제 시간축을 따라 받은 표시와 보낸 표시가 놓입니다
  • 활동 — 하루하루가 얼마나 바빴는지 보여 주는 달력 격자
  • 원이든 줄이든 날짜든 클릭하면 그 뒤의 메시지가 나오고, 페이지를 벗어나지 않고 읽을 수 있습니다
See all 8 capabilities
  • 계정으로, 기간으로 — 30일, 90일, 12개월 또는 직접 고른 날짜 — 그리고 방향으로 범위를 좁힙니다
  • 자동 발송으로 추정되는 발신자 숨기기를 한 번 체크하면 뉴스레터가 사람을 밀어내지 않습니다
  • 무엇을 근거로 삼았는지 밝힙니다. 어떤 폴더가 로컬에 캐시되어 있는지, 그것이 메일함의 어느 정도를 덮는지 알려 줍니다
  • 오직 로컬 헤더만으로 만들어집니다 — 클라우드 서비스도 계정도 없으며, 아무것도 기기를 떠나지 않습니다

보안 & 프라이버시

메일은 사용자의 컴퓨터에 남습니다. MailVault는 발신자를 검증하고, 인증 정보를 macOS 키체인이나 Linux Secret Service에 저장하며, 샌드박스 안에서 실행됩니다. 클라우드 서비스도, 텔레메트리도 없습니다.

  • 링크 안전성 — 표시된 문구와 실제 URL 목적지가 다른 피싱 링크를 감지합니다
  • 메일 추적기 차단 Premium — 광고 메일이 열람 시점을 알리는 데 쓰는 숨은 1×1 픽셀을 찾아, 메시지가 그려지기 전에 HTML에서 걷어냅니다
  • 발신자 사칭 감지 — 표시 이름이 다른 주소나 도메인을 흉내 내면 경고합니다
  • 클릭 확인 — 의심스러운 링크를 열기 전에 URL을 비교해 보여 주는 경고 창
See all 10 capabilities
  • 발신자 검증 배지 — SPF, DKIM, DMARC 검사
  • 헤더 불일치 감지 — From과 Reply-To가 어긋나면 위조 경고
  • macOS 키체인 & Linux Secret Service 인증 정보 저장
  • macOS App Sandbox — 안전한 컨테이너 안에서 실행됩니다
  • 클라우드 없음, 추적 없음, 텔레메트리 없음
  • 오픈소스 — 코드를 한 줄까지 직접 확인할 수 있습니다

저장 & 백업

메일이 어디서든 읽을 수 있는 표준 형식으로 저장됩니다. 한 번의 클릭으로 로컬에 보관하고, ZIP으로 내보내고, 어떤 컴퓨터에서든 복원하십시오. 특정 업체에 묶이는 일은 없습니다.

  • 표준 Maildir + .eml(RFC 5322) 형식 — 어디에도 묶이지 않습니다
  • 클릭 한 번으로 로컬 저장소에 보관
  • ZIP 백업 내보내기 — 보관된 메일만 또는 전체 메일, 설정 포함
  • 이식 가능한 가져오기 — 어떤 컴퓨터에서도 복원
See all 9 capabilities
  • 외부 백업 폴더 — .eml 파일을 Dropbox, iCloud Drive 등 원하는 외부 위치에 복사하며, macOS 보안 범위 북마크로 접근 권한이 유지됩니다
  • 빈 캐시로 인한 손상 방지 — 이전 캐시에 데이터가 있었는데 서버가 갑자기 빈 결과를 돌려주면 이를 거부해 메일함 구조와 헤더를 지킵니다
  • 캐시 크기 한도와 보관 기간 설정
  • 백그라운드 캐싱 파이프라인 — 조용히 동기화합니다
  • 백그라운드 헬퍼 — 앱 창을 닫아도 메일 동기화가 계속됩니다

Premium 기능

Premium 구독으로 고급 기능을 사용하십시오. 연간 요금제는 14일 무료 체험으로 시작합니다.

  • 예약 자동 백업 Premium — 계정별로 매시간, 매일 또는 매주로 설정할 수 있고 실행 시각 지정과 폴더 단위 체크포인트를 지원합니다. 지정한 시각에를 고르면 백업이 시작될 수 있는 시각을 직접 정할 수 있어, 다른 프로그램이 이미 쓰는 외장 드라이브의 볼트에 알맞습니다. 모든 일정은 앱이 유휴 상태가 될 때까지 기다립니다
  • 백업 상태 점검 — 폴더별로 서버, 로컬, 외부 사본의 개수를 상태 표시와 함께 보여 주는 검증 보기
  • 계정 간 메일함 이전 Premium — 폴더 매핑과 진행 상황 표시를 갖추고 IMAP 계정 사이로 메일을 옮깁니다
  • 안내에 따른 서버 변경 — 메일 호스트를 옮깁니까? 새 서버를 한 번만 입력하십시오. IMAP과 SMTP를 검증하고, 볼트를 새 서버로 올릴 수 있으며, DNS 상태 점검(MX/SPF/DKIM/DMARC)이 배달 문제를 미리 알려 줍니다
11가지 기능 모두 보기

  • Time Capsule Premium — 어떤 메일함이든 특정 시점의 스냅샷을 만들고, 지난 어느 날짜의 상태였는지 그대로 살펴봅니다
