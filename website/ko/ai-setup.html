AI 기반 메일 정리

로컬 AI 모델이 메일을 분류하고, 서버에서 지워도 안전한 메일을 제안합니다. 모든 처리는 사용자의 컴퓨터에서 이루어집니다. 메일 데이터는 절대 기기 밖으로 나가지 않습니다.

작동 방식

1. 모델 다운로드

설정에서 AI를 켜고 모델(~2-5 GB)을 내려받습니다. 모델은 앱 데이터 폴더에 로컬로 저장됩니다. 한 번만 내려받으면 됩니다.

2. 자동 분류

백업이 끝날 때마다 AI가 메일을 분류합니다: 뉴스레터, 프로모션, 알림, 개인, 업무 등으로 나뉩니다.

3. 검토 및 정리

정리 보고서를 검토하고, 일괄 작업을 승인하고, 서버 저장 공간을 확보합니다. 로컬 사본은 항상 그대로 보존됩니다.

100% 프라이빗. 클라우드 없음.

클라우드 기반 메일 도구와 달리 MailVault의 AI는 전적으로 사용자의 컴퓨터에서 실행됩니다. 모델은 메일을 로컬에서 처리합니다 — 어떤 서버나 API, 제3자 서비스로도 전송되는 것은 없습니다. 메일은 사용자의 것입니다.

  • 모델은 사용자의 CPU/GPU에서 실행되며 — 분류에 인터넷이 필요하지 않습니다
  • 메일 내용, 메타데이터, 주소가 컴퓨터 밖으로 나가지 않습니다
  • 디스크 공간이 필요하면 언제든 모델을 삭제할 수 있습니다

시스템 요구 사항

RAM 16 GB 권장 (작은 모델 사용 시 최소 8 GB)
디스크 공간 모델 파일용 ~2-5 GB
GPU 선택 사항 — Apple Silicon에서는 Metal을, 그 외에서는 CPU를 사용합니다
인터넷 최초 모델 다운로드에만 필요합니다

자주 묻는 질문

MailVault는 어떤 AI 모델을 사용합니까?

MailVault는 GGUF 형식의 오픈소스 모델을 내려받습니다. 권장 모델은 Llama 3.1 8B(~4.6 GB)로, 분류 품질과 속도의 균형이 가장 좋습니다. RAM이 적은 컴퓨터를 위해 더 작은 3B 모델도 제공됩니다.

직접 준비한 모델을 쓸 수 있습니까?

가능합니다. GGUF 형식의 모델 파일을 모델 디렉터리(설정 > AI & 정리에 표시됩니다)에 넣으면 모델 선택 목록에 나타납니다.

"서버에서 삭제"하면 어떻게 됩니까?

해당 메일은 IMAP 서버에서 제거되어 서버 저장 공간이 확보되지만, MailVault에 있는 로컬 .eml 사본은 항상 그대로 유지됩니다. Time Capsule 기능에서 언제든 메일을 열람하거나 복원할 수 있습니다.

AI가 제 수정 내용을 학습합니까?

학습합니다. 메일을 다시 분류하면 MailVault가 그 수정 내용을 기록합니다. 같은 패턴(예: 특정 발신 도메인)에 대한 수정이 충분히 쌓이면 로컬 규칙이 자동으로 만들어집니다. 이 규칙은 AI보다 먼저 적용되므로, 시간이 지날수록 분류가 더 빠르고 정확해집니다.

학습된 규칙을 공유할 수 있습니까?

가능합니다. 설정에서 규칙을 익명화된 JSON 파일로 내보낼 수 있습니다. 내보낸 파일에는 도메인 패턴과 카테고리 매핑만 담기며 — 이메일 주소, 이름, 메시지 내용은 포함되지 않습니다. 다른 사람이 이 규칙을 가져와 사용자의 분류 기준을 그대로 활용할 수 있습니다.

구독이 필요합니까?

메일 정리와 Time Capsule은 Premium 기능입니다. 핵심 기능인 메일 보관과 읽기는 계속 무료입니다.
