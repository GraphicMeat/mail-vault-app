macOS

Apple Silicon과 Intel용 다운로드 하나입니다. macOS 11 이상.

Linux

이미 앱이 있다면 다시 다운로드할 필요가 없습니다.

  1. 이메일 계정 연결

    앱의 계정 설정 절차를 따르세요. Gmail과 Microsoft 계정은 제공업체 로그인을 사용하며, 다른 제공업체는 IMAP 설정이 필요할 수 있습니다.

  2. 첫 아카이브 만들기

    몇 개의 메시지를 선택하고 보관을 선택하세요. 저장한 메시지를 열어 ‘볼트에 저장됨’ 상태를 확인하세요. 서버 사본은 그대로 유지됩니다.
