Como organizar automaticamente e-mails com faturas

Nesta página
  • 1. Use uma etiqueta consistente para as faturas
  • 2. Crie uma regra que use informações visíveis ao aplicativo
  • 3. Confira a prévia antes de ativar
  • 4. Reúna as faturas antigas no mesmo conjunto
  • O que este fluxo de trabalho permite verificar e o que não permite

Por MailVault · 4 min de leitura

Você precisa da fatura de uma compra, mas o nome do fornecedor não é o que aparece no e-mail. O recibo chegou em outra conta. Uma atualização de entrega aparece antes do documento de que você realmente precisa. Buscar de novo acaba funcionando, mas no próximo mês você vai repetir a mesma procura.

Para organizar automaticamente e-mails com faturas, escolha uma etiqueta, crie uma regra específica, confira as correspondências na prévia e use essa etiqueta para reunir os resultados. No MailVault, Etiquetas automáticas pode aplicar a etiqueta quando chegam e-mails que correspondem à regra. Você pode revisar mensagens antigas separadamente e criar uma visão salva para o conjunto.

A mudança útil é pequena: decida como quer encontrar essas mensagens depois e faça os novos e-mails chegarem com essa etiqueta já aplicada.

Escolher uma etiqueta · Criar a regra · Conferir correspondências · Reunir os resultados

1. Use uma etiqueta consistente para as faturas

Comece com Faturas ou Recibos. Se precisar das duas, defina o que cada uma significa: uma fatura solicita pagamento; um recibo registra uma compra ou um pagamento. Uma etiqueta chamada Faturas não deve significar Pago sem que isso fique claro.

Use primeiro etiquetas manuais em algumas mensagens conhecidas. Escolha uma fatura de fornecedor, um recibo de compra e uma notificação sem relação. Esses exemplos dão uma base concreta para comparar com os resultados da regra.

2. Crie uma regra que use informações visíveis ao aplicativo

Abra Configurações → Etiquetas automáticas → Nova regra. Dê um nome à regra, selecione ou crie a etiqueta que ela deve aplicar e escreva uma instrução como:

Etiquete faturas e recibos de compras. Exclua atualizações de envio, confirmações de entrega e ofertas promocionais.

Em Refinar (opcional), adicione uma condição com o endereço exato do remetente, o domínio ou o assunto quando souber esses dados. Para um fornecedor habitual, uma condição de remetente e um assunto contendo “fatura” são um ponto de partida útil. Evite exigir um anexo, a menos que todas as faturas desejadas realmente tenham um: alguns fornecedores disponibilizam o documento por um link.

Etiquetas automáticas vê o remetente, o assunto, a pasta e se há um anexo. Não lê o corpo da mensagem nem o PDF anexado. Uma instrução sobre o valor total da fatura, a data de vencimento dentro de um PDF ou se uma fatura foi paga pede à regra que deduza informações que ela não tem.

Mantenha Na caixa de entrada → Manter na caixa de entrada durante os testes. A regra pode etiquetar os e-mails sem mudar sua rotina normal de leitura.

3. Confira a prévia antes de ativar

Escolha a conta a conferir e pressione Pré-visualizar. Isso mostra o que corresponderia sem aplicar etiquetas. Procure dois tipos de erro: uma atualização de entrega incluída como fatura e uma fatura real ignorada por ter um assunto vago.

Ajuste uma condição por vez e confira a prévia novamente. Se aparecer Não foi possível decidir, confira a configuração de IA antes de considerar a regra pronta. Regras em linguagem natural precisam de um modelo funcionando; as condições exatas reduzem os candidatos antes que o modelo os avalie. O guia de configuração de IA explica as opções disponíveis.

Por padrão, as regras usam processamento no dispositivo. Escolher um provedor remoto muda onde os metadados dos candidatos são processados; revise essa escolha nas configurações da regra. Você sempre pode etiquetar manualmente uma mensagem ambígua.

Quando as correspondências parecerem úteis, salve e ative a regra. Uma prévia é uma amostra, então confira também as primeiras faturas novas que chegarem.

4. Reúna as faturas antigas no mesmo conjunto

Use Retroagir para aplicar a regra salva aos e-mails antigos da conta selecionada. Revise os resultados antes de entregar o conjunto a outra pessoa. O MailVault permite desfazer a aplicação ao histórico se a regra tiver sido ampla demais.

Para uma revisão mensal, crie uma visão salva filtrada pela etiqueta de faturas e pelo período desejado. Uma visão pode reunir correspondências de várias contas sem mover as mensagens originais. Três visões salvas estão incluídas gratuitamente, contando as iniciais; o Premium permite mais.

O que este fluxo de trabalho permite verificar e o que não permite

Etiquetas automáticas e o uso manual de etiquetas são gratuitos. Uma etiqueta facilita reunir mensagens; ela não verifica um fornecedor, aprova um pagamento nem extrai campos contábeis. Abra a mensagem e o documento originais quando os detalhes importarem. Etiquetar também não cria um backup independente.

Se uma fatura antiga estiver faltando, confira as condições de assunto e remetente da regra, a conta selecionada e os e-mails disponíveis localmente. Para uma busca pontual, use o guia específico para pesquisar em um grande arquivo de e-mails. Para preservar documentos, siga o guia de arquivamento de e-mails para freelancers.

Comece com um fornecedor e algumas mensagens. Quando os resultados forem confiáveis, amplie a regra. O objetivo é um conjunto em que você confie o suficiente para abrir diretamente no próximo mês.

Facilite a busca pelas faturas do próximo mês.
