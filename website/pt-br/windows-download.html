MailVault para Windows

Seu download está começando.

O instalador está a caminho. Quando terminar, abra-o pela pasta Downloads. O Windows pode pedir uma confirmação antes; esta página explica o motivo e como conferir que o arquivo é nosso.

Baixar para Windows

Se o download não começar, use o botão acima.

Por que o Windows pode mostrar um aviso

Todo instalador baixado passa pelo Microsoft Defender SmartScreen. Ele olha duas coisas: quem assinou o arquivo e quantas pessoas já o baixaram e executaram.

O instalador do MailVault é assinado pelo Azure Artifact Signing, o serviço de assinatura da própria Microsoft. A Microsoft verifica a identidade da empresa antes de deixá-la assinar qualquer coisa, e o Windows confirma que a assinatura está intacta antes de rodar o instalador.

A reputação é o que leva tempo. O MailVault para Windows é novo e cada versão é um arquivo novo, então o SmartScreen pode ainda não conhecê-lo e mostrar “O Windows protegeu o computador”. Essa mensagem quer dizer que o arquivo ainda é pouco conhecido. Não quer dizer que algo nocivo foi encontrado.

  1. Se o navegador perguntar

    O Edge pode dizer que o arquivo “não é baixado com frequência”. Abra o menu de downloads, escolha os três pontos ao lado do arquivo e depois Manter.

  2. Se o SmartScreen aparecer

    Clique em Mais informações. Confira se o editor é MODERNIOS APLIKACIJOS, a empresa que faz o MailVault, e clique em Executar assim mesmo.

  3. Se o editor for outro

    Não execute o arquivo se aparecer Editor desconhecido ou qualquer outro nome. Apague-o e baixe de novo por esta página.

Confira você mesmo

Você não precisa acreditar só na nossa palavra. Clique com o botão direito no instalador, escolha Propriedades e abra a guia Assinaturas Digitais: lá aparece MODERNIOS APLIKACIJOS, e em Detalhes a assinatura está OK.

Cada versão no GitHub também mostra um checksum SHA-256 ao lado de cada arquivo. Rode Get-FileHash no instalador pelo PowerShell e compare os dois valores.
