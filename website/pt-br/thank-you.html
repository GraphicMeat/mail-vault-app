Se o download não começar, use o botão acima.

macOS

Instale no seu Mac

Um download para Apple Silicon e Intel, no macOS 11 ou posterior. O app é assinado e notarizado pela Apple.

  1. Abra o .dmg

    Abra o arquivo .dmg do MailVault pela sua pasta Downloads.

  2. Arraste para Aplicativos

    Arraste o MailVault para a pasta Aplicativos na janela que se abre.

  3. Abra o MailVault

    Abra-o em Aplicativos ou no Launchpad. O macOS pergunta uma vez se quer abrir um app baixado da internet: clique em Abrir.

Windows

Instale no Windows

Windows 10 ou 11, 64 bits. Rode o instalador pela sua pasta Downloads e depois abra o MailVault pelo menu Iniciar.

O MailVault para Windows é novo, então o SmartScreen pode não conhecê-lo ainda. Por que o Windows pode mostrar um aviso e como conferir o arquivo.

  1. Se o navegador perguntar

    O Edge pode dizer que o arquivo “não é baixado com frequência”. Abra o menu de downloads, escolha os três pontos ao lado do arquivo e depois Manter.

  2. Se o SmartScreen aparecer

    Clique em Mais informações. Confira se o editor é MODERNIOS APLIKACIJOS, a empresa que faz o MailVault, e clique em Executar assim mesmo.

  3. Se o editor for outro

    Não execute o arquivo se aparecer Editor desconhecido ou qualquer outro nome. Apague-o e baixe de novo por esta página.

Linux

Instale no Linux

Ubuntu 22.04+ ou Debian 12+, em Intel, AMD ou ARM. Prefere atualizações automáticas? Baixe na Snap Store ↗

  1. Abra um terminal em Downloads

    Ou dê dois cliques no arquivo .deb para abri-lo no seu gerenciador de pacotes.

  2. Instale o pacote

    Rode sudo apt install ./MailVault_*.deb. O ./ diz ao apt para usar o arquivo local.

  3. Abra o MailVault

    Encontre o MailVault no seu menu de aplicativos.
