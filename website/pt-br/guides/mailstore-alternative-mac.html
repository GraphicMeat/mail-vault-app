Melhor alternativa ao MailStore para Mac — MailVault

6 min de leitura

Se você já procurou por um software de arquivamento de e-mail, provavelmente encontrou o MailStore Home. Ele é uma das ferramentas mais populares para arquivar e-mails localmente no Windows. O problema é que o MailStore não roda no Mac. Nunca rodou. Se você está no macOS (ou no Linux), precisa de uma alternativa.

MailVault é um aplicativo de arquivamento de e-mail gratuito e de código aberto, feito especificamente para macOS e Linux. Ele faz o que o MailStore faz — arquivar e-mails IMAP no seu disco local — mas roda nativamente no Mac (Intel e Apple Silicon) e no Linux, guarda as mensagens em formatos abertos e padrão e não custa nada.

MailStore: o que ele faz bem

O MailStore Home é um produto sólido para quem usa Windows. Sendo justo com os pontos fortes dele:

  • Maduro e bem testado — O MailStore existe desde 2006. Ele lida bem com casos extremos e funciona com uma grande variedade de provedores de e-mail.
  • Busca em texto completo — O MailStore indexa os e-mails arquivados para uma busca rápida em todo o arquivo permanente.
  • Várias fontes — Além do IMAP, o MailStore consegue arquivar a partir de arquivos PST do Outlook, de servidores Exchange e de outros clientes de e-mail locais.
  • Versão corporativa — O MailStore Server foi feito para organizações que precisam de arquivamento centralizado de e-mail, com recursos de conformidade, trilhas de auditoria e políticas de retenção.

Para quem usa Windows em ambientes corporativos, o MailStore Server é difícil de superar. Mas, para uso pessoal em um Mac, ele nem sequer é uma opção.

Onde o MailVault ganha

Ele roda no Mac. Essa é a diferença mais evidente. Se você usa macOS, o MailStore não é uma opção. O MailVault roda nativamente no macOS (Intel e Apple Silicon) e no Linux. Sem Wine, sem máquina virtual, sem gambiarra.

Armazenamento em padrão aberto. O MailStore guarda os e-mails arquivados em um formato de banco de dados proprietário. Se o MailStore parar de ser desenvolvido, acessar esses e-mails fica difícil. O MailVault guarda cada e-mail como um arquivo .eml padrão — o formato RFC 5322, que qualquer cliente de e-mail abre. O seu arquivo permanente é só uma pasta de arquivos. Você pode abri-los no Apple Mail, no Thunderbird ou em qualquer editor de texto.

Código aberto. O código-fonte do MailVault está no GitHub. Você pode inspecioná-lo, auditá-lo, modificá-lo ou contribuir com ele. Para algo que lida com os seus e-mails pessoais, saber exatamente o que o software faz importa.

Ele também é um cliente de e-mail. O MailStore é puramente uma ferramenta de arquivamento — você arquiva os e-mails e depois usa um cliente separado para lê-los. O MailVault é os dois: você lê, busca, escreve, responde e encaminha e-mails direto no aplicativo, e os arquiva no seu disco local quando quer guardá-los para sempre.

Cache em segundo plano. O MailVault consegue baixar o conteúdo das mensagens automaticamente, em segundo plano, conforme você navega, montando aos poucos um arquivo local sem intervenção manual. O MailStore exige que você rode as tarefas de arquivamento explicitamente.

Onde o MailStore ganha

Sendo honesto sobre as diferenças:

  • Índice de busca em texto completo — O MailStore monta um índice de texto completo de todos os e-mails arquivados, para busca instantânea em arquivos grandes. A busca do MailVault usa a busca do lado do servidor IMAP para as consultas on-line e o acesso a arquivos para os e-mails locais, o que é menos sofisticado em arquivos muito grandes.
  • Importação de PST e Exchange — Se você tem arquivos PST do Outlook ou precisa arquivar direto de um servidor Exchange (e não por IMAP), o MailStore aceita essas fontes. O MailVault funciona só com IMAP.
  • Conformidade corporativa — O MailStore Server (a edição paga) oferece arquivamento centralizado, políticas de retenção, trilhas de auditoria e recursos de bloqueio legal de que as organizações precisam para a conformidade. O MailVault foi feito para uso pessoal e de pequenas empresas, não para conformidade corporativa.
  • Maturidade — O MailStore existe há quase 20 anos. Ele já lidou com mais casos extremos, mais provedores de e-mail e mais cenários de uso do que o MailVault viu até agora.

Quem deveria usar o MailVault?

O MailVault é a escolha certa se:

  • Você usa macOS ou Linux e precisa de arquivamento local de e-mails.
  • Você quer os seus e-mails arquivados em formatos padrão e abertos (e não em um banco de dados proprietário).
  • Você prefere um software livre e de código aberto, que dá para inspecionar e no qual dá para confiar.
  • Você quer um aplicativo que seja ao mesmo tempo cliente de e-mail e ferramenta de arquivamento — ler, enviar e arquivar em um só lugar.
  • Você é freelancer, consultor ou dono de uma pequena empresa e precisa de um arquivo pessoal de e-mails, sem a complexidade corporativa.
  • Você quer liberar espaço de e-mail arquivando localmente e apagando do servidor.

Se você precisa de recursos de conformidade corporativa, integração com Exchange ou importação de PST, o MailStore Server é a ferramenta melhor. Mas, para arquivamento pessoal de e-mail em um Mac, o MailVault faz bem o trabalho — e é gratuito.

Outras alternativas

Para completar, aqui estão outras opções que quem usa Mac às vezes considera:

  • Apple Mail + pastas locais — Você pode arrastar e-mails para caixas postais locais no Apple Mail, mas não há um fluxo de arquivamento em lote, não há exportação para Maildir, e buscar em pastas locais é lento com grandes volumes.
  • Thunderbird — gratuito e multiplataforma, mas o Thunderbird é um cliente de e-mail, não uma ferramenta de arquivamento. Ele não tem um fluxo dedicado de arquivo local. O armazenamento local dele usa o formato mbox, menos resistente que o Maildir.
  • Google Takeout / exportação do provedor — Uma exportação única em bloco para arquivos .mbox. Não é pesquisável, não é incremental, e o .mbox é um formato de arquivo único, propenso à corrupção em escala.

O MailVault preenche essa lacuna: um aplicativo dedicado de arquivamento de e-mail para Mac e Linux, com formatos abertos e sem custo.
