Como fazer backup de e-mails no Linux em EML

Um backup de e-mails no Linux deve resistir tanto a uma exclusão pelo provedor quanto a uma falha no disco. Comece arquivando mensagens em um cofre local independente e mantenha uma segunda cópia em outro lugar. O app do MailVault para Linux salva os e-mails arquivados como arquivos EML individuais em pastas Maildir.

1. Instale o app para Linux e conecte uma conta

Use os links para Linux na página de download e escolha o pacote e a arquitetura compatíveis com seu sistema. Siga as instruções atuais de instalação nessa página em vez de copiar comandos de outra distribuição. Adicione contas do Gmail ou Microsoft pelo fluxo de login compatível ou informe os dados de conexão fornecidos pelo seu provedor IMAP. Uma organização pode restringir o acesso independentemente do sistema operacional.

2. Crie um arquivo antes de fazer um backup

  1. Compare Caixa de entrada, Enviados e pastas personalizadas com seu webmail. Inclua pastas antigas e marcadores que você quer manter.
  2. Nas operações em massa, escolha as pastas e o período e selecione Arquivar. Isso cria cópias locais sem remover e-mails do servidor.
  3. Deixe o app aberto até a conclusão da tarefa. Confira as falhas e tente novamente as mensagens ausentes antes de considerar o arquivo completo.
  4. Escolha a origem Cofre e examine mensagens de vários anos, incluindo anexos.

Verifique o arquivo antes de confiar nele

  1. Mude a origem das mensagens para Cofre, em vez de Servidor ou Todas. Procure uma mensagem antiga que você reconheça.
  2. Desconecte-se da rede e abra algumas mensagens arquivadas de pastas e anos diferentes. Abra também seus anexos. Um assunto na lista não comprova que o corpo da mensagem foi salvo.
  3. Em Configurações, abra Backup e restauração e use Exportar backup. Escolha um local em uma segunda unidade. O ZIP contém o cofre, as contas e as configurações; não inclui mensagens que existem apenas no servidor.
  4. Confira se o ZIP abre, contém arquivos .eml e inclui as pastas que você pretendia preservar. Para e-mails importantes, teste a restauração de uma cópia em uma instalação separada antes de excluir qualquer coisa.

3. Proteja a cópia no disco

Use uma segunda unidade para o backup exportado. Uma segunda pasta no mesmo disco não protege contra uma falha nesse disco. Se a unidade for removível, verifique se está montada e permite gravação antes de uma execução agendada. Guarde e-mails privados em armazenamento criptografado e mantenha as credenciais de recuperação do backup em um lugar acessível mesmo se perder o computador.

O Maildir torna as mensagens individuais portáteis, mas o cofre ativo também contém metadados do app. Prefira o fluxo de backup/exportação do app para uma instalação em uso. Se copiar o cofre inteiro pelo sistema de arquivos, feche o app primeiro para não copiar arquivos durante uma gravação.

Posso automatizar isso?
