Como exportar e-mails do Outlook para EML

Nesta página

  • Exporte uma caixa do Outlook.com ou Microsoft 365 em EML

  • Demo rápida: confira se os e-mails estão no cofre

A exportação do Outlook depende da versão que você usa. O novo Outlook e o Outlook na Web permitem salvar mensagens individuais. O Outlook clássico usa outro fluxo de exportação, e um backup de caixa em PST não é uma pasta de arquivos EML. Para obter uma caixa inteira em arquivos EML individuais, arquive a conta online com um app para desktop compatível.

Salve uma mensagem individual no novo Outlook ou no Outlook na Web

  1. Abra a mensagem no painel de leitura ou em uma janela própria.
  2. No novo Outlook, escolha Mais ações → Salvar como. Na Web, abra o menu Mais ações da mensagem e procure Salvar como ou Baixar, dependendo da interface.
  3. Escolha um destino se for solicitado. Confira a extensão do arquivo salvo e abra-o em um app de e-mail para verificar a mensagem e os anexos.

Consulte as instruções de salvamento da Microsoft para sua versão se os menus forem diferentes. Salvar uma mensagem não exporta o restante da conversa ou da caixa.

Exporte uma caixa do Outlook.com ou Microsoft 365 em EML

  1. Instale o MailVault e adicione a conta usando o login da Microsoft. Contas do Outlook.com usam o Microsoft Graph no MailVault; o Microsoft 365 também permite a conexão OAuth do app. Políticas da organização podem impedir o acesso.
  2. Examine Caixa de entrada, Enviados e pastas personalizadas. Confirme se os e-mails necessários estão disponíveis na conta conectada; arquivos online e caixas compartilhadas podem exigir uma forma separada de acesso compatível.
  3. Selecione as pastas e datas nas operações em massa, escolha Arquivar e aguarde o fim do download. Use apenas Arquivar no primeiro backup.
  4. Mude para a origem Cofre e confira mensagens antigas e anexos. As mensagens arquivadas são salvas localmente como arquivos .eml individuais.

Verifique o arquivo antes de confiar nele

  1. Mude a origem das mensagens para Cofre, em vez de Servidor ou Todas. Procure uma mensagem antiga que você reconheça.
  2. Desconecte-se da rede e abra algumas mensagens arquivadas de pastas e anos diferentes. Abra também seus anexos. Um assunto na lista não comprova que o corpo da mensagem foi salvo.
  3. Em Configurações, abra Backup e restauração e use Exportar backup. Escolha um local em uma segunda unidade. O ZIP contém o cofre, as contas e as configurações; não inclui mensagens que existem apenas no servidor.
  4. Confira se o ZIP abre, contém arquivos .eml e inclui as pastas que você pretendia preservar. Para e-mails importantes, teste a restauração de uma cópia em uma instalação separada antes de excluir qualquer coisa.

E se você já tiver um arquivo PST ou MSG?

PST é um contêiner de dados do Outlook; MSG é outro formato para mensagens individuais. Renomear qualquer um deles para .eml não faz a conversão. Guarde o arquivo original, use o Outlook ou um conversor com suporte explícito ao formato e valide uma conversão de amostra antes de processar a coleção inteira. As instruções de arquivamento de contas online do MailVault aqui não importam nem convertem arquivos PST. Estas instruções sobre a estrutura dos arquivos se referem ao formato padrão Maildir. Configurações → Armazenamento também oferece armazenamento JMAP, que mantém os bytes originais das mensagens com registros JSON e elimina mensagens idênticas duplicadas.

Para o método nativo de backup de caixas da Microsoft, veja Fazer backup dos e-mails do Outlook. Para o fluxo no Mac, veja fazer backup de e-mails do Outlook.com no Mac. Se o problema for espaço, continue com liberar espaço no Outlook.com.

Baixe o MailVault grátis para criar seu primeiro arquivo local. O arquivamento manual é gratuito; o arquivamento automático, os backups agendados e Arquivar e excluir exigem Premium.
