How to Organize Invoice Emails Automatically

By MailVault · 4 min read

You need the invoice for a purchase, but the supplier’s name is not the name on the email. The receipt went to a second account. A delivery update appears before the document you actually need. Searching again works, eventually, but next month you will repeat the same hunt.

To organize invoice emails automatically, choose one tag, create a narrow rule, preview its matches, then use that tag to collect the results. In MailVault, Auto Tags can apply the label as matching mail arrives. You can review older mail separately and build a saved view for the collection.

The useful change is small: decide how you want to find these messages later, then make new mail arrive with that label already attached.

Choose a tag · Build the rule · Check matches · Collect the results

1. Give invoices one consistent label

Start with Invoices or Receipts. If you need both, decide what each means: an invoice asks for payment; a receipt records a purchase or payment. A tag named Invoices should not silently mean Paid.

Use manual tags on a few known messages first. Pick one supplier invoice, one purchase receipt and one unrelated notification. Those examples give you something concrete to compare with the rule’s output.

2. Create a rule that uses information the app can see

Open Settings → Auto Tags → New rule. Name the rule, select or create the tag it should apply, and write an instruction such as:

Tag purchase invoices and receipts. Exclude shipping updates, delivery confirmations and promotional offers.

Under Narrow it down, add an exact sender address, sender domain or subject condition when you know it. For one regular supplier, a sender condition plus a subject containing “invoice” is a useful starting point. Avoid requiring an attachment unless every invoice you want actually has one: some suppliers put the document behind a link.

Auto Tags sees the sender, subject, mailbox and whether an attachment exists. It does not read the message body or the attached PDF. An instruction about the invoice total, due date inside a PDF, or whether an invoice has been paid asks the rule to infer information it does not have.

Keep In the Inbox → Keep in Inbox while testing. The rule can label mail without changing your normal reading routine.

3. Preview before enabling

Choose the account to check and press Preview. This shows what would match without applying tags. Look for two kinds of mistakes: a delivery update included as an invoice, and a real invoice missed because its subject is vague.

Adjust one condition at a time and preview again. If you see Could not decide, check the AI setup before assuming the rule is ready. Plain-language rules need a working model; exact conditions narrow the candidates before that model evaluates them. The AI setup guide explains the available options.

Rules use on-device processing by default. Choosing a remote provider changes where the candidate metadata is processed; review that choice in the rule settings. You can always tag an ambiguous message yourself.

When the matches look useful, save and enable the rule. A preview is a sample, so check the first new invoices that arrive too.

4. Bring older invoices into the same collection

Use Backfill to apply the saved rule to past mail in the selected account. Review its results before using the collection for a handoff. MailVault offers an undo for the history pass if the rule was too broad.

For a monthly review, create a saved view filtered by your invoice tag and the date range you need. A view can gather matches across accounts without moving the original messages. Three saved views are included free, counting the starter views; Premium allows more.

What this workflow does and does not establish

Auto Tags and manual tagging are free. A tag makes messages easier to collect; it does not verify a supplier, approve a payment or extract accounting fields. Open the original message and document when the details matter. Tagging also does not create an independent backup.

If an older invoice is missing, check the rule’s subject and sender conditions, the selected account and the mail available locally. For a one-off retrieval, use the separate guide to searching a large email archive. For preserving documents, follow the freelancer email archive guide.

Start with one supplier and a handful of messages. Once the results are dependable, expand the rule. The goal is a collection you trust enough to open directly next month.
