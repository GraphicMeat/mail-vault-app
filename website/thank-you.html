macOS

Install on your Mac

One download for Apple Silicon and Intel, on macOS 11 or later. The app is signed and notarized by Apple.

  1. Open the .dmg

    Open the MailVault .dmg file from your Downloads folder.

  2. Drag to Applications

    Drag MailVault into the Applications folder in the window that opens.

  3. Open MailVault

    Open it from Applications or Launchpad. macOS asks once whether to open an app downloaded from the internet: click Open.

Windows

Install on Windows

Windows 10 or 11, 64-bit. Run the installer from your Downloads folder, then open MailVault from the Start menu.

MailVault for Windows is new, so SmartScreen may not know it yet. Why Windows may show a warning, and how to check the file.

  1. If your browser asks

    Edge may say the file “isn’t commonly downloaded”. Open the download menu, choose the three dots next to the file, then Keep.

  2. If SmartScreen appears

    Click More info. Check that Publisher reads MODERNIOS APLIKACIJOS, the company that makes MailVault, then click Run anyway.

  3. If the publisher is different

    Do not run the file if it says Unknown publisher or any other name. Delete it and download again from this page.

Linux

Install on Linux

Ubuntu 22.04+ or Debian 12+, on Intel, AMD or ARM. Prefer automatic updates? Get it from the Snap Store ↗

  1. Open a terminal in Downloads

    Or double-click the .deb file to open it in your software installer.

  2. Install the package

    Run sudo apt install ./MailVault_*.deb. The ./ tells apt to use the local file.

  3. Open MailVault

    Find MailVault in your applications menu.
