MailVault per Windows

Il download sta per iniziare.

Il programma di installazione è in arrivo. Al termine, aprilo dalla cartella Download. Windows potrebbe chiederti prima una conferma; questa pagina spiega perché e come verificare che il file sia nostro.

Scarica per Windows

Se il download non parte, usa il pulsante qui sopra.

Perché Windows può mostrare un avviso

Ogni programma di installazione scaricato viene controllato da Microsoft Defender SmartScreen. Guarda due cose: chi ha firmato il file e quante persone lo hanno già scaricato ed eseguito.

Il programma di installazione di MailVault è firmato tramite Azure Artifact Signing, il servizio di firma di Microsoft. Microsoft verifica l’identità dell’azienda prima di permetterle di firmare qualsiasi cosa, e Windows conferma che la firma è intatta prima di avviare l’installazione.

La reputazione è ciò che richiede tempo. MailVault per Windows è nuovo e ogni release è un file nuovo, quindi SmartScreen potrebbe non conoscerlo ancora e mostrare «Windows ha protetto il PC». Il messaggio indica che il file è poco diffuso. Non significa che sia stato trovato qualcosa di dannoso.

  1. Se il browser chiede conferma

    Edge potrebbe dire che il file «non viene scaricato comunemente». Apri il menu dei download, scegli i tre puntini accanto al file, poi Mantieni.

  2. Se compare SmartScreen

    Fai clic su Ulteriori informazioni. Controlla che l’autore sia MODERNIOS APLIKACIJOS, l’azienda che sviluppa MailVault, poi fai clic su Esegui comunque.

  3. Se l’autore è diverso

    Non eseguire il file se indica Autore sconosciuto o qualsiasi altro nome. Eliminalo e scaricalo di nuovo da questa pagina.

Controlla tu stesso

Non devi fidarti sulla parola. Fai clic destro sul programma di installazione, scegli Proprietà e apri la scheda Firme digitali: compare MODERNIOS APLIKACIJOS, e in Dettagli la firma risulta valida.

Ogni release su GitHub riporta anche un checksum SHA-256 accanto a ogni file. Esegui Get-FileHash sul programma di installazione in PowerShell e confronta i due valori.
