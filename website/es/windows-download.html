MailVault para Windows

Tu descarga está empezando.

El instalador está en camino. Cuando termine, ábrelo desde tu carpeta Descargas. Puede que Windows te pida confirmación antes; esta página explica por qué y cómo comprobar que el archivo es nuestro.

Descargar para Windows

Si la descarga no empieza, usa el botón de arriba.

Por qué Windows puede mostrar una advertencia

Microsoft Defender SmartScreen revisa cada instalador que descargas. Se fija en dos cosas: quién firmó el archivo y cuántas personas ya lo han descargado y ejecutado.

El instalador de MailVault está firmado con Azure Artifact Signing, el servicio de firma de Microsoft. Microsoft verifica la identidad de la empresa antes de permitirle firmar nada, y Windows confirma que la firma está intacta antes de ejecutar el instalador.

La reputación es lo que lleva tiempo. MailVault para Windows es nuevo y cada versión es un archivo nuevo, así que puede que SmartScreen aún no lo conozca y muestre «Windows protegió su PC». Ese mensaje significa que el archivo no es muy conocido. No significa que se haya encontrado nada dañino.

  1. Si tu navegador pregunta

    Edge puede decir que el archivo «no se descarga normalmente». Abre el menú de descargas, elige los tres puntos junto al archivo y luego Conservar.

  2. Si aparece SmartScreen

    Haz clic en Más información. Comprueba que el editor sea MODERNIOS APLIKACIJOS, la empresa que desarrolla MailVault, y haz clic en Ejecutar de todas formas.

  3. Si el editor es otro

    No ejecutes el archivo si dice Editor desconocido o cualquier otro nombre. Bórralo y vuelve a descargarlo desde esta página.

Compruébalo tú mismo

No tienes que creernos sin más. Haz clic derecho en el instalador, elige Propiedades y abre la pestaña Firmas digitales: aparece MODERNIOS APLIKACIJOS, y en Detalles se indica que la firma es correcta.

Cada versión en GitHub también muestra una suma de comprobación SHA-256 junto a cada archivo. Ejecuta Get-FileHash sobre el instalador en PowerShell y compara los dos valores.
