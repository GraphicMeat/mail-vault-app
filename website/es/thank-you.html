Descargar MailVault

Si la descarga no empieza, usa el botón de arriba.

macOS

Instalar en tu Mac

Una descarga para Apple Silicon e Intel, en macOS 11 o posterior. La app está firmada y notarizada por Apple.

  1. Abrir el .dmg

    Abre el archivo .dmg de MailVault desde tu carpeta Descargas.

  2. Arrastrar a Aplicaciones

    Arrastra MailVault a la carpeta Aplicaciones en la ventana que se abre.

  3. Abrir MailVault

    Ábrelo desde Aplicaciones o Launchpad. macOS pregunta una vez si quieres abrir una app descargada de internet: haz clic en Abrir.

Windows

Instalar en Windows

Windows 10 u 11, de 64 bits. Ejecuta el instalador desde tu carpeta Descargas y luego abre MailVault desde el menú Inicio.

MailVault para Windows es nuevo, así que puede que SmartScreen todavía no lo conozca. Por qué Windows puede mostrar una advertencia y cómo comprobar el archivo.

  1. Si tu navegador pregunta

    Edge puede decir que el archivo «no se descarga normalmente». Abre el menú de descargas, elige los tres puntos junto al archivo y luego Conservar.

  2. Si aparece SmartScreen

    Haz clic en Más información. Comprueba que el editor sea MODERNIOS APLIKACIJOS, la empresa que desarrolla MailVault, y haz clic en Ejecutar de todas formas.

  3. Si el editor es otro

    No ejecutes el archivo si dice Editor desconocido o cualquier otro nombre. Bórralo y vuelve a descargarlo desde esta página.

Linux

Instalar en Linux

Ubuntu 22.04+ o Debian 12+, en Intel, AMD o ARM. ¿Prefieres actualizaciones automáticas? Consíguelo en Snap Store ↗

  1. Abrir una terminal en Descargas

    O haz doble clic en el archivo .deb para abrirlo en tu gestor de paquetes.

  2. Instalar el paquete

    Ejecuta sudo apt install ./MailVault_*.deb. El ./ le indica a apt que use el archivo local.

  3. Abrir MailVault

    Busca MailVault en tu menú de aplicaciones.
