Why Windows may show a warning

Every installer you download is checked by Microsoft Defender SmartScreen. It looks at two things: who signed the file, and how many people have already downloaded and run it.

MailVault’s installer is signed through Microsoft’s own Azure Artifact Signing service. Microsoft checks the identity of the company before it lets that company sign anything, and Windows confirms the signature is intact before the installer runs.

Reputation is the part that takes time. MailVault for Windows is new, and every release is a new file, so SmartScreen may not know it yet and can show “Windows protected your PC”. That message means the file is not widely known. It does not mean anything harmful was found.

  1. If your browser asks

    Edge may say the file “isn’t commonly downloaded”. Open the download menu, choose the three dots next to the file, then Keep.

  2. If SmartScreen appears

    Click More info. Check that Publisher reads MODERNIOS APLIKACIJOS, the company that makes MailVault, then click Run anyway.

  3. If the publisher is different

    Do not run the file if it says Unknown publisher or any other name. Delete it and download again from this page.

Check it yourself

You do not have to take our word for it. Right-click the installer, choose Properties, and open the Digital Signatures tab: it lists MODERNIOS APLIKACIJOS, and Details says the signature is OK.

Each release on GitHub also lists a SHA-256 checksum next to every file. Run Get-FileHash on the installer in PowerShell and compare the two values.
