MailVault 正在前往你的“下载”文件夹。按下面的步骤安装并打开它。

下载 MailVault

如果下载没有开始，请使用上方的按钮。

macOS

在 Mac 上安装

Apple Silicon 和 Intel 共用一个下载包，需要 macOS 11 或更高版本。该应用已由 Apple 签名并公证。

  1. 打开 .dmg

    从你的“下载”文件夹打开 MailVault 的 .dmg 文件。

  2. 拖入“应用程序”

    在打开的窗口中，把 MailVault 拖入“应用程序”文件夹。

  3. 打开 MailVault

    从“应用程序”或 Launchpad 打开它。macOS 会询问一次是否要打开从网上下载的应用：点击“打开”。

Windows

在 Windows 上安装

64 位的 Windows 10 或 11。从你的“下载”文件夹运行安装程序，然后从“开始”菜单打开 MailVault。

Windows 版 MailVault 是新推出的，SmartScreen 可能还不认识它。Windows 为什么会显示警告，以及如何检查文件。

  1. 如果浏览器询问

    Edge 可能会提示该文件“不常下载”。打开下载菜单，选择文件旁的三个点，然后选择“保留”。

  2. 如果出现 SmartScreen

    点击“更多信息”。确认发布者显示为 MailVault 的开发公司 MODERNIOS APLIKACIJOS，然后点击“仍要运行”。

  3. 如果发布者不同

    如果显示“未知发布者”或其他任何名称，请不要运行该文件。删除它，然后从本页重新下载。

Linux

在 Linux 上安装

Ubuntu 22.04 及以上，或 Debian 12 及以上，支持 Intel、AMD 或 ARM。想要自动更新？在 Snap Store 获取 ↗

  1. 在“下载”文件夹中打开终端

    或者双击 .deb 文件，在软件包安装程序中打开它。

  2. 安装软件包

    运行 sudo apt install ./MailVault_*.deb。./ 告诉 apt 使用本地文件。

  3. 打开 MailVault

    在应用程序菜单中找到 MailVault。
