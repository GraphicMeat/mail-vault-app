谁在用 MailVault

MailVault 为真实的人解决的真实问题。

小企业的邮件留存

物流公司、会计和运营团队要处理发票、发货确认和合规单据，这些都不能删。MailVault 会把一切复制进你的保险库，让你在腾空邮箱的同时，不会丢掉法律要求你保留的记录。

  • 合规安全的留存
  • 按日期范围批量归档
  • 法庭也能读的标准 .eml 文件

清理邮箱

你 10GB 的邮箱满了。又满了。与其花钱买更多服务器存储，或者随手删掉一些旧邮件，不如用 MailVault 把它们归档到本地。腾出服务器空间，离线也能搜到一切。

  • 归档 + 从服务器删除
  • 即时本地搜索
  • 没有循环扣费的存储费用

在意隐私的人

你的邮件里装着你最私人的数据。MailVault 把一切都存在你的机器上 — 没有云同步，没有遥测，没有跟踪。凭据留在你操作系统的钥匙串里。开源，所以你可以核对每一行代码。

  • 无云端，无跟踪
  • macOS 钥匙串 / Linux Secret Service
  • 开源

离线访问邮件

在路上、远程办公，或者只是信不过手边的网络？邮件一旦归档，你的全部邮件历史都能离线使用 — 完全可搜索，不需要联网。

  • 完整的离线访问
  • 没有网络也能用
  • 跨所有账户的本地搜索
