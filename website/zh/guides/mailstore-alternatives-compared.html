MailStore 替代方案：七种选择，按使用场景分类

7 分钟阅读

合适的 MailStore 替代方案，取决于你要替换的是哪一个 MailStore，以及为什么要替换。MailStore Home 是一款供私人使用的免费 Windows 归档工具。MailStore Server 是一款面向企业的付费 Windows 归档。本文把七种真实的选择分为四组：在 Mac 或 Linux 上的个人使用、在 Windows 上的个人使用、开源归档服务器，以及 Microsoft 365 和 Google Workspace 已内置的工具。MailVault 是我们做的，是七种之一，我们把它的限制和其他产品的限制并列写出。想深入比较某一对，请阅读 MailVault 与 MailStore Home 对比或 MailStore Server 替代方案。

简短回答

  • 在 Mac 或 Linux 上的个人：MailVault，或者在 Mac 上用 Mail Archiver X。
  • 在 Windows 上、想要免费自己动手搭建的个人：Thunderbird 加 ImportExportTools NG，或者 MailVault。
  • 愿意自己运行服务器的公司：Piler、Mail-Archiver 或 Open Archiver。
  • 已经在用 Microsoft 365 或 Google Workspace 的公司：Microsoft Purview 或 Google 保险柜（Google Vault）。

适合在 Mac 或 Linux 上的个人

MailStore Home 需要 Windows 10 或 11，所以 Mac 和 Linux 用户只能另找出路。我们的 Mac 上的 MailStore 替代方案指南更深入地讨论了 Mac 的情况。

1. MailVault

MailVault 是一款适用于 macOS、Windows 和 Linux 的免费邮件应用，把你选择的邮件以普通 .eml 文件的形式，存放在你电脑上 Maildir 风格文件夹组成的本地保险库中。它可以连接 Gmail、Microsoft 365、Outlook.com 和任何 IMAP 账户，导入 Google Takeout 导出等 MBOX 文件，并用本地索引离线搜索它保存的所有内容。手动备份免费且不限次数。「归档」和「从服务器删除」作为两个单独的步骤都是免费的，而一步完成、在移除服务器副本之前检查每一份副本的「归档并删除」属于 Premium。

限制：不支持 PST 导入，不支持导入 Outlook 或 Thunderbird 配置文件，没有供多位用户共用的归档，也没有保留策略或法律保留。附件搜索、定时备份和清理规则属于 Premium。

2. Mail Archiver X

Moth Software 的 Mail Archiver X 是一款付费 Mac 应用，可以从 Apple Mail、Outlook、Thunderbird、Postbox 以及包括 Gmail 和 iCloud 在内的 IMAP 账户归档。它把归档保存在一个带搜索索引的内部数据库中，可以导出为 PDF 和 MBOX，归档可以放在内置或外置硬盘上。厂商也列出了网络存储，但它的手册说标准版需要本地归档。带有服务器组件的 Pro 版增加了多台电脑和多位用户的访问。当前版本为 8.2.4。

限制：仅限 Mac，而且归档是一个数据库，而不是每封邮件一个文件，所以要取出标准文件就得导出。价格写在厂商的手册中：$49.95 另加税，Pro 版 $150 起。

适合在 Windows 上的个人

在 Windows 上，MailStore Home 本身仍可免费用于私人用途。如果你无论如何都要离开它，或者想要一套在其他系统上也能用的方案，MailVault 同样可以在 Windows 上运行，此外还有一条免费的自己动手路线。

3. Thunderbird 加 ImportExportTools NG

Thunderbird 是一款适用于 Windows、macOS 和 Linux 的免费邮件客户端。它的「归档」按钮会把邮件移到一个归档文件夹，你可以把这个文件夹指向电脑上的本地文件夹，按年或按月归档。免费的 ImportExportTools NG 附加组件可以把邮件导出为 EML、HTML、PDF、CSV 或纯文本，把文件夹导出为 mbox，还能导入 mbox 和 EML 文件。

限制：Thunderbird 默认把每个文件夹存为一个 mbox 文件；Maildir 存储需要按账户手动开启，Mozilla 称之为实验性功能，并表示在开启之前，你应该知道如何提交错误报告和恢复邮件。归档需要手动进行，而且一旦邮件进入本地文件夹，备份该文件夹就是你自己的事了。详情请参阅 MailVault 与 Thunderbird。

开源归档服务器

这些更多是在替代 MailStore Server，而不是 MailStore Home。三者都可以免费使用，也都需要有人来安装、更新和备份服务器。

4. Mail-Archiver

Mail-Archiver（与 Mail Archiver X 是不同的产品）是一款基于 GPL-3 的自托管 Web 应用，在 Docker 中与 PostgreSQL 数据库一起运行。它可以同步 IMAP 账户，通过 Microsoft Graph 同步 Microsoft 365，连接个人 Outlook.com 账户，导入 MBOX 和压缩的 EML，并导出为同样的格式。多位用户可以共用它，按账户设置权限。它可以在你为每个账户设定的期限之后从服务器删除邮件，并保留登录、搜索和导出的访问日志。

限制：本身不提供 HTTPS，所以需要反向代理，而且它的 README 中没有列出法律保留功能。

5. Piler

Piler 是一款基于 GPL-3 的开源归档服务器。免费的开源版通过 SMTP 接收邮件，可接入 Office 365 和 Google 账户，读取 EML、Maildir 和邮箱文件，并包含归档和保留规则、法律保留、审计日志、去重、压缩和邮件加密。它通过 AD 或 LDAP、单点登录和双重验证码让用户登录。企业版是付费的，公开了价格档位，并增加了电子数据展示、多租户和可选的付费支持。

限制：免费版仅限单台服务器，提供社区支持，企业版价格只能单独询价。

6. Open Archiver

Open Archiver 是一个基于 AGPL-3 的自托管平台，用 Docker Compose 启动。它可以接收 Google Workspace、Microsoft 365、IMAP、PST 文件、压缩的 EML 和 MBOX，并为邮件和 PDF、DOCX 等附件的文本建立索引。它把邮件以 .eml 文件存储在本地磁盘或兼容 S3 的存储上，支持去重、压缩和静态加密，在接收时记录每封邮件的哈希值，并保留审计记录。

限制：它的 README 把法律保留标为尚待推出，默认配置至少需要 4 GB 内存。

企业级：你的服务商已经提供的归档

7. Microsoft Purview 或 Google 保险柜（Google Vault）

如果公司的邮件在 Microsoft 365 中，Microsoft Purview 的保留策略和标签会在用户删除邮箱项目之后保留其副本，电子数据展示（eDiscovery）可以搜索它们。请确认哪个 Microsoft 365 方案包含你需要的部分。如果邮件在 Google Workspace 中，Google 保险柜会在包含它的版本上处理保留规则、保留、搜索、导出以及保险柜活动的审计日志。

限制：副本仍留在同一服务商的云中，所以它们不是独立的备份。Google 表示，保险柜（Vault）不是数据归档，在你设置规则之前不会保留任何内容。如果需要一个基于 Windows、具备同类控制功能的独立归档，MailStore Server 本身仍是一个选择。

如何选择

  1. 归档是给谁用的？一个人的邮件是桌面端的工作。很多人的邮件、由其他人来搜索，是服务器端的工作。
  2. 你需要保留规则、法律保留或审计日志吗？如果需要，请看看 Piler、MailStore Server 或你的服务商自己的工具。这里的桌面端选项都做不到。
  3. 你的旧邮件在哪里？PST 文件指向 MailStore Home 或 Open Archiver。MBOX 文件和 IMAP 账户几乎适用于这里所有的工具。
  4. 最后你希望留下什么格式？如果你希望十年后不借助工具也能打开普通文件，请优先选择每封邮件一个文件的格式，例如 .eml。

常见问题

MailStore 最好的免费替代方案是什么？

这取决于用途。对于在 Mac、Windows 或 Linux 上的个人，选 MailVault 或 Thunderbird 加 ImportExportTools NG。对于在自己服务器上的公司归档，选 Piler 开源版、Mail-Archiver 或 Open Archiver。

MailStore 有开源的替代方案吗？

有。Piler 和 Mail-Archiver（均为 GPL-3）以及 Open Archiver（AGPL-3）都是开源的归档服务器。在桌面端，Thunderbird 是开源的，MailVault 的源代码也公开在 GitHub 上。

哪些 MailStore 替代方案能读取 PST 文件？

在这里的工具中，Open Archiver 可以导入 PST 文件，MailStore Home 和 MailStore Server 也能归档它们。MailVault、Mail-Archiver、Thunderbird 加 ImportExportTools NG 以及 Piler 的免费版都没有列出 PST 导入功能。

Mail-Archiver 和 Mail Archiver X 是同一个东西吗？

不是。Mail-Archiver 是一款在 Docker 中运行的免费自托管 Web 应用。Mail Archiver X 是 Moth Software 出品的付费 Mac 应用。
