如何在 Linux 上将邮件备份为 EML

  • 3. 保护磁盘上的副本
  • 可以自动执行吗？

Linux 邮件备份应能应对服务商删除邮件和硬盘故障。先将邮件归档到独立的本地保险库，再在其他位置保留第二份副本。MailVault 的 Linux 应用会将归档邮件以独立的 EML 文件保存在 Maildir 文件夹中。 这些文件结构说明适用于默认的 Maildir 格式。设置 → 存储还提供 JMAP 存储，将原始邮件字节与 JSON 记录一起保留，并对相同邮件去重。

1. 安装 Linux 应用并连接账户

使用下载页面上的 Linux 下载链接，选择适合您系统的软件包和架构。请遵循该页面的当前安装说明，不要照搬其他发行版的命令。通过支持的登录流程添加 Gmail 或 Microsoft 账户，或输入 IMAP 服务商提供的连接信息。无论使用哪种操作系统，组织都可能限制访问。

2. 先归档，再备份

  1. 将收件箱、已发送和自定义文件夹与网页邮箱进行核对。把需要保留的旧文件夹和标签也包含在内。
  2. 在批量操作中，选择文件夹和日期范围，然后选择归档。这会创建本地副本，不会移除服务器上的邮件。
  3. 让应用保持运行，直到任务完成。在认定归档完整之前，检查失败项目，并重试遗漏的邮件。
  4. 选择保险库来源，检查不同年份的邮件及其附件。

先验证归档，再依赖它

  1. 将邮件来源切换为保险库，而不是服务器或全部。搜索一封您记得的旧邮件。
  2. 断开网络，打开几封来自不同文件夹、不同年份的归档邮件，也打开它们的附件。列表中有邮件主题，并不能证明邮件正文已保存。
  3. 在设置中打开备份与恢复，使用导出备份。选择第二块硬盘上的位置。ZIP 包含保险库、账户和设置，不包含只存在于服务器上的邮件。
  4. 检查 ZIP 能否打开、是否包含 .eml 文件，以及是否包含您打算保留的文件夹。对于重要邮件，删除任何内容前，请在单独安装的应用中测试恢复一份副本。

3. 保护磁盘上的副本

将导出的备份放在第二块硬盘上。同一块硬盘中的另一个文件夹无法防范该硬盘故障。如果是可移动硬盘，请在定时任务运行前确认它已挂载且可写。将私人邮件存放在加密存储中，并把备份恢复凭据保存在即使丢失电脑也能取用的地方。

Maildir 使单封邮件易于迁移，但正在使用的保险库还包含应用元数据。对于运行中的应用，请优先使用应用自身的备份/导出流程。如果要在文件系统层面复制整个保险库，请先关闭应用，以免复制到尚未写完的文件。

可以自动执行吗？

MailVault Premium 支持定时备份。启用定时任务前，请先成功完成一次手动归档，并验证恢复流程。如果您偏好终端操作，请参照 IMAP 备份检查清单，比较工具的身份验证支持、存储格式、删除行为和恢复流程。
