如何把 iCloud 邮件导出到电脑

6 分钟阅读

Apple 没有为 iCloud 邮件提供一键「导出我的邮件」按钮，这让很多想备份 @icloud.com、@me.com 或 @mac.com 账户的人很意外。好消息是 iCloud 邮件完整支持标准 IMAP 访问，也就是说任何支持 IMAP 的邮件客户端或备份工具都能把你的邮件下载下来 — 你只需要正确配置，其中包括一个 Apple 特有的步骤：应用专用密码。

第 1 步：生成应用专用密码

Apple 要求你的 Apple ID 开启两步验证，并且不允许第三方应用用你平常的 Apple ID 密码登录。作为替代，你要专门为邮件访问生成一个独立的应用专用密码：

  • 打开 appleid.apple.com 并登录。
  • 在「登录与安全」下，选择「App 专用密码」。
  • 点击「生成 App 专用密码」，起一个像「邮件备份」这样的标签，Apple 会显示一个一次性密码。
  • 当你的邮件客户端或备份工具要求登录时，使用这个密码（而不是你平常的 Apple ID 密码）。

第 2 步：iCloud 邮件的 IMAP 设置

  • IMAP 服务器：imap.mail.me.com，端口 993，SSL/TLS。
  • SMTP 服务器：smtp.mail.me.com，端口 587，SSL/TLS，需要身份验证。
  • 用户名：你完整的 iCloud 邮箱地址（含 @icloud.com、@me.com 或 @mac.com）。

第 3 步：连接邮件客户端或归档工具，把一切下载下来

有了上面的应用专用密码和 IMAP 设置，任何标准邮件客户端都能连上并同步你的 iCloud 邮件。如果你只是要备份（并不打算日常使用这个客户端），那么专门的归档工具比完整的邮件客户端更合适，因为它就是为了下载并保存一切而做的，而不只是把收件箱显示出来。

为什么要导出 iCloud 邮件

人们专门备份 iCloud 邮件的几个常见理由：iCloud 免费方案的存储档位小得出名（5 GB，由邮件、照片和设备备份共用），邮件常常被夹在中间；有些人想要一份不依赖于留在 Apple 生态内的邮件副本；还有些人打算彻底离开 Apple 硬件，希望邮件历史能跟着走。

常见问题

为什么 iCloud 邮件需要应用专用密码？

Apple 要求 Apple ID 开启两步验证，并且不允许第三方邮件客户端用你平常的 Apple ID 密码登录。请在 appleid.apple.com 的「登录与安全」下生成一个独立的应用专用密码，用它来登录。

iCloud 邮件的 IMAP 服务器设置是什么？

IMAP 服务器 imap.mail.me.com，端口 993，使用 SSL/TLS。发信用 SMTP 服务器 smtp.mail.me.com，端口 587，SSL/TLS 并需要认证。用户名填你完整的 iCloud 地址。

iCloud 有类似 Google Takeout 的内置邮件导出功能吗？

没有。Apple 不提供针对 iCloud 邮件的一键导出。把邮件取出来的实际办法，是用应用专用密码通过 IMAP 连接一个邮件客户端或备份工具。

我可以在 Windows 上导出 iCloud 邮件吗？

原则上可以，只要用支持 IMAP 的 Windows 邮件客户端，配合应用专用密码。MailVault 本身目前支持 macOS 和 Linux，不支持 Windows。
