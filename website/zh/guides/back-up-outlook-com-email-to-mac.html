如何把 Outlook.com 和 Hotmail 邮件备份到你的 Mac

9 分钟阅读 · 更新于 2026 年 10 月 8 日

目前有四种可行的方法，把 Outlook.com 或 Hotmail 邮件备份到 Mac：从旧版 Mac 版 Outlook 导出 .olm 文件，从 Apple Mail 导出 .mbox 文件，在 Thunderbird 中借助附加组件导出，或者让 MailVault 把每封邮件保存为 .eml 文件。本页对它们进行比较，说明每种方法能给你什么，并解释在依赖备份之前如何检查它。如果你想在备份之后在线删除邮件，请阅读如何为 Hotmail 和 Outlook.com 腾出空间。

简短回答

  • 今天就用现有工具做一份副本：把账户添加到 Apple Mail，然后使用邮箱 > 导出邮箱。
  • 你已经在用 Mac 版 Outlook：从旧版 Outlook 导出 .olm 文件。
  • 一份持续更新、可以搜索的副本：MailVault（免费）或 Thunderbird（免费）。
  • 无论你选哪种：在在线删除任何内容之前，先从备份中打开旧邮件和附件。

开始之前

  • Microsoft 自己的导出需要桌面版 Outlook。Microsoft 的帮助页面说明，导出 Outlook.com 邮箱需要使用桌面版 Outlook：在 Windows 上导出 .pst 文件，或者从旧版 Mac 版 Outlook 导出 .olm 文件。如果你没有 Outlook，Microsoft 建议使用 30 天免费的 Microsoft 365 试用。
  • 其他应用必须使用新式登录。Microsoft 表示，从 2024 年 9 月 16 日起，其他邮件应用必须使用新式登录（OAuth）才能访问 Outlook.com，而不能只用用户名和密码。Apple Mail、Thunderbird 和 MailVault 都支持这种方式。
  • 检查你的磁盘空间。在 Outlook.com 中查看设置 > 帐户 > 存储。你的备份大约需要 Mac 上有这么多可用空间。

方法 1：旧版 Mac 版 Outlook（.olm 文件）

  1. 把你的 Outlook.com 账户添加到 Mac 版 Outlook，并等它同步完成。
  2. 切换到旧版 Outlook。Microsoft 只为旧版 Mac 版 Outlook 提供了导出说明，并表示对旧版 Mac 版 Outlook 的支持将于 2026 年 10 月结束。它的帮助页面没有介绍新版 Mac 版 Outlook 的导出，所以在依赖这种方法之前，请查看 Microsoft 页面上的最新状态。
  3. 在工具选项卡上，选择导出。如果看不到它，请检查更新，然后在文件菜单中查找。
  4. 在 Export to Archive File (.olm)（导出到存档文件）中，勾选你需要的项目，选择继续，然后选择文件的保存位置。

你得到的是：一个包含你邮件的 .olm 文件，如果你勾选了联系人和日历，也会包含它们。它的用途是通过工具 > 导入重新导入 Mac 版 Outlook。适合：已经在用 Mac 版 Outlook 的人。

方法 2：Apple Mail（.mbox 文件）

  1. 在「邮件」中，选择邮件 > 添加账户，输入你的 Outlook.com 地址并按步骤操作。Microsoft 表示，把账户设置为 Outlook.com 时，Apple Mail 会使用新式登录。
  2. 选择邮件 > 设置 > 账户 > 账户信息，把下载附件设为全部。「邮件」总会下载图片、PDF、视频和音频。设为最近时，其他类型的附件只下载过去 15 个月的。
  3. 等每个文件夹都下载完。打开几封最旧的邮件确认一下。
  4. 选中一个或多个邮箱，然后选择邮箱 > 导出邮箱。选择一个文件夹并确认。

你得到的是：每个邮箱一个 .mbox 包。如果你再次导出，「邮件」会在旧文件旁边新建一个文件，例如 My Mailbox 3.mbox，而不是覆盖它。以后要阅读备份，请使用文件 > 导入邮箱；邮件会出现在一个名为导入的新邮箱中。适合：不用安装任何东西就快速做一份副本。每次导出都是一份快照，所以新邮件需要重新导出。

方法 3：Thunderbird（.mbox 或 .eml 文件）

  1. 安装 Thunderbird 并添加你的 Outlook.com 账户。Mozilla 2026 年的指南说，要把身份验证方式设为 OAuth2，并在 Thunderbird 自己的设置中允许来自 Microsoft 网站的 Cookie。
  2. 在账户设置 > 同步与存储中，打开在此计算机上保存此账户的消息。不打开的话，Thunderbird 只保留邮件头，其余部分从服务器获取。
  3. 让每个文件夹都下载完。
  4. 安装 ImportExportTools NG 附加组件。它可以把一个文件夹导出为 .mbox 文件，或把文件夹中的邮件导出为 .eml、HTML、PDF、CSV 或纯文本文件。

适合：同时想要一款免费、开源的日常邮件应用的人。工作或学校账户可能需要管理员先批准 Thunderbird。

方法 4：MailVault（可以搜索的 .eml 文件）

MailVault 是一款适用于 macOS、Windows 和 Linux 的免费邮件应用，会在你电脑上的保险库里保留一份邮件副本。不存在 MailVault 账户，你的邮件也不会经过 MailVault 服务器。下面的步骤适用于从我们网站下载的版本。Mac App Store 版在一些地方有所不同，比如备份设置和移动保险库。

连接你的 Outlook.com 账户

  1. 下载 MailVault 并打开它。请使用 2.19.1 或更高版本，该版本修复了 Outlook.com 账户的归档问题。
  2. 选择添加账户，然后选择 Outlook / Microsoft 365，并输入你的地址。
  3. 选择使用 Microsoft 账户登录。Microsoft 的登录页面会在你的浏览器中打开。你返回之后，MailVault 会自动添加账户。

MailVault 能识别 outlook.com、hotmail.com 和 live.com 地址（以及各地区版本），并通过 Microsoft Graph（Microsoft 的邮件 API）连接它们。你不需要输入 IMAP 设置或应用专用密码。工作和学校的 Microsoft 365 账户则通过 IMAP 使用 OAuth2 登录，规则严格的组织可以在高级（企业）下设置自己的客户端 ID 和租户 ID。

进行备份

  1. 打开设置 > 备份与恢复 > 备份设置。
  2. 在备份内容下，选择全部邮件（从服务器下载）。另一个选项仅已归档邮件只复制已经在你保险库中的邮件。
  3. 如果你有外置硬盘，为第二份副本选择一个文件夹。这是一份独立的副本，MailVault 在日常使用中不会读取它。
  4. 在备份计划标签页上，选择立即备份所有账户。手动备份免费，没有额度限制。

你得到的是：每封邮件一个 .eml 文件，存放在 Maildir 文件夹中，按账户和文件夹分类。在 Mac 上，默认位置是 ~/Library/Containers/com.mailvault.app/Data/Library/Application Support/com.mailvault.app/。你可以把保险库移到另一块硬盘上，Mac App Store 版除外。之后的备份是增量的：只下载新邮件。这些邮件可以在 MailVault 中搜索，离线也可以。

免费版与 Premium：连接账户、阅读、搜索、归档和手动备份都是免费的。定时自动备份、备份健康监测、「全部保存」（在后台下载每个文件夹和全部历史并保留下来）以及一步完成的归档并删除属于 Premium，目前按抢先体验价为每月 $4 或每年 $25。

Outlook.com 账户的已知限制：由于这类账户使用 Microsoft Graph，暂时无法使用稍后提醒，无法把 MBOX 文件恢复到服务器，已删除的邮件可以恢复到你的电脑上但不能恢复到服务器，连接测试后也不会显示收件箱数量。阅读、删除、移动、标记和备份都与其他账户一样正常。

如何检查你的备份是否完整

  1. 比较数量。记下 Outlook.com 中每个大文件夹有多少封邮件，并与备份对比。在 MailVault 中，每个文件夹的标题会显示其中有多少封邮件在你的保险库里，例如 已存入保险库：79 / 79。每个文件夹的服务器与保险库数量对照表属于 Premium（备份健康监测）。
  2. 打开最旧的邮件，而不只是最近的。缺漏往往藏在旧文件夹里。
  3. 打开几种不同类型的附件：一个 PDF、一张照片、一个办公文档。
  4. 搜索你记得的多年前的内容，比如一个名字或一个订单号。
  5. 在生成这些文件的应用之外打开它们。双击一个 .eml 文件，它会在 Apple Mail 中打开。通过文件 > 导入邮箱导入 .mbox。
  6. 在另一块硬盘上保留第二份副本。一台笔记本上的一份副本不算备份。

常见问题

没有 Outlook，能把 Hotmail 邮件导出到 Mac 吗？

能。Apple Mail 可以下载你的 Outlook.com 邮件，并把每个邮箱导出为 .mbox 文件。Thunderbird 借助导出附加组件也能做到，MailVault 则把每封邮件保存为 .eml 文件。Microsoft 自己的导出需要桌面版 Outlook。

邮件备份用哪种文件格式最好？

其他应用能打开的格式。一个 .eml 文件保存一封邮件及其附件，一个 .mbox 文件保存整个邮箱。Apple Mail 可以打开 .eml 文件，也可以导入 .mbox 文件。.olm 文件的用途是重新导入 Mac 版 Outlook。

MailVault 支持 Hotmail 和 Live.com 地址吗？

支持。MailVault 把 outlook.com、hotmail.com 和 live.com 地址视为个人 Microsoft 账户。你在浏览器中用 Microsoft 账户登录，MailVault 通过 Microsoft Graph 连接，所以无需填写任何 IMAP 设置。

邮件备份会保持最新吗？

从 Apple Mail 或 Outlook 导出的是一份快照，所以要包含新邮件就得重新导出。在 MailVault 中，你再运行一次备份，只会下载新邮件。定时自动备份是 MailVault Premium 的一部分。

Outlook.com 里还有「导出邮箱」按钮吗？

Microsoft 当前的帮助页面只介绍了用桌面版 Outlook 导出。较早的指南提到 Outlook.com 设置中有一个「导出邮箱」按钮。如果你的账户里看不到它，请使用本页介绍的方法之一。
