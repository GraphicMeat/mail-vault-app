MailStore Server 替代方案：按归档的使用者来挑选

7 分钟阅读

本页面向所有在寻找 MailStore Server 替代方案的人。MailStore Server 是面向企业的付费版本：一个集中归档多个邮箱的中央归档，带有保留规则、法律保留和审计日志。如果这正是你需要的，诚实的答案是另一款服务器产品，比如 Piler、Mail-Archiver 或 Open Archiver，或者 Microsoft 365 和 Google Workspace 已经内置的保留工具。MailVault 不在其中。它是一款为个人管理自己邮件的桌面应用。如果你比较的是免费的家庭版，请阅读 MailVault 与 MailStore Home 对比。要把所有选择并排比较，请参阅 MailStore 替代方案对比。

简短回答

  • 需要合规、保留或法律保留功能的公司归档：在自己的服务器上运行 Piler 开源版、Mail-Archiver 或 Open Archiver；如果你的邮件已经在 Microsoft 365 或 Google Workspace 中，则用 Microsoft Purview 和 Google 保险柜。
  • 个人，或每人各管自己邮箱的小团队：你多半不需要服务器。像 MailVault 这样的桌面归档工具就够了。

MailStore Server 能做什么

MailStore 把 Server 描述为面向中小企业的邮件归档软件。以下是它的产品页面目前列出的内容：

  • 平台：Windows 11 以及 Windows Server 2016 至 2025。
  • 价格：五用户入门套装 295 EUR 起（另加增值税），含一年的 Standard Update & Support。最低订购五个用户，一次安装最多支持 2,000 个用户。提供 30 天试用。
  • 来源：Microsoft 365、Exchange Server、Google Workspace、任何 IMAP 或 POP3 服务器、PST 和 EML 文件，以及日志记录（journaling），这样邮件在到达邮箱之前就可以被归档。
  • 合规：保留策略、法律保留、审计日志，以及供外部审计人员使用的审计员用户类型。它存储内容的 SHA 哈希值，并用 AES-256 加密归档。
  • 访问：员工通过 Outlook 加载项或可在手机上使用的 Web 界面搜索归档。

MailStore 是 OpenText 的子公司。这些功能正是企业购买它的原因，任何真正的替代品都需要具备其中的大部分。

Piler

在 MailStore Server 的合规方面，Piler 是最接近的开源对应产品。它的开源版是免费的。它通过 SMTP 接收邮件，可接入 Office 365 和 Google 账户，读取 EML、Maildir 和邮箱文件，并包含归档和保留规则、法律保留、审计日志、去重和邮件加密。企业版是付费的，公开了价格档位，并增加了电子数据展示、多租户和可选的付费支持。

Mail-Archiver

Mail-Archiver（不是 Mac 应用 Mail Archiver X）适合想要一个网页、让几个人一起搜索已归档邮件的小型办公室。它可以同步 IMAP 账户，通过 Microsoft Graph 同步 Microsoft 365，导入 MBOX 和压缩的 EML 文件，并导出为同样的格式。用户按账户获得权限，还可以通过 OpenID Connect 登录。它可以在你为每个账户设定的期限之后从服务器删除邮件，还有一项设置可以禁止从归档中手动删除。它本身不提供 HTTPS，所以前面需要一个反向代理。

Open Archiver

Open Archiver 可以接收 Google Workspace、Microsoft 365、IMAP 以及 PST、MBOX 和 EML 文件。它为邮件文本和 PDF、DOCX 等附件建立索引，在接收时存储每封邮件的哈希值以便发现改动，并保留审计记录。它的 README 仍把法律保留列为待办事项，所以在纠纷中依赖它之前，请先确认当前状态。

你的服务商已经提供的工具

如果你的公司已经在为 Microsoft 365 或 Google Workspace 付费，请先看看那里。Microsoft Purview 的保留策略会在用户删除邮箱项目之后，在邮箱的「可恢复的项目」文件夹中保留一份副本，电子数据展示仍然可以找到它们。请确认哪个 Microsoft 365 方案包含你需要的部分。Google 保险柜为 Gmail 和其他 Workspace 数据处理保留、保留、搜索和导出。Google 明确表示保险柜不是数据归档：在你设置规则之前它不会保留任何内容，过期且未被保留的数据会照常删除。

MailVault 不适用的情况

MailVault 是我们做的，所以直说：MailVault 不能替代 MailStore Server。它：

  • 没有中央归档服务器，也没有在用户之间共享的归档。
  • 没有访问他人邮箱的管理员权限，也没有日志记录（journaling）。
  • 没有保留策略、法律保留、审计记录或审计员角色。
  • 不支持 PST 导入。

如果审计人员、监管机构或你的法务团队会就公司的邮件提出问题，请选择上面的某个服务器方案。

MailVault 适合谁

很多搜索 MailStore Server 替代方案的人根本不需要服务器。他们是一个邮箱满了的人，一个想保留每一段客户往来的自由职业者，或者一个每人各管自己收件箱的三人团队。对他们来说，服务器是额外的负担：一台需要运行的机器，需要安装的更新，还有归档本身的备份。

MailVault 是一款适用于 macOS、Windows 和 Linux 的免费桌面应用。每个人各自安装，登录自己的 Gmail、Microsoft 365、Outlook.com 或 IMAP 账户，在自己的电脑上保留一份邮件副本。不存在 MailVault 账户，邮件的传输路径上也没有 MailVault 服务器，源代码公开在 GitHub 上。面向自由职业者和小型企业的邮件归档指南更详细地介绍了这种情况。

MailVault 能做什么

以普通文件构成的本地归档

你保留的每封邮件都是 Maildir 风格文件夹中的一个标准 .eml 文件，每封邮件一个文件，所以其他邮件应用也能打开它。保险库可以移到外置硬盘或挂载的 NAS 上：MailVault 会复制所有内容，检查每个文件都已到达，然后才删除原文件。Mac App Store 版不支持这种移动。备份运行时还可以把第二份副本写入你选择的文件夹。

在你自己的电脑上搜索

本地全文索引可以搜索每一封已保存的邮件，联网与否都可以。你可以按发件人、日期、文件夹或标签缩小范围。在我们公布的搜索测试中，在 50,000 封邮件中最慢的一次搜索耗时 14 毫秒。在 PDF 和 Office 附件内搜索是 Premium 功能。

备份

每个账户的手动备份都免费且不限次数。定时备份以及按文件夹显示服务器、本地和外部副本的数量，属于 Premium。

先归档再删除，中间经过检查

「归档」把邮件复制进你的保险库，服务器副本保持不变。「从服务器删除」移除服务器副本。两者都是免费的。归档并删除（Premium）一步完成两者：它把每封邮件复制进你的保险库，检查副本确实存在，然后才从服务器删除。任何没有通过检查的邮件都会留在服务器上。「归档、备份并删除」（Premium）还会把一份副本写入你的备份文件夹，并在移除任何内容之前检查两份副本。

不需要服务器的小团队方案

对于一个两到五人、没人需要搜索同事邮件的团队，这样就够了：

  1. 每个人安装 MailVault，并添加自己的账户。
  2. 每个人在 设置、备份与恢复 中，在自己掌控的硬盘上选择一个第二份副本文件夹，比如外置 SSD 或 NAS 共享。
  3. 运行一次备份，然后归档较早的年份。只从服务器删除已经在保险库中的邮件。使用 Premium 时，「归档并删除」会替你做这项检查。

你放弃的是：一个人无法搜索另一个人的归档，也没有关于谁做了什么的集中记录。如果你需要其中任何一项，就需要服务器。

常见问题

MailStore Server 有免费的替代方案吗？

有，只要你能运行服务器。Piler 开源版、Mail-Archiver 和 Open Archiver 都是免费的开源归档服务器，Piler 的免费版包含保留规则、法律保留和审计日志。许可不花钱，但你需要自己安装、更新和备份服务器。

公司可以用 MailStore Home 代替 MailStore Server 吗？

MailStore 表示 Home 可免费用于家庭中的私人用途，并建议企业在商业用途中使用 MailStore Server。在把 Home 用于工作之前，请阅读 MailStore 的许可条款。

MailVault 是合规或法律保留归档吗？

不是。MailVault 在你自己的电脑上保留一份你自己邮件的个人副本。它没有保留策略、法律保留、审计记录或中央归档，所以在合规方面不能替代 MailStore Server。

哪些 MailStore Server 替代方案可以在 Linux 上运行？

MailStore Server 在 Windows 11 和 Windows Server 上运行。Mail-Archiver 和 Open Archiver 在 Docker 中运行，Piler 的文档说明了如何为 Ubuntu 构建 .deb 安装包。

下一步做什么

如果需求是合规，请试用一款服务器产品，或者在一台测试机器上部署 Piler 或 Mail-Archiver，归档一个邮箱。如果是每人一个邮箱，请免费下载 MailVault，先在一个账户上试用。如果你之后想要定时备份或一步完成的「归档并删除」，Premium 按抢先体验价为每月 $4 或每年 $25（参阅价格）。
