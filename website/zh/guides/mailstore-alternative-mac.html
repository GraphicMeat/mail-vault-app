Mac 上最好的 MailStore 替代方案 — MailVault

6 分钟阅读

如果你搜过邮件归档软件，多半见过 MailStore Home。它是 Windows 上最流行的本地邮件归档工具之一。问题在于 MailStore 不能在 Mac 上运行。它从来就不能。如果你用的是 macOS（或 Linux），你需要一个替代品。

MailVault 是一款专为 macOS 和 Linux 打造的免费开源邮件归档应用。它做的事和 MailStore 一样 — 把 IMAP 邮件归档到你的本地磁盘 — 但它在 Mac（Intel 和 Apple Silicon）与 Linux 上原生运行，以标准开放格式存储邮件，而且分文不取。

MailStore 做得好的地方

对 Windows 用户来说，MailStore Home 是个扎实的产品。公平地说说它的强项：

  • 成熟且经过充分检验 — MailStore 从 2006 年就有了。它对各种边角情况处理得不错，支持的邮件服务商也很广。
  • 全文搜索 — MailStore 会为归档的邮件建索引，让你在整份归档里做快速全文搜索。
  • 多种来源类型 — 除了 IMAP，MailStore 还能从 Outlook 的 PST 文件、Exchange 服务器和其他本地邮件客户端归档。
  • 企业版 — MailStore Server 面向需要集中式邮件归档的机构，带合规功能、审计轨迹和留存策略。

对企业环境里的 Windows 用户来说，MailStore Server 很难被超越。但在 Mac 上做个人使用，它根本就不是一个选项。

MailVault 强在哪里

它能在 Mac 上跑。这是最明显的差别。如果你用 macOS，MailStore 根本不是一个选项。MailVault 原生支持 macOS（Intel 和 Apple Silicon）以及 Linux。不需要 Wine，不需要虚拟机，也不需要任何变通办法。

开放标准的存储。MailStore 把归档的邮件存在一个专有的数据库格式里。如果 MailStore 停止开发，要拿到那些邮件就变得很麻烦。MailVault 把每封邮件都存成标准的 .eml 文件 — 任何邮件客户端都能打开的 RFC 5322 格式。你的归档就是一个装着文件的文件夹。你可以用 Apple Mail、Thunderbird，甚至文本编辑器打开它们。

开源。MailVault 的源代码在 GitHub 上。你可以查看、审计、修改它，也可以为它贡献代码。对一个经手你私人邮件的东西来说，清楚地知道这软件到底做了什么，是要紧的。

它同时也是一个邮件客户端。MailStore 纯粹是归档工具 — 你归档完邮件，还得另外用一个客户端去读。MailVault 两样都是：你可以直接在应用里阅读、搜索、撰写、回复和转发邮件，想永久保留时再把它们归档到本地磁盘。

后台缓存。MailVault 可以在你浏览的同时于后台自动下载邮件内容，让本地归档一点点建起来，不需要你手动干预。MailStore 则要求你明确地去运行归档任务。

MailStore 强在哪里

诚实地说说差距：

  • 全文搜索索引 — MailStore 为所有归档邮件建立全文索引，在大规模归档里也能即时搜索。MailVault 的搜索在线时用 IMAP 服务器端搜索，本地邮件则按文件访问，面对特别大的归档时不如前者精细。
  • PST 和 Exchange 导入 — 如果你有 Outlook 的 PST 文件，或者需要直接从 Exchange 服务器归档（而不是走 IMAP），MailStore 支持这些来源。MailVault 只支持 IMAP。
  • 企业合规 — MailStore Server（付费版）提供集中式归档、留存策略、审计轨迹和法律保全功能，这些是机构做合规所需要的。MailVault 面向个人和小企业使用，不面向企业合规。
  • 成熟度 — MailStore 已经存在了将近 20 年。它见过的边角情况、邮件服务商和用户场景，都比 MailVault 目前见过的多。

谁更该选 MailVault？

如果符合以下情况，MailVault 就是对的选择：

  • 你用 macOS 或 Linux，并且需要本地邮件归档。
  • 你希望归档的邮件保存为标准的开放格式（而不是专有数据库）。
  • 你更偏好免费的开源软件，可以自己查看、自己判断是否可信。
  • 你想要一个既是邮件客户端又是归档工具的应用 — 阅读、发送和归档都在一个地方。
  • 你是自由职业者、顾问或小企业主，需要一份个人邮件归档，但不想要企业级的复杂度。
  • 你想通过归档到本地再从服务器删除来腾出邮箱空间。

如果你需要企业合规功能、Exchange 集成或 PST 导入，MailStore Server 是更好的工具。但要在 Mac 上做个人邮件归档，MailVault 干得不错 — 而且它免费。

其他替代方案

为完整起见，这里列出 Mac 用户有时会考虑的其他选项：

  • Apple Mail + 本地文件夹 — 你可以把邮件拖进 Apple Mail 的本地邮箱文件夹，但没有批量归档的流程，没有 Maildir 导出，而且量一大，搜索本地文件夹就很慢。
  • Thunderbird — 免费且跨平台，但 Thunderbird 是邮件客户端，不是归档工具。它没有专门的本地归档流程。它的本地存储用的是 mbox 格式，抗损坏能力不如 Maildir。
  • Google Takeout / 服务商导出 — 一次性批量导出成 .mbox 文件。不能搜索，不能增量，而且 .mbox 是单文件格式，规模一大就容易损坏。

MailVault 补上了这块空缺：一款面向 Mac 和 Linux 的专用邮件归档应用，格式开放，分文不取。
