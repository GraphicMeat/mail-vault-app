Mac 上的 MailStore 替代方案：MailVault

6 分钟阅读

如果你搜索过邮件归档软件，很可能已经见过 MailStore Home。它是在 Windows 上把邮件归档到本地最流行的工具之一。问题是，MailStore Home 只能在 Windows 10 和 11 上运行，没有 Mac 版。如果你用的是 macOS（或 Linux），就需要一个替代方案。

MailVault 是一款适用于 macOS、Windows 和 Linux 的免费邮件应用，把你的邮件归档到你自己的磁盘上。它在你的 Mac（Intel 或 Apple Silicon）上保留一份 Gmail、Microsoft 365、Outlook.com 和 IMAP 邮件的副本，以标准开放格式存储，核心应用不花一分钱。

本页讲的是 Mac。想看与 Windows 版的正面对比，请阅读 MailVault 与 MailStore Home 对比。如果你需要为整个公司建立归档，请参阅 MailStore Server 替代方案；要把所有选择并排比较，请参阅 MailStore 替代方案对比。

MailStore 做得好的地方

对 Windows 用户来说，MailStore Home 是个扎实的产品。公平地说说它的强项：

  • 成熟且经过充分检验 — MailStore 从 2006 年就有了。它对各种边角情况处理得不错，支持的邮件服务商也很广。
  • 全文搜索 — MailStore 会为归档的邮件建索引，让你在整份归档里做快速全文搜索。
  • 多种来源类型 — 除了 IMAP，MailStore 还能从 Outlook 的 PST 文件、Exchange 服务器和其他本地邮件客户端归档。
  • 企业版 — MailStore Server 面向需要集中式邮件归档的机构，带合规功能、审计轨迹和留存策略。

MailStore Server 面向中小企业，在 Windows 和 Windows Server 上运行。对于在 Mac 上的个人使用，这两个版本都不是选项。

MailVault 强在哪里

它能在 Mac 上跑。这是最明显的差别。如果你用 macOS，MailStore 根本不是一个选项。MailVault 原生支持 macOS（Intel 和 Apple Silicon）以及 Linux。不需要 Wine，不需要虚拟机，也不需要任何变通办法。

开放的标准存储。MailStore 把你归档的邮件保存在它自己的归档文件中，要取出 EML 或 MSG 文件就得导出。如果 MailStore 停止开发，访问这些邮件就会变得更困难。MailVault 把每封邮件存为标准的 .eml 文件，也就是其他邮件客户端都能打开的 RFC 5322 格式。你的归档不过是一个装满文件的文件夹。你可以在 Apple Mail、Thunderbird 或任何文本编辑器中打开它们。

源代码公开在 GitHub 上。MailVault 的源代码公开在 GitHub 上。你可以阅读代码，检查它如何处理你的邮件。对于一个经手你私人邮件的软件来说，确切知道它在做什么很重要。

它同时也是一个邮件客户端。MailStore 纯粹是归档工具 — 你归档完邮件，还得另外用一个客户端去读。MailVault 两样都是：你可以直接在应用里阅读、搜索、撰写、回复和转发邮件，想永久保留时再把它们归档到本地磁盘。

本地搜索，离线可用。MailVault 为你 Mac 上的邮件建立全文索引，无需联网即可搜索。你可以按发件人、日期、文件夹或标签缩小范围。在我们公布的搜索测试中，在 50,000 封邮件中最慢的一次搜索耗时 14 毫秒。

有多少内容留在你的 Mac 上。默认情况下，MailVault 在你的电脑上保留最近几个月的邮件，你可以选择 1、3、6 或 12 个月。你归档的邮件和你的备份永远不会因这项设置而被删除。「全部保存」（Premium）会保留每个文件夹和全部历史。

先归档再删除，并经过检查。归档邮件和从服务器删除邮件作为两个单独的步骤都是免费的。归档并删除（Premium）一次完成两者：它把每封邮件复制进你的保险库，检查副本，然后才从服务器删除。

MailStore 强在哪里

诚实地说说差距：

  • 免费的附件搜索：MailStore Home 免费为邮件和附件建立索引。MailVault 也有本地全文索引，但在 PDF 和 Office 附件内搜索属于 Premium。
  • PST 和 Exchange 导入：如果你有 Outlook PST 文件，或者需要直接从 Exchange 服务器归档，MailStore 支持这些来源。MailVault 通过 IMAP 或 Microsoft Graph 连接，并能导入 MBOX 文件，但无法读取 PST 文件。
  • 企业合规：MailStore Server（付费版）提供集中归档、保留策略、审计记录和法律保留等组织合规所需的功能。MailVault 面向个人和小型企业使用，并不是为企业合规而设计的。
  • 成熟度：MailStore 自 2006 年起上市，已有大约 20 年。它处理过的边缘情况、邮件服务商和用户场景，比 MailVault 目前见过的都多。

谁更该选 MailVault？

如果符合以下情况，MailVault 就是对的选择：

  • 你用 macOS 或 Linux，并且需要本地邮件归档。
  • 你希望归档的邮件保存为标准的开放格式（而不是专有数据库）。
  • 你更喜欢可以阅读源代码的免费软件。
  • 你想要一个既是邮件客户端又是归档工具的应用 — 阅读、发送和归档都在一个地方。
  • 你是自由职业者、顾问或小企业主，需要一份个人邮件归档，但不想要企业级的复杂度。
  • 你想通过归档到本地再从服务器删除来腾出邮箱空间。

如果你需要为公司提供合规功能，请阅读 MailStore Server 替代方案。如果你的旧邮件在 PST 文件中，Windows 上的 MailStore Home 可以读取它们。对于在 Mac 上归档个人邮件，MailVault 能胜任，而且核心应用是免费的。

其他替代方案

为完整起见，这里列出 Mac 用户有时会考虑的其他选项：

  • Apple Mail + 本地文件夹：你可以把邮件拖进 Apple Mail 的本地邮箱，并通过 邮箱 > 导出邮箱 把它们保存为 mbox 格式。但没有一个步骤会在你从服务器删除之前检查本地副本，也不能导出为 Maildir。
  • Thunderbird：免费且跨平台。它的「归档」按钮可以把邮件移到你 Mac 上的本地文件夹，ImportExportTools NG 附加组件可以导出 EML、mbox 或 PDF。归档需要手动进行，而且它的本地存储默认每个文件夹使用一个 mbox 文件。参阅 MailVault 与 Thunderbird。
  • Google Takeout / 服务商导出：一次性批量导出为 .mbox 文件。单靠它本身既不能搜索，也不是增量的，而且 .mbox 是单文件格式。MailVault 可以把 Takeout 的 .mbox 文件导入你的保险库。
  • Mail Archiver X：Moth Software 出品的付费 Mac 应用，把 Apple Mail、Outlook、Thunderbird 和 IMAP 账户归档到它自己的数据库中，并可导出为 PDF 或 MBOX。它和其他工具都收录在七款 MailStore 替代方案对比中。

MailVault 填补了这个空缺：一款适用于 Mac、Windows 和 Linux、带本地归档的邮件应用，采用开放格式，核心应用免费。
