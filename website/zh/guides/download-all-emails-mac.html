如何在 Mac 上下载所有邮件

要在 Mac 上下载所有邮件，可以选择 Apple Mail 邮箱导出或专用的本地归档工具。关键在于完整性：仅收件箱通常无法涵盖整个账户，同步邮箱仍可能反映服务器上的删除操作。

方案 1：从 Apple Mail 导出邮箱

  1. 在 Apple Mail 中连接账户，等待邮件获取完成。检查收件箱、已发送和每个需要的文件夹，包括旧邮件。
  2. 在边栏中选择所需邮箱，然后选择邮箱 → 导出邮箱。
  3. 选择 Mac 或外置硬盘上的文件夹。Apple Mail 以 MBOX 格式导出邮箱数据。
  4. 保留第二份副本，并使用文件 → 导入邮箱测试导入。打开导入副本中有代表性的邮件和附件。

这些菜单名称和 MBOX 格式在 Apple 的邮箱导入与导出指南中有说明。导出的邮箱是一份独立文件；仅在 Mail 中保持账户连接，并不等于做了同样的备份。

方案 2：使用 MailVault 创建可搜索的 EML 归档

  1. 从开始使用页面下载 macOS 版本，添加邮件账户。如果可用，请使用 Google 或 Microsoft 登录。
  2. 列出文件夹检查清单：收件箱、已发送、自定义文件夹，以及包含收件箱之外邮件的所有标签。如有需要，让服务商已归档或隐藏的文件夹对当前连接可见。
  3. 通过批量操作选择所需文件夹和日期，然后选择归档。等待完成，并调查任何失败项目或跳过的文件夹。
  4. 将来源切换为保险库，检查独立的本地副本。保险库中的邮件使用 .eml 文件；只在服务器来源下可见的邮件尚未归档。

先验证归档，再依赖它

  1. 将邮件来源切换为保险库，而不是服务器或全部。搜索一封您记得的旧邮件。
  2. 断开网络，打开几封来自不同文件夹、不同年份的归档邮件，也打开它们的附件。列表中有邮件主题，并不能证明邮件正文已保存。
  3. 在设置中打开备份与恢复，使用导出备份。选择第二块硬盘上的位置。ZIP 包含保险库、账户和设置，不包含只存在于服务器上的邮件。
  4. 检查 ZIP 能否打开、是否包含 .eml 文件，以及是否包含您打算保留的文件夹。对于重要邮件，删除任何内容前，请在单独安装的应用中测试恢复一份副本。

为什么下载“所有邮件”需要文件夹检查清单

桌面连接只能归档服务商向它开放的内容。隐藏的 Gmail 标签、第二个账户、联机存档或管理员限制都可能造成遗漏。将服务商网页应用中的文件夹列表与应用列表进行比较，然后在每个重要文件夹中抽查最旧和最新的邮件。Gmail 标签重叠也可能使原始计数产生误导；同一封邮件可能出现在多个标签下。

有关特定账户的说明，请阅读将 Gmail 保存为 EML、将 Outlook 保存为 EML或导出 iCloud Mail。如果您正在从 Windows 归档工具迁移，请先阅读适用于 Mac 的 MailStore 替代工具。
