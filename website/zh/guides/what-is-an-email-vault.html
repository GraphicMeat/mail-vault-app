什么是邮件保险库？三种含义，以及如何建立你自己的保险库

8 分钟阅读

邮件保险库是一个受保护的、保存邮件以便日后查找的地方。这个词涵盖三种不同的东西：一份由你拥有、保存在你自己电脑上的本地邮件归档；一个由安全邮件服务在其服务器上加密的托管邮箱；以及一份公司为法律原因保存员工邮件而运行的合规归档。本页逐一解释它们，然后演示如何自己建立第一种。如果你已经确定想要本地保险库，正在挑选软件，那么邮件客户端与邮件保险库的对比是更好的起点。

简短回答

  • 本地邮件保险库：你自己磁盘上的一份邮件副本，服务器删除邮件时它依然保留。由你持有。
  • 托管的安全邮箱：以加密方式存储在服务商服务器上的邮件。对他人保密，但仍然是别人运营的账户。
  • 合规归档：由公司运行、包含每一封邮件的副本，为审计和法律要求保存一定年限。
  • MailVault 属于第一种：一款适用于 macOS、Windows 和 Linux 的免费桌面应用，把你的邮件以普通 .eml 文件保存在你的电脑上。

人们说「邮件保险库」时指的三种东西

搜索邮件保险库或 mail vault 会得到截然不同的工具，因为很多产品都用这个词。下面简要说明每种含义，不涉及任何具体产品。

1. 由你拥有的本地归档

一份保存在你掌控的电脑或硬盘上的邮箱副本，采用其他程序也能读取的格式。它不依赖你的服务商的服务器、你的登录信息或你的订阅。当服务器上的邮件被删除，甚至整个账户消失时，这份副本依然保留。这是大多数个人想要「保存」邮件时心里想的含义。

2. 托管的加密邮箱

一些安全邮件服务把它们的存储称为保险库。你的邮件以加密方式存放在它们的服务器上，你通过它们的应用或网站访问。目的是隐私：防止你的邮件被他人读取。它仍然是一个托管账户，所以本页后面关于保管的问题同样适用于它。如果账户被关闭或你失去访问权，那台服务器上的邮件就无法触及了。

3. 合规归档

许多组织必须在固定期限内保存业务邮件，并在审计、纠纷或法律保留时提供出来。合规归档会在每封邮件发出或收到时捕获一份副本，以用户无法悄悄删除的方式存储，并让管理员可以搜索所有人的邮件。它由雇主或 IT 部门运营。邮箱的主人离职时，通常无法带走这份副本。

MailVault 属于哪一种

MailVault 属于第一种。它是一款适用于 macOS、Windows 和 Linux 的桌面邮件应用，会在你电脑上的保险库里保留一份邮件副本。每封邮件都是 Maildir 风格文件夹里的一个普通 .eml 文件，所以不借助 MailVault，Apple Mail、Thunderbird 或文本编辑器也能打开它。你登录的是你的邮箱服务商，而不是 MailVault：Gmail 和 Microsoft 365 通过它们自己的登录页面，Outlook.com 通过 Microsoft Graph，其他服务商则通过 IMAP。你的电脑直接与邮件服务器通信，MailVault 的服务器从不接触你的邮件。源代码公开在 GitHub 上。

它不是托管服务，也不是合规归档。没有 MailVault 服务器保存你的邮件，它也没有管理控制台或法律保留功能。什么进入保险库、什么离开，由你决定。

保险库不是一个镜像服务器的邮件客户端

大多数邮件应用都是镜像。它们显示服务器上的内容，并为了速度保留本地缓存。当服务器删除一封邮件时，镜像也会在下次同步时删除它。这对于让手机、笔记本和网页邮箱保持一致是对的，对于保存邮件却是错的。

保险库副本不受服务器支配：一封邮件一旦进入保险库，上游的任何操作都不会删除它。MailVault 两项工作都做：一个普通的邮件客户端，背后有一个保险库，每一行都会显示一封邮件是仅在服务器上、在你的保险库中，还是你唯一的副本。

有一个细节很重要。MailVault 还保留一个工作缓存，默认情况下（「保留近期」下载模式），它会从你的电脑上移除超过几个月的缓存副本，而服务器保留它的副本。缓存的邮件不是保险库；已归档和已备份的邮件永远不会被任何下载模式移除。这就是为什么下面的步骤最后要做一次明确的备份或归档。

如何在 10 分钟内建立你自己的邮件保险库

10 分钟是设置所需的时间。在那之后，大邮箱的下载会在后台继续进行，需要多长时间取决于邮箱的大小和你的网络连接。下面的六个步骤只用到免费应用。

  1. 安装 MailVault。从开始使用页面下载适用于 macOS、Windows 或 Linux 的免费应用。无需注册 MailVault 账户。
  2. 选择保险库的位置。首次运行时会询问你的邮件应该存放在哪里。默认是应用自己的文件夹。你也可以选择另一个文件夹或外置硬盘，之后还可以在 设置 → 备份与恢复 → 备份设置 中更改。MailVault 会把所有内容复制到新位置，检查每个文件都已到达，然后才删除原文件。（Mac App Store 版不支持移动保险库。）
  3. 添加你的账户。在服务商自己的页面上登录 Gmail、Microsoft 365 或 Outlook.com，或者为其他任何服务商输入 IMAP 信息。你的密码或登录令牌保存在系统的凭据存储中，比如 macOS 上的钥匙串。
  4. 决定哪些内容进入保险库。在 设置 → 备份与恢复 中，「备份内容」默认为仅已归档邮件。要把仍然只在服务器上的邮件也拉进来，请选择全部邮件（从服务器下载）。这可能会占用大量磁盘空间，所以请确认空间足够。如果你只想保留部分邮件，可以跳过这一步，手动归档：选中邮件并选择归档，它会把邮件复制进你的保险库，同时也保留在服务器上。
  5. 点击「立即备份所有账户」。手动备份免费且不限次数。进度条会开始运行，备份卡片会在每一份副本都进入保险库时告诉你。之后的运行是增量的，只下载新邮件。
  6. 检查一下。把文件夹列表切换到保险库标签页。你在那里看到的内容都在你的磁盘上。标题会显示该文件夹有多少在你的保险库中。设置中的账户卡片还会列出 MailVault 已显示或缓存、但尚未进入保险库的近期邮件，并提供一个「立即保存」按钮；它覆盖的是你的下载模式所保留的那几个月，而不是仍在服务器上的更早邮件。

有两个可选步骤能让保险库更稳固。第一，在 设置 → 备份与恢复 中，在外置硬盘或 NAS 上添加第二份副本（在 Mac App Store 版中，外部备份文件夹需要单独购买）。MailVault 会在那里写入同样的 .eml 文件，应用在日常使用中从不读取它，服务器上删除的邮件也会保留在其中。没有它，所有内容都放在一台电脑的一个文件夹里，失去那台电脑就失去了保险库。第二，一旦保险库保存了你的旧邮件，你就可以把它们从服务器清除，腾出空间。单独从服务器删除是免费的。归档并删除会把每封邮件复制进保险库，并在移除服务器副本之前检查它，这是一项 Premium 功能。

保管：如果服务商关闭了账户，你的邮件会怎样

你的收件箱建立在别人运营的基础设施上，适用的条款由他们随时可以修改。丢了手机号或身份验证器，账户就会被锁。员工离职当天，雇主就会关闭邮箱。服务商会删除不活跃的账户：例如 Google 表示，它可以删除连续两年不活跃的 Google 账户及其内容（Google 的不活跃账户政策）。我们关于你的邮箱服务商为什么不是备份的文章更详细地讨论了这些情况。

当账户没了，本地保险库能给你什么、不能给你什么：

  • 它保留之前已保存的内容。已经在保险库中的每封邮件都作为文件留在你的磁盘上。打开它们不需要旧的登录信息、密码重置或服务商的许可。
  • 它不会继续接收邮件。在那之后发往已关闭地址的邮件，不会出现在任何你能看到的地方。保险库保存的是过去，而不是地址。
  • 它只和磁盘一样安全。一台笔记本上的一份副本，终究只是一份副本。在外置硬盘上保留第二份副本，并像对待任何其他备份一样对待那块硬盘。
  • 没有 MailVault 也能阅读。这些文件都是标准的 .eml，你还可以把保险库导出为一个 ZIP，附带一份按地址把邮件对应到账户的清单文件，以便在另一台电脑上重新导入。

如果你知道某个账户即将关闭，请先建立保险库，并在失去访问权之前在「保险库」标签页上检查它。如果你用的是 Mac，还在比较各种工具，Mac 上的邮件归档介绍了更广泛的选择。

常见问题

邮件保险库和备份是一回事吗？

很接近，但不完全一样。备份是出问题时用来恢复的副本。保险库是一份你同时也在使用的副本：你每天阅读和搜索它，而且在服务器删除邮件之后它依然保留这些邮件。MailVault 还可以把第二份副本写入外置硬盘，那就是你保险库的备份。

邮件保险库和加密邮件或安全邮件是一回事吗？

不是。安全邮件服务保护存放在其服务器上的邮件不被他人读取。本地邮件保险库关注的是谁持有副本。MailVault 把你的邮件保存为普通 .eml 文件，以便其他应用读取，这也意味着任何能打开这个文件夹的人都能读到它们。如果电脑可能丢失或被盗，请打开系统的磁盘加密（Mac 上的 FileVault，Windows 上的 BitLocker）。

没有 MailVault，我能打开我的保险库吗？

能。每封邮件都是 Maildir 风格文件夹中的一个标准 .eml 文件。Apple Mail、Thunderbird 和其他邮件应用都能打开它们，文本编辑器也能读取。你还可以把保险库导出为一个装有 .eml 文件的 ZIP。

如果我停止支付 Premium，我的保险库会怎样？

什么都不会被删除。阅读、搜索、归档和手动备份都是免费的，Premium 订阅过期也绝不会从你的电脑上移除邮件。你失去的是 Premium 的附加功能，比如定时备份和「归档并删除」。

下一步做什么

判断本地保险库最快的方法，是用一个账户建一个，然后看看「保险库」标签页。本地保险库功能页详细介绍了文件布局以及如何把保险库移到另一块硬盘，价格页面列出了 Premium 增加的功能。邮件进入保险库之后，MailVault 邮件分析可以告诉你是谁把它塞满的。
