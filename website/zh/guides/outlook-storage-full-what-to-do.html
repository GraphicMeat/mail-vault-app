Outlook 存储空间已满：先找出是什么满了，再解决它

8 分钟阅读 · 更新于 2026 年 10 月 8 日

当 Outlook 提示你的存储空间已满时，先弄清楚满的是哪一种存储。免费的 Outlook.com 账户（包括 Hotmail 和 Live.com 地址）有两项限额：15 GB 邮件空间，以及由 OneDrive 和 Outlook.com 附件共享的 5 GB Microsoft 云存储空间。工作或学校账户的邮箱限额由你所在的组织设定。达到免费限额后，Outlook.com 会停止收发邮件。本页帮你找出是什么满了，并选择解决办法。动手清理的步骤，请阅读如何为 Hotmail 和 Outlook.com 腾出空间。简短的概述，请参阅 Outlook.com 或 Hotmail 邮箱已满。

简短回答

  1. 在 Outlook.com 中，打开设置 > 帐户 > 存储，查看你的邮件存储空间。然后也检查一下你的 Microsoft 云存储空间。
  2. 清空已删除邮件。在你清空之前，它会一直占用你的存储空间。
  3. 还是满的？在电脑上保存一份旧邮件的副本，检查副本，然后从 Outlook.com 删除这些邮件。
  4. 只有当你需要在每台设备上在线访问全部旧邮件时，才购买更多存储空间。

变化最长可能需要 24 小时才会显示。

Outlook 存储空间满了会怎样

Microsoft 描述了三种情况。它们都会让你的邮件停摆，所以值得当天就处理。

  • 你的 Outlook.com 邮箱满了。你无法在 Outlook.com 中收发邮件。别人发给你的邮件会被退回。他们必须在你腾出空间之后重新发送。
  • 你的 Microsoft 云存储空间满了。即使你的邮箱还有空间，你也无法在 Outlook.com 中收发邮件。你的 OneDrive 文件会变为只读，新文件不会上传或同步。Microsoft 表示，6 个月后它可能会删除你的 OneDrive 及其中的文件。
  • 你的工作或学校邮箱满了。你无法收发邮件，给你发邮件的人会收到一条提示你的邮箱已满的错误消息。在此之前，当邮箱接近满时，Microsoft 会发送警告邮件和应用内消息。

第 2 步：是邮箱还是云存储空间？

在个人账户上，两项限额满的原因各不相同。你的邮箱存放你的邮件、联系人和日历。你的 Microsoft 云存储空间存放 OneDrive 文件和照片、OneDrive 回收站，以及按 Microsoft 的说法，你的 Outlook.com 附件。所以，一个装满照片的 OneDrive 可能会让你的邮件停摆，即使你从没动过收件箱。

Microsoft 自己的帮助页面对这种划分的描述并不完全一致。不要猜。在删除任何内容之前，两个数字都要看。

5 分钟检查

  1. 检查你的邮件存储空间。登录 Outlook.com，选择设置 > 帐户 > 存储。你可以看到每个文件夹占用了多少空间。
  2. 检查你的云存储空间。登录你的 Microsoft 账户，打开 Microsoft 存储页面。帮助页面什么是 Microsoft 云存储？解释了哪些内容会计入其中。
  3. 看看「已删除邮件」。在你清空它之前，或者每个项目 30 天后被移除之前，它都会占用你的存储空间。
  4. 你用过「清理」功能吗？用「清理」移除的邮件，只有在也从「已删除邮件」中删除之后，才会减少你的存储占用。
  5. 看看「垃圾邮件」。Outlook.com 会在 10 天后删除「垃圾邮件」中的项目，所以这个文件夹很少是问题所在。
  6. 如果满的是云存储空间，检查 OneDrive 回收站。它也会占用空间。

存储页面还可以永久删除某个文件夹中的所有项目，或者只删除 3、6 或 12 个月以前的项目。这很快，但不可恢复。只对你不需要或已经复制过的文件夹使用它。

你的三个选择，依次如下

1. 清理

清空「已删除邮件」，删除你不读的简报，并通过筛选 > 排序依据 > 大小找出最大的邮件。这是免费的，当你只超出限额一点点时往往就够了。完整的步骤清单，以及哪些要保留，请参阅为 Hotmail 和 Outlook.com 腾出空间。

2. 把旧邮件留在你的电脑上，然后在线删除

大多数满了的邮箱，塞满的都是你很少打开、却又不想丢掉的旧邮件。你可以把这些邮件的副本下载到你的电脑上，检查副本，然后从 Outlook.com 删除这些邮件。空间回来了，而当你需要时，邮件依然都在。

MailVault 是一款适用于 macOS、Windows 和 Linux 的免费桌面应用，可以做到这一点。它把每封邮件保存为你电脑上的一个标准 .eml 文件。使用免费应用时分两步完成：归档把邮件复制进你的保险库，然后从服务器删除把它从 Outlook.com 移除。一步完成、在移除服务器副本之前检查每一份副本的归档并删除属于 Premium。参阅归档并删除如何运作。

3. 购买更多存储空间

Microsoft 365 基本版、个人版和家庭版会把你的邮件存储空间提高到 100 GB。100 GB 的邮箱不包含在 Microsoft 365 试用中。价格因国家而异，请在 Microsoft 网站上查看。当你需要在手机和网页上随时访问每一封旧邮件时，这是正确的选择。但它不能阻止你的邮箱继续增长。我们在本地归档与付费购买更多存储空间中比较了这两种做法。

什么时候选哪个

  • 邮件现在正在被退回。先清空「已删除邮件」。这很快，而且只会移除你已经删除过的邮件。然后在本周规划一个更长期的解决办法。
  • 邮箱里塞满了旧邮件。在本地归档它们，然后从 Outlook.com 删除。这样可以腾出大量空间，而不会丢失任何东西。
  • 云存储空间满了，大部分被 OneDrive 占用。删除邮件只能帮上一点点。移动或删除 OneDrive 文件，清空 OneDrive 回收站，或者购买存储空间。删除带大附件的旧邮件也有帮助。
  • 这是工作或学校账户。先问问你的 IT 管理员。你的组织可能为你提供了存档邮箱。如果公司规定不允许，不要把工作邮件复制到个人工具中。
  • 你需要所有内容都在线上。购买存储空间，并接受账单会一直持续。

如果你选择归档，先做副本，再删除。我们的把 Outlook.com 邮件备份到 Mac 指南比较了制作这份副本的各种方法，在不丢失旧邮件的前提下腾出邮箱空间则针对任何服务商解释了同样的思路。

关于 Outlook 桌面应用的说明

  • 经典版 Windows 版 Outlook 有文件 > 工具 > 邮箱清理。它会显示邮箱及其文件夹的大小，查找早于某个日期或大于某个大小的项目，并清空「已删除邮件」。
  • .pst 或 .ost 文件存放在你的电脑上。Microsoft 的文档说明这类文件的默认大小上限为 50 GB。这项限额与你的 Outlook.com 或工作邮箱限额是分开的。

常见问题

Outlook.com 有多少免费存储空间？

免费的 Outlook.com 账户有 15 GB 邮件空间和 5 GB Microsoft 云存储空间。云存储空间由你的 OneDrive 文件和照片、你的 Outlook.com 附件以及你的 Microsoft 365 应用共享。

Outlook 存储空间满了，我还能收到邮件吗？

不能。当你的 Outlook.com 邮箱或 Microsoft 云存储空间满了，你就无法收发邮件。发给你的邮件会被退回给发件人，他们必须在你腾出空间之后重新发送。

Outlook 要多久才会显示我腾出的空间？

Microsoft 表示，变化最长可能需要 24 小时才会生效。「已删除邮件」中的邮件在你清空该文件夹之前仍然占用空间，所以先清空它。

购买 Microsoft 365 能解决 Outlook 邮箱已满的问题吗？

Microsoft 365 基本版、个人版和家庭版包含 100 GB 邮件存储空间，所以限额暂时不再是问题。在 Microsoft 365 试用期间无法使用 100 GB 邮箱。如果你的邮件持续增长，更大的限额也可能被填满。

从 Outlook.com 删除之后，我的邮件还安全吗？

只有在别处有副本时才安全。「已删除邮件」中的项目会在 30 天后被移除。在删除任何内容之前，先在你的电脑上保存一份旧邮件的副本，并确认副本能打开。
