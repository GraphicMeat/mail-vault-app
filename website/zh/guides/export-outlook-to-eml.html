如何将 Outlook 邮件导出为 EML

Outlook 的导出方式取决于您使用的版本。新版 Outlook 和网页版 Outlook 可以保存单封邮件。经典版 Outlook 使用不同的导出流程，PST 邮箱备份也不等于一个装有 EML 文件的文件夹。若要将整个邮箱保存为独立的 EML 文件，请使用兼容的桌面应用归档当前账户。

在新版 Outlook 或网页版 Outlook 中保存单封邮件

  1. 在阅读窗格或独立窗口中打开邮件。
  2. 在新版 Outlook 中，选择更多操作 → 另存为。在网页版中，打开邮件的更多操作菜单，根据界面查找另存为或下载。
  3. 如果出现提示，请选择目标位置。检查已保存文件的扩展名，再用邮件应用打开，验证邮件和附件。

如果菜单不同，请查看 Microsoft 针对不同版本的保存说明。保存一封邮件不会导出该对话的其余邮件或整个邮箱。

将 Outlook.com 或 Microsoft 365 邮箱导出为 EML

  1. 安装 MailVault，通过 Microsoft 登录添加账户。Outlook.com 账户在 MailVault 中使用 Microsoft Graph；Microsoft 365 也支持应用的 OAuth 账户连接。组织策略可能阻止访问。
  2. 检查收件箱、已发送和自定义文件夹。确认所需邮件确实可在已连接的账户中访问；联机存档和共享邮箱可能需要另外受支持的访问方式。
  3. 在批量操作中选择文件夹和日期，选择归档，等待下载完成。首次备份时只使用归档操作。
  4. 切换到保险库来源，检查旧邮件和附件。归档邮件以独立的 .eml 文件保存在本地。

先验证归档，再依赖它

  1. 将邮件来源切换为保险库，而不是服务器或全部。搜索一封您记得的旧邮件。
  2. 断开网络，打开几封来自不同文件夹、不同年份的归档邮件，也打开它们的附件。列表中有邮件主题，并不能证明邮件正文已保存。
  3. 在设置中打开备份与恢复，使用导出备份。选择第二块硬盘上的位置。ZIP 包含保险库、账户和设置，不包含只存在于服务器上的邮件。
  4. 检查 ZIP 能否打开、是否包含 .eml 文件，以及是否包含您打算保留的文件夹。对于重要邮件，删除任何内容前，请在单独安装的应用中测试恢复一份副本。

如果已经有 PST 或 MSG 文件怎么办？

PST 是 Outlook 数据容器；MSG 是另一种单封邮件格式。将其中任何一种重命名为 .eml，都不会完成格式转换。请保留原始文件，使用 Outlook 或明确支持该格式的转换工具，并在处理全部文件前验证一份转换样本。此处的 MailVault 在线账户归档说明不涉及导入或转换 PST 文件。

Microsoft 自带的邮箱备份方式请参阅备份 Outlook 邮件。Mac 上的流程请参阅将 Outlook.com 邮件备份到 Mac。如果问题在于存储空间，请继续阅读释放 Outlook.com 空间。
