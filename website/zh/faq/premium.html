免费版与 Premium

每位 MailVault 用户免费拥有的功能，以及 MailVault Premium 额外提供的部分。

MailVault 是免费的吗？

MailVault 的核心功能是免费的，包括邮件阅读、撰写、搜索、会话归并、本地归档和手动备份。Premium 功能 —— 定时自动备份、跨账户邮箱迁移和自动清理规则 —— 需要付费。各方案分别包含什么，见定价页面。源代码在 GitHub 上。

MailVault 能拦截邮件跟踪像素吗？

会的。MailVault 打开的每一封邮件都会被检查有没有跟踪像素 —— 就是营销邮件用来回报你何时打开、打开几次、来自哪个 IP、用的哪个客户端的隐藏 1x1 图片。带有跟踪像素的邮件，主题旁边会出现一只小眼睛，点开它会说明是哪家跟踪公司，并显示这个像素本来要请求的确切 URL。检测对所有人免费。MailVault Premium 还会在邮件渲染之前把这些信标从 HTML 里剥掉，于是请求根本不会发出，发件人什么也得不到。应用自带将近 500 个已知的跟踪端点；这份列表随应用分发、随版本更新，从不在运行时去服务器拉取。看看它如何工作，处理前后对比。
