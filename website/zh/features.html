你需要的每一项功能

MailVault 是一款面向 macOS 和 Linux 的邮件客户端兼备份工具。从统一收件箱、会话式对话到本地归档，这里是它能做的一切。

邮件管理 会话视图 聊天视图 安全 存储 批量操作 多账户 个性化 性能 Premium

邮件管理

阅读、撰写和整理邮件所需的一切。一键登录，精准搜索，轻松管理收件箱。

  • 撰写、回复、全部回复和转发，支持附件
  • Gmail 与 Microsoft 365 OAuth2 一键登录
  • 面向 Outlook.com 的 Microsoft Graph API —— 绕开 IMAP 回归缺陷
  • 带筛选条件的高级搜索 —— 发件人、日期范围、附件、文件夹
  • 搜索历史与常用筛选建议
  • 标记已读/未读，为邮件加星或加标记
  • 撤销发送 —— 全局默认值，也可为单次撰写单独设置（15 秒到 5 分钟）
  • 发件箱托盘 —— 本地先暂存再发送，发送途中可取消和重试
  • 已发送文件夹同步 —— SMTP 发送后，外发邮件会复制到服务器的已发送文件夹
  • 移动到文件夹 —— 在服务器的各个文件夹之间重新整理邮件
  • 邮件模板 —— 保存并复用撰写片段
  • 联系人选择器 —— 撰写、填写收件人或回复时，按账户过滤并加权排序的建议
  • 按发件人分组 —— 一键把收件箱按联系人组织，发出的回复内嵌在会话中
  • 基于 DNS 的服务器自动识别 —— SRV 记录、Mozilla autoconfig、MX 回退，以及已知服务商映射
  • 内嵌图片 —— 通过 CID 引用的徽标和照片直接在邮件正文中显示
  • 链接安全 —— 检测钓鱼链接和发件人伪装，并给出醒目提示

邮件会话与对话

基于 JWZ 算法的 Gmail 式会话视图。相关邮件归为一组，并智能折叠，让阅读干净利落。

  • 使用 JWZ 算法的 Gmail 式会话视图
  • 会话视图 —— 所有邮件按时间顺序堆叠
  • 可配置的排序方式 —— 最旧优先或最新优先
  • 引用折叠 —— 折叠被引用的回复，阅读更清爽
  • 签名折叠 —— 4 种模式：智能、始终显示、始终隐藏、折叠

聊天视图

一种独特的、像即时通讯一样的邮件体验。发出的和收到的邮件合并成一段连续对话，配上聊天气泡，就像你常用的聊天应用。

  • 独特的即时通讯式邮件视图
  • 发出的和收到的邮件合并成一段对话
  • 带发件人头像的聊天气泡
  • 正文渐进加载，每个气泡单独显示加载状态

安全与隐私

你的邮件留在你的机器上。MailVault 会校验发件人，把凭据保存在 macOS 钥匙串或 Linux Secret Service 中，并在沙盒里运行。没有云服务，没有遥测。

  • 链接安全 —— 检测显示文本与实际 URL 目标不符的钓鱼链接
  • 邮件跟踪拦截 Premium —— 找出营销邮件用来上报你何时打开的隐藏 1×1 像素，并在邮件渲染之前把它们从 HTML 里剥掉
  • 发件人伪装检测 —— 显示名冒充其他邮箱或域名时给出警告
  • 点击确认 —— 打开可疑链接前弹窗提示，并对比 URL
  • 发件人验证标记 —— SPF、DKIM 和 DMARC 校验
  • 邮件头不一致检测 —— From 与 Reply-To 伪造告警
  • 凭据保存在 macOS 钥匙串与 Linux Secret Service 中
  • macOS App Sandbox —— 在安全容器中运行
  • 无云端、无跟踪、无遥测
  • 开源 —— 每一行代码都可查看

存储与备份

你的邮件以随处可读的标准格式保存。一键归档到本地，导出为 ZIP，在任何机器上恢复。永远不会被厂商锁定。

  • 标准 Maildir + .eml（RFC 5322）格式 —— 永不被锁定
  • 一键归档到本地存储
  • ZIP 备份导出 —— 仅已归档或全部邮件，可含设置
  • 可迁移的导入 —— 在任何机器上恢复
  • 外部备份文件夹 —— 把 .eml 文件镜像到 Dropbox、iCloud Drive 或任意外部位置，macOS 上使用持久的安全作用域书签
  • 空缓存损坏防护 —— 当此前缓存有数据时，拒绝可疑的空服务器结果，保住邮箱树和邮件头
  • 可配置的缓存大小上限和保留时长
  • 后台缓存流水线 —— 静默同步
  • 后台助手 —— 即使关闭应用窗口，邮件也继续同步

批量操作

一次选中成百上千封邮件，归档、删除，或一次操作同时完成两者。挑选日期范围，查看进度，随时取消。

  • 多选并显示浮动操作栏
  • 批量归档、删除，或归档 + 删除
  • 日期范围选择 —— 按年份或自定义范围
  • 带取消按钮的进度条
  • 崩溃后可恢复的操作

多账户

你的所有邮件账户都在一处。瞬间切换——没有加载等待。可以合并成统一收件箱，也可以给每个账户配上自己的显示名和颜色。

  • 添加不限数量的邮件账户
  • 统一收件箱 —— 在一个合并视图中查看所有账户
  • Gmail、Outlook、Yahoo、iCloud、ProtonMail（Bridge）、Fastmail、Zoho，以及任何 IMAP 服务商
  • 自定义显示名和头像颜色
  • 账户排序与隐藏/显示
  • 基于 LRU 状态缓存的即时账户切换
  • 按账户记忆邮箱 —— 记住你上次所在的文件夹
  • 发件人洞察 —— 每位联系人的往来记录和频率

布局与个性化

把 MailVault 调成你的样子。选主题、调整面板、挑日期格式，把界面调到贴合你的工作方式。

  • 深色和浅色模式，邮件内容还有独立的单封主题切换
  • 三栏或两栏布局，面板宽度可调
  • 可折叠侧边栏，支持仅图标模式
  • 默认或紧凑的邮件列表样式
  • 可配置的日期格式 —— 美式、欧式、ISO、易读或自定义
  • 桌面通知和 Dock 角标
  • 所有核心操作都有键盘快捷键，且可自定义按键
  • 通知自定义 —— 按账户、按文件夹控制
  • 查看源码 —— 查看邮件的 RFC 5322 原始内容
  • 在新窗口中打开邮件

性能与技术

用 Rust 和 Tauri 构建，速度原生，资源占用极小。智能同步协议、虚拟滚动和预取让一切保持流畅。

  • 用 Rust（Tauri）构建 —— 不是 Electron
  • 通过 async-imap 原生实现 IMAP —— 没有 Node.js sidecar
  • CONDSTORE 增量同步 —— 没有变化时零 IMAP 调用
  • COMPRESS=DEFLATE —— 带宽减少 70-80%
  • 虚拟滚动 —— 17,000+ 封邮件依然流畅
  • 邮件正文预取 —— 后面 3 封邮件秒开
  • macOS 上的原生 Sparkle 自动更新 —— 已签名的 appcast，应用内下载并安装
  • 跨平台 —— macOS（Apple Silicon 与 Intel）和 Linux（.deb、AppImage、Snap、Flatpak）
  • 系统托盘 —— 在后台静默同步

  • 定时自动备份 Premium —— 为每个账户设置每日、每周或自定义计划，可指定具体时刻，并按文件夹记录检查点
  • 备份健康监测 —— 一个校验视图，按文件夹显示服务器、本地与外部三方的数量对比，并带状态指示

  • 基于朴素贝叶斯分类器的邮件清理 Premium —— 它会学着把你的邮件归入新闻通讯、推广、事务通知、私人、工作和垃圾邮件几类，并可为每一类分别设置保留/归档/删除动作
  • Time Capsule Premium —— 为任何邮箱创建时间点快照，并浏览它在过去某一天的样子
  • 邮件跟踪拦截 Premium —— 在每封邮件渲染之前剥掉其中的跟踪像素，发件人永远不会知道你打开过。发现跟踪器对所有人免费；把它去掉才是订阅带来的部分。看看处理前后
