MailVault 与 MailStore Home 并排对比

6 分钟阅读

如果你想要一个 MailStore Home 替代方案，本页针对个人邮件对这两款免费工具进行正面比较。MailStore Home 是一款 Windows 程序，把来自 Outlook、Thunderbird、Gmail、Outlook.com、IMAP 账户和 PST 文件的邮件复制到一个可搜索的归档中。MailVault 是一款适用于 macOS、Windows 和 Linux 的免费邮件应用，以普通 .eml 文件在你的电脑上保留一份邮件副本。如果你需要为整个公司建立归档，请改为阅读 MailStore Server 替代方案。更多工具的列表，请参阅 MailStore 替代方案对比。

简短回答

在 Windows 上，如果要从 PST 文件或多个本地邮件程序中导入，MailStore Home 更合适。在 Mac 或 Linux 上，或者如果你希望归档以普通 .eml 文件存在于一个你同时用来阅读和回复邮件的应用中，MailVault 更合适。

MailStore Home 的优势

  • 来源更多，尤其是在 Windows 上。它能读取 Outlook 配置文件、PST 文件、Exchange Server 邮箱、Windows Mail 和 Thunderbird 配置文件。MailVault 完全无法读取 PST 文件。
  • 免费的附件搜索。MailStore Home 免费为附件建立索引。在 MailVault 中，在 PDF 和 Office 附件内搜索属于 Premium。
  • 免费的删除规则。归档配置可以在邮件归档后、经过一段等待期后或按时长从邮箱中移除邮件，并且只移除已确认在归档中的邮件。带旗标的邮件会被保留，除非你打开同样删除它们的选项。在 MailVault 中，自动清理规则和一步完成的「归档并删除」属于 Premium。
  • 免费的便携版。它可以从 U 盘运行，无需安装。MailVault 的便携模式仅限 Windows，且属于 Premium。
  • 更多把邮件放回去的方式。它可以把归档的邮件导出到 Exchange、IMAP 邮箱或 Gmail，这也让它成为一款迁移工具。
  • 悠久的历史。MailStore 的产品自 2006 年起上市，Home 在 2026 年仍有更新。

MailVault 的优势

  • 它能在 Mac 和 Linux 上运行。MailStore Home 只列出 Windows 10 和 11。MailVault 可在 macOS 11 或更高版本（Apple Silicon 和 Intel）、Windows 和 Linux 上运行。Mac 上的 MailStore 替代方案指南介绍了 Mac 的情况。
  • 你的归档就是普通文件。每封邮件都是 Maildir 风格文件夹中的一个标准 .eml 文件，Apple Mail、Thunderbird 或文本编辑器无需 MailVault 就能打开。MailStore Home 把邮件保存在自己的归档文件中，要取出标准文件就得导出。
  • 一个应用既能阅读也能保存邮件。MailVault 是一个完整的邮件客户端：阅读、搜索、回复和发送，然后归档你想保留的内容。每一行都会显示一封邮件是在服务器上、在你的保险库中，还是两处都有。
  • Microsoft 365 是明确列出的来源。Microsoft 365 账户通过 OAuth2 登录，个人 Outlook.com、Hotmail 和 Live.com 账户通过 Microsoft Graph 连接。MailStore Home 的产品页面列出了 Outlook.com 和 Exchange Server 2003 至 2019，但没有 Microsoft 365。
  • 源代码公开在 GitHub 上。代码就在 GitHub 上，你可以检查它如何处理你的邮件。

归档存放在哪里

在 MailStore Home 中，归档位于一个数据文件夹中，你可以用其内置的备份功能备份，或者在程序关闭时复制该文件夹。MailStore 警告不要把这个文件夹放在 Dropbox 等同步服务中，因为在 MailStore Home 使用这些文件时，同步服务可能会改动它们。

在 MailVault 中，归档是一个装有 .eml 文件的文件夹。设置、备份与恢复 会显示它的位置，在文件管理器中打开它，还可以把它移到另一块硬盘。你可以在外置硬盘或 NAS 共享上添加第二份副本，在每次备份运行时写入。

从 MailStore Home 迁移到 MailVault

MailVault 无法直接打开 MailStore 的归档文件。最简单的路线是把 MailVault 连接到相同的账户，归档仍在服务器上的邮件。对于现在只存在于 MailStore Home 中的邮件，先从 MailStore Home 导出到一个 IMAP 或 Gmail 邮箱，让 MailVault 归档它们，然后再从服务器上删除。请先检查你的邮箱配额，因为导出会让这些邮件暂时回到服务器上。

谁该选哪个

  • 选择 MailStore Home，如果你在 Windows 上，有 PST 文件或 Outlook 和 Thunderbird 配置文件需要导入，想要免费的附件搜索和免费的删除规则，并且满足于一个只做归档的工具。
  • 选择 MailVault，如果你在 Mac 或 Linux 上，希望归档是在任何地方都能打开的普通文件，使用 Gmail、Microsoft 365、Outlook.com 或 IMAP，并且想要一个能阅读、搜索和保存邮件的应用。
  • 两者都不选，如果你的公司需要保留策略、法律保留或审计日志。那是服务器的领域。

常见问题

MailStore Home 有 Mac 版吗？

没有。MailStore 列出的 MailStore Home 系统要求是 Windows 10 和 Windows 11。在 Mac 上你需要别的工具，比如 MailVault 或其他 Mac 选择之一。

MailVault 能导入 MailStore Home 的归档吗？

不能直接导入。MailVault 无法读取 MailStore 的归档文件。把邮件从 MailStore Home 导出到一个 IMAP 或 Gmail 邮箱，再用 MailVault 归档，或者把 MailVault 连接到原来的账户。

MailVault 能打开 PST 文件吗？

不能。MailVault 可以导入 MBOX 文件，并连接 Gmail、Microsoft 365、Outlook.com 和 IMAP 账户。如果你的旧邮件在 PST 文件中，Windows 上的 MailStore Home 可以归档它们。

MailStore Home 真的免费吗？

是的，据 MailStore 表示，用于家庭私人用途是免费的。对于商业用途，它建议企业使用付费的 MailStore Server。

下一步做什么

如果你在 Windows 上并且有 PST 文件，先试试 MailStore Home。如果你在 Mac 或 Linux 上，或者你想要普通文件，请免费下载 MailVault，连接一个账户，归档较早的某一年，看看它如何运作。归档并删除页面说明了哪些免费、哪些属于 Premium。

还可以把 MailVault 与 Thunderbird 和 Apple Mail 做比较，或者了解本地搜索。
