Windows 为什么可能显示警告

你下载的每个安装程序都会经过 Microsoft Defender SmartScreen 检查。它看两件事：谁签名了这个文件，以及已有多少人下载并运行过它。

MailVault 的安装程序通过 Microsoft 自己的签名服务 Azure Artifact Signing 签名。Microsoft 会先核实公司身份，才允许其签名任何文件；Windows 在运行安装程序前也会确认签名完好无损。

需要时间的是信誉。Windows 版 MailVault 刚刚推出，而且每个版本都是一个新文件，所以 SmartScreen 可能还不认识它，并显示“Windows 已保护你的电脑”。这个提示表示文件还不够常见，并不表示发现了任何有害内容。

  1. 如果浏览器询问

    Edge 可能会提示该文件“不常下载”。打开下载菜单，选择文件旁的三个点，然后选择“保留”。

  2. 如果出现 SmartScreen

    点击“更多信息”。确认发布者显示为 MailVault 的开发公司 MODERNIOS APLIKACIJOS，然后点击“仍要运行”。

  3. 如果发布者不同

    如果显示“未知发布者”或其他任何名称，请不要运行该文件。删除它，然后从本页重新下载。

自己验证

你不必只听我们说。右键点击安装程序，选择“属性”，打开“数字签名”选项卡：其中列出 MODERNIOS APLIKACIJOS，在“详细信息”中可以看到此数字签名正常。

GitHub 上的每个版本还会在每个文件旁列出 SHA-256 校验和。在 PowerShell 中对安装程序运行 Get-FileHash，比较两个值即可。
