Mac 邮件备份软件：以恢复能力为选择标准

适合你的 Mac 的邮件备份软件，应让恢复过程可预期。只有知道复制了什么、存到哪里、如何再次打开，“备份完成”才有意义。选择时要进行恢复测试，尤其是在清理已满的邮箱或关闭账户之前。

本指南由 MailVault 的开发者撰写。我们的应用适合需要可搜索邮件归档和自主可控备份的人。一次性导出或整台 Mac 的备份，也可以是合理配置的一部分。

三种方法，三种用途

导出邮箱适合一次性复制或迁移。Apple Mail 可将选中的邮箱导出为 MBOX 包；请参阅 Apple 的导出说明。检查包含哪些文件夹和邮件，并在需要更新副本时再次导出。

Mac 备份保护已经存放在电脑上的文件。Apple 的Time Machine 指南说明了 Mac 的备份与恢复方法。不要假设系统备份会包含邮件应用从未完整下载的邮件。请检查归档位置是否在备份范围内。

邮件归档加单独备份既能让你日常使用邮件，也能增加一份用于恢复的副本。MailVault 将归档邮件存为 .eml 文件，并可备份到你选择的位置。归档及其备份不应因同一个故障而同时丢失。 这些文件结构说明适用于默认的 Maildir 格式。设置 → 存储还提供 JMAP 存储，将原始邮件字节与 JSON 记录一起保留，并对相同邮件去重。

Mac App Store 版本无法将日常使用的保管库移至其他文件夹，但仍可选择单独的备份位置。

在 MailVault 中应检查什么

运行任务前，先检查备份范围。仅备份已归档邮件，只会覆盖已经保存在保管库中的内容。若要包含仍然只在服务器上的邮件，请选择更大的范围，并在下载这些邮件期间保持账户连接。

为了应对磁盘故障，请在另一块驱动器上选择第二个存储位置。同一磁盘上的另一个文件夹，无法防止该磁盘丢失带来的损失。如果备份驱动器平时断开连接，请在任务开始前接上，并在收起前检查结果。

手动备份还是定时备份？

MailVault 的手动备份免费且不限次数，适合一次性归档，或已经有定期备份习惯的人。定时备份属于 Premium，适合每天都有变化的邮箱。定时安排减少了重复操作，但任务仍然需要访问源数据和目标位置。

做一次小规模恢复演练

  1. 备份一个包含旧邮件、近期邮件和附件的文件夹。
  2. 确认任务已完成，并检查备份目标位置。
  3. 从备份中复制一封样本邮件，在兼容的邮件应用中打开。
  4. 打开其附件，并将发件人、日期和正文与原件比较。
  5. 记下备份的存放位置，以及从另一台 Mac 访问它的方法。

请在删除任何服务器邮件之前完成这些步骤。Premium 的归档并删除组合操作为这项流程增加了检查，但整体恢复计划仍然重要。先做一次免费的手动备份，证明结果可以使用，再决定自动化是否值得付费。
