MailVault pour Windows

Votre téléchargement commence.

Le programme d’installation arrive. Une fois terminé, ouvrez-le depuis votre dossier Téléchargements. Windows peut d’abord vous demander de confirmer ; cette page explique pourquoi, et comment vérifier que le fichier vient bien de nous.

Télécharger pour Windows

Si le téléchargement ne démarre pas, utilisez le bouton ci-dessus.

Pourquoi Windows peut afficher un avertissement

Chaque programme d’installation téléchargé est vérifié par Microsoft Defender SmartScreen. Il regarde deux choses : qui a signé le fichier, et combien de personnes l’ont déjà téléchargé et exécuté.

Le programme d’installation de MailVault est signé via Azure Artifact Signing, le service de signature de Microsoft. Microsoft vérifie l’identité de la société avant de la laisser signer quoi que ce soit, et Windows confirme que la signature est intacte avant de lancer l’installation.

La réputation, elle, demande du temps. MailVault pour Windows est récent et chaque version est un nouveau fichier : SmartScreen ne le connaît peut-être pas encore et peut afficher « Windows a protégé votre ordinateur ». Ce message signifie que le fichier est peu répandu. Il ne signifie pas qu’un élément dangereux a été trouvé.

  1. Si votre navigateur vous le demande

    Edge peut indiquer que le fichier « n’est pas fréquemment téléchargé ». Ouvrez le menu des téléchargements, choisissez les trois points à côté du fichier, puis Conserver.

  2. Si SmartScreen s’affiche

    Cliquez sur Informations complémentaires. Vérifiez que l’éditeur indiqué est MODERNIOS APLIKACIJOS, la société qui développe MailVault, puis cliquez sur Exécuter quand même.

  3. Si l’éditeur est différent

    N’exécutez pas le fichier s’il indique Éditeur inconnu ou tout autre nom. Supprimez-le et téléchargez-le à nouveau depuis cette page.

Vérifiez par vous-même

Inutile de nous croire sur parole. Faites un clic droit sur le programme d’installation, choisissez Propriétés, puis ouvrez l’onglet Signatures numériques : MODERNIOS APLIKACIJOS y figure, et Détails indique que la signature est correcte.

Chaque version sur GitHub indique aussi une somme de contrôle SHA-256 à côté de chaque fichier. Lancez Get-FileHash sur le programme d’installation dans PowerShell et comparez les deux valeurs.
