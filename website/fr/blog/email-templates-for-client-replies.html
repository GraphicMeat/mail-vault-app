Modèles d’e-mails pour répondre aux clients : trois exemples réutilisables

Sur cette page
  • Trois modèles de réponses aux clients à adapter
  • Enregistrer le texte une fois dans MailVault
  • Insérer le texte là où la réponse en a besoin
  • Une courte vérification avant chaque envoi
  • Garder une bibliothèque assez petite pour être utilisée

Par MailVault · 4 min de lecture

Un client vous demande ce qu’il vous faut pour établir un devis. Vous connaissez la réponse : vous avez écrit presque le même e-mail hier. Vous le retrouvez dans les messages envoyés, copiez le paragraphe, changez le nom et espérez ne pas avoir oublié la date limite du projet précédent.

Un modèle d’e-mail conserve la partie récurrente d’une réponse pour vous laisser du temps pour les détails qui ont changé. Dans MailVault, enregistrez un modèle nommé dans Paramètres → Modèles, insérez-le dans un brouillon depuis le menu Modèles, puis modifiez-le avant l’envoi. Les modèles font partie de l’application gratuite.

Le but est de ne plus reconstituer de mémoire des formulations utiles. Commencez par trois réponses que vous envoyez déjà régulièrement, plutôt que par une bibliothèque de messages que vous n’utiliserez peut-être jamais.

Trois exemples · Enregistrer un modèle · Insérer et modifier · Vérifier avant l’envoi

Trois modèles de réponses aux clients à adapter

Le texte entre crochets ci-dessous vous rappelle les éléments à remplacer à la main. MailVault insère le texte enregistré ; ces exemples ne remplacent pas automatiquement les noms, les projets ou les dates.

1. Demander les précisions nécessaires au devis

Bonjour [nom],

Merci de m’avoir contacté au sujet de [projet]. Pour établir un devis adapté, pourriez-vous m’envoyer le périmètre du projet, les éventuels documents de référence et le délai souhaité ?

Si vous avez un budget fixe ou besoin d’un livrable particulier, merci de le préciser également. Une fois ces informations reçues, je pourrai confirmer la prochaine étape.

Enregistrez ce modèle sous le nom Devis — demander des précisions. Avant l’envoi, retirez les questions auxquelles le client a déjà répondu. Répéter une question du message précédent donne à une réponse réutilisable une impression de négligence.

2. Confirmer la réception des fichiers sans promettre un délai non vérifié

Bonjour [nom],

Merci, j’ai bien reçu [fichiers ou documents]. Je les examinerai au regard de [périmètre convenu] et vous signalerai tout élément manquant.

Je vous ferai un point d’ici [date et fuseau horaire].

Enregistrez ce modèle sous le nom Fichiers — reçus. Vérifiez que les pièces jointes ou les liens partagés s’ouvrent bien, puis choisissez une date que vous pouvez respecter. Si vous n’avez pas tout reçu, indiquez plutôt précisément ce qui manque.

3. Relancer sur une décision précise

Bonjour [nom],

Je reviens vers vous au sujet de [proposition ou question] du [date]. Pourriez-vous confirmer [décision attendue] ?

Si le calendrier a changé, dites-le-moi pour que je puisse adapter la prochaine étape.

Enregistrez ce modèle sous le nom Relance — décision. Précisez la décision attendue : valider le bon à tirer, choisir une option ou fournir un fichier manquant. Il est plus facile de répondre à une question précise qu’à « Des nouvelles ? ».

Enregistrer le texte une fois dans MailVault

  1. Ouvrez Paramètres → Modèles et choisissez Ajouter un modèle.
  2. Saisissez un nom court qui décrit dans quel cas vous l’utiliseriez.
  3. Collez le texte réutilisable dans le corps du modèle. Mettez les informations variables entre crochets bien visibles.
  4. Choisissez Enregistrer. Utilisez la commande de modification à côté du modèle lorsque son texte doit être actualisé.

Le modèle enregistré contient un nom et le texte du message. Prévoyez de choisir le destinataire, l’objet et les pièces jointes dans le message lui-même. Évitez de conserver les informations privées d’un client particulier dans un modèle destiné à tous.

Insérer le texte là où la réponse en a besoin

Ouvrez un nouveau message ou une réponse, placez le curseur à l’endroit voulu et choisissez un modèle dans Modèles. MailVault insère le texte dans le brouillon. Vous pouvez modifier le texte inséré sans réécrire le modèle enregistré.

Par exemple, si le client a déjà précisé le délai, retirez cette question du modèle de devis et demandez uniquement le périmètre et les références. Ajoutez une phrase qui répond à son message. Le modèle fournit un point de départ ; votre réponse finale doit toujours convenir à la conversation.

Une courte vérification avant chaque envoi

  • Remplacez tous les éléments entre crochets. Recherchez les noms, dates et projets laissés en attente.
  • Vérifiez le compte et les destinataires. Confirmez l’adresse d’expédition et les personnes qui recevront une réponse à tous.
  • Vérifiez vos engagements. Un délai ou un prix repris d’un ancien texte doit toujours être validé par vos soins.
  • Joignez le fichier mentionné. Le texte du modèle ne le joint pas à votre place.
  • Relisez le brouillon entier. Supprimez les salutations, signatures et passages répétés que vous avez déjà écrits au-dessus du point d’insertion.

Garder une bibliothèque assez petite pour être utilisée

Après une semaine, gardez les modèles que vous avez réellement insérés et révisez les phrases que vous modifiez sans cesse. Ne séparez un modèle en deux que si deux situations demandent régulièrement des formulations différentes. Un petit ensemble de noms clairs facilite le choix lorsqu’un client attend.

Les modèles n’ont pas besoin d’IA pour insérer du texte enregistré. Si vous souhaitez reformuler un brouillon particulier, l’aide à la rédaction par IA est une fonction distincte. Si votre difficulté principale est de vous rappeler quels messages demandent encore votre attention, commencez par une revue quotidienne des réponses à envoyer.

Enregistrez la prochaine réponse que vous écririez sinon deux fois.

Essayez cette méthode dans MailVault. Disponible sur macOS, Windows et Linux.
