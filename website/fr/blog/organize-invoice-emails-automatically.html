Comment organiser automatiquement les e-mails de factures

Sur cette page
  • 1. Donner aux factures un tag cohérent
  • 2. Créer une règle fondée sur les informations visibles par l’application
  • 3. Prévisualiser avant d’activer
  • 4. Rassembler les anciennes factures au même endroit
  • Ce que cette méthode permet d’établir, et ses limites

Par MailVault · 4 min de lecture

Vous cherchez la facture d’un achat, mais le nom du fournisseur ne correspond pas à celui qui figure sur l’e-mail. Le reçu est arrivé sur un second compte. Un avis de livraison apparaît avant le document recherché. Vous finissez par le retrouver à force de chercher, mais le mois prochain, tout recommencera.

Pour organiser automatiquement les e-mails de factures, choisissez un tag, créez une règle précise, prévisualisez ses résultats, puis utilisez ce tag pour les rassembler. Dans MailVault, l’étiquetage auto peut appliquer le tag dès l’arrivée des e-mails correspondants. Vous pouvez examiner les anciens messages séparément et créer une vue enregistrée pour cet ensemble.

Le changement utile est simple : décidez comment vous voulez retrouver ces messages plus tard, puis faites en sorte que les nouveaux e-mails arrivent déjà étiquetés.

Choisir un tag · Créer la règle · Vérifier les résultats · Rassembler les résultats

1. Donner aux factures un tag cohérent

Commencez par Factures ou Reçus. Si vous avez besoin des deux, définissez leur sens : une facture demande un paiement ; un reçu atteste un achat ou un paiement. Un tag nommé Factures ne doit pas signifier implicitement Payé.

Appliquez d’abord des tags manuels à quelques messages connus. Choisissez une facture fournisseur, un reçu d’achat et une notification sans rapport. Ces exemples vous donnent des éléments concrets à comparer aux résultats de la règle.

2. Créer une règle fondée sur les informations visibles par l’application

Ouvrez Paramètres → Étiquetage auto → Nouvelle règle. Nommez la règle, choisissez ou créez le tag à appliquer et rédigez une consigne comme celle-ci :

Étiquetez les factures et reçus d’achats. Excluez les avis d’expédition, les confirmations de livraison et les offres promotionnelles.

Sous Affiner (facultatif), ajoutez une adresse d’expéditeur exacte, un domaine d’expéditeur ou une condition sur l’objet lorsque vous les connaissez. Pour un fournisseur régulier, une condition sur l’expéditeur et un objet contenant « facture » constituent un bon point de départ. N’exigez une pièce jointe que si chaque facture recherchée en possède vraiment une : certains fournisseurs donnent accès au document par un lien.

L’étiquetage auto voit l’expéditeur, l’objet, le dossier et la présence éventuelle d’une pièce jointe. Il ne lit ni le corps du message ni le PDF joint. Une consigne portant sur le montant de la facture, l’échéance dans un PDF ou le fait qu’une facture ait été payée demande à la règle de déduire des informations dont elle ne dispose pas.

Pendant les essais, conservez Dans la boîte de réception → Garder en boîte de réception. La règle peut étiqueter les messages sans changer votre façon habituelle de les lire.

3. Prévisualiser avant d’activer

Choisissez le compte à examiner et cliquez sur Aperçu. Vous voyez les correspondances possibles sans appliquer de tags. Cherchez deux types d’erreurs : un avis de livraison inclus comme facture et une vraie facture manquée parce que son objet est vague.

Modifiez une condition à la fois, puis relancez l’aperçu. Si vous voyez Impossible de décider, vérifiez la configuration de l’IA avant de considérer la règle comme prête. Les règles en langage courant ont besoin d’un modèle opérationnel ; les conditions exactes réduisent les messages candidats avant leur évaluation par ce modèle. Le guide de configuration de l’IA présente les options disponibles.

Par défaut, les règles sont traitées sur l’appareil. Choisir un fournisseur distant change le lieu de traitement des métadonnées des messages candidats ; vérifiez ce choix dans les réglages de la règle. Vous pouvez toujours étiqueter vous-même un message ambigu.

Lorsque les correspondances semblent utiles, enregistrez et activez la règle. Un aperçu est un échantillon : vérifiez aussi les premières nouvelles factures reçues.

4. Rassembler les anciennes factures au même endroit

Utilisez Rétro-application pour appliquer la règle enregistrée aux anciens e-mails du compte sélectionné. Examinez les résultats avant de transmettre l’ensemble. MailVault permet d’annuler ce traitement de l’historique si la règle était trop large.

Pour une revue mensuelle, créez une vue enregistrée filtrée par votre tag de factures et la période voulue. Une vue peut rassembler les correspondances de plusieurs comptes sans déplacer les messages d’origine. Trois vues enregistrées sont incluses gratuitement, vues prédéfinies comprises ; Premium en permet davantage.

Ce que cette méthode permet d’établir, et ses limites

L’étiquetage auto et les tags manuels sont gratuits. Un tag facilite le regroupement des messages ; il ne vérifie pas un fournisseur, n’approuve pas un paiement et n’extrait pas de données comptables. Ouvrez le message et le document d’origine lorsque les détails comptent. L’étiquetage ne crée pas non plus de sauvegarde indépendante.

Si une ancienne facture manque, vérifiez les conditions d’objet et d’expéditeur de la règle, le compte sélectionné et les e-mails disponibles localement. Pour une recherche ponctuelle, consultez le guide consacré à la recherche dans une grande archive d’e-mails. Pour conserver les documents, suivez le guide d’archivage des e-mails pour les indépendants.

Commencez par un fournisseur et quelques messages. Une fois les résultats fiables, élargissez la règle. L’objectif est d’obtenir un ensemble auquel vous faites assez confiance pour l’ouvrir directement le mois prochain.
