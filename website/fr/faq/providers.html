Connectez Gmail, Microsoft 365, Outlook.com, Proton Mail et les serveurs JMAP comme Fastmail, et envoyez depuis un alias.

MailVault fonctionne-t-il avec Gmail et Outlook ?

Oui. MailVault fonctionne avec Gmail, Outlook, les serveurs JMAP comme Fastmail et tout service de messagerie compatible IMAP. Pour Gmail, connectez-vous directement avec votre compte Google via OAuth2 — aucun paramétrage IMAP manuel n'est nécessaire. Les comptes Microsoft 365 Business et Enterprise peuvent se connecter directement avec votre compte Microsoft via OAuth2, y compris avec l'authentification à deux facteurs. Les comptes personnels Outlook.com, Hotmail et Live.com se connectent via l'API Microsoft Graph.

Comment connecter mon compte Outlook.com ?

MailVault connecte les comptes personnels Outlook.com, Hotmail et Live.com via l'API Microsoft Graph. Ajoutez le compte, choisissez Se connecter avec Microsoft et terminez la connexion dans votre navigateur. MailVault reconnaît un compte Microsoft personnel et utilise Graph de lui-même ; il n'y a donc aucun réglage IMAP à saisir.

Il n'utilise pas IMAP pour ces comptes à cause d'un problème IMAP chez Microsoft avec la connexion OAuth2, apparu fin 2024. La lecture, la suppression, le marquage comme lu ou non lu, le déplacement et la sauvegarde du courrier fonctionnent comme sur les autres comptes.

Pas encore disponible sur les comptes Graph :

  • Reporter
  • Restaurer un fichier MBOX sur le serveur
  • Récupérer sur le serveur pour les e-mails supprimés. Récupérer en local fonctionne, pour le courrier déjà présent sur cet ordinateur
  • Le nombre de messages de la boîte de réception que la fenêtre d'ajout de compte indique après le test de connexion

Les comptes Microsoft 365 Business et Enterprise utilisent IMAP avec OAuth2 et ne sont pas concernés par ces limites. Cette connexion suit la même approche que Mozilla Thunderbird, avec l'authentification PKCE et XOAUTH2.

Comment utiliser MailVault avec Proton Mail ?

Proton Mail chiffre votre courrier de bout en bout : il n'expose donc pas IMAP directement. Le connecter à MailVault (ou à n'importe quel client de messagerie tiers) demande Proton Mail Bridge — une application de bureau signée Proton, qui tourne sur votre propre ordinateur et expose votre boîte chiffrée en IMAP/SMTP standard sur 127.0.0.1. Bridge exige une formule Proton Mail payante ; il n'est pas disponible sur l'offre gratuite de Proton.

Étapes de configuration :

  1. Installez Proton Mail Bridge depuis le site de Proton
  2. Connectez-vous à Bridge avec votre compte Proton
  3. Bridge affiche des identifiants IMAP/SMTP par compte — le mot de passe indiqué est un mot de passe d'application généré par Bridge, et non le mot de passe habituel de votre compte Proton
  4. Dans MailVault, choisissez Proton Mail Bridge dans la liste des fournisseurs (ou IMAP personnalisé s'il n'y figure pas) et saisissez :
    • Serveur : 127.0.0.1
    • Port IMAP : 1143, sécurité : STARTTLS
    • Port SMTP : 1025
    • Nom d'utilisateur : votre adresse e-mail Proton
    • Mot de passe : le mot de passe généré par Bridge à l'étape 3

Proton Mail Bridge doit tourner en arrière-plan chaque fois que MailVault se synchronise — si Bridge est fermé, MailVault ne peut pas atteindre la boîte mail. Le courrier que vous avez déjà archivé reste entièrement lisible et consultable dans MailVault même quand Bridge est fermé, puisque MailVault fonctionne d'abord en local et lit son propre stock de fichiers .eml plutôt que Bridge en direct. Ces indications sur la structure des fichiers concernent le format Maildir utilisé par défaut. Paramètres → Stockage propose aussi le stockage JMAP, qui conserve les octets des messages d’origine avec des enregistrements JSON et déduplique les messages identiques.

Bridge protège son serveur IMAP/SMTP local avec un certificat TLS auto-signé. MailVault s'en occupe automatiquement pour les connexions locales (127.0.0.1) : aucune installation manuelle de certificat n'est nécessaire.

Puis-je envoyer depuis une autre adresse que celle avec laquelle je me connecte ?

Oui. Ajoutez l'adresse comme alias du compte, comme expliqué dans Comment envoyer depuis un alias ?, puis choisissez-la dans la ligne De quand vous écrivez, ou faites-en l'adresse par défaut. C'est courant chez Fastmail et chez tout fournisseur où l'adresse avec laquelle vous vous connectez n'est pas celle que vous communiquez.

Seule l'adresse From des e-mails sortants change. Votre identifiant et votre mot de passe restent inchangés, MailVault se connecte toujours avec le compte que vous avez configuré et aucun en-tête Reply-To n'est ajouté — les réponses arrivent à l'adresse utilisée pour l'envoi.

Comment envoyer depuis un alias ?

Ouvrez Paramètres → Comptes, choisissez le compte et allez à sa section Alias. Elle liste toutes les adresses depuis lesquelles le compte envoie : d'abord son adresse de connexion, puis chaque alias. Le lien Ajouter une adresse dans la ligne De d'un nouveau message ouvre la même section.

Ajouter et configurer un alias :

  • Comptes Google : si vous vous êtes connecté avec Google, MailVault récupère les adresses depuis lesquelles Gmail vous permet d'envoyer et les liste pour vous.
  • Comptes JMAP : les adresses d'envoi proviennent des identités configurées sur votre serveur. Ajoutez-les ou modifiez-les à cet endroit.
  • Autres fournisseurs : MailVault suggère les adresses qu'il a vues dans votre propre courrier, celles depuis lesquelles vous avez envoyé et celles où arrive votre courrier. Vous pouvez aussi ajouter n'importe quelle adresse à la main.
  • Nom : donnez à chaque alias le nom que les destinataires doivent voir. Le courrier envoyé depuis l'alias part sous ce nom.
  • Par défaut : choisissez l'adresse avec laquelle commencent les nouveaux messages.
  • Vérifier : envoie un message de test depuis l'alias, pour voir si votre fournisseur l'accepte avant de compter dessus.

Votre fournisseur doit autoriser l'adresse :

  • Fastmail : ajoutez d'abord l'adresse comme alias ou identité dans Fastmail.
  • Gmail : ajoutez-la dans Gmail sous Paramètres → Comptes et importation → Envoyer des e-mails en tant que.
  • Microsoft 365 et Outlook.com : les alias s'ajoutent dans le compte Microsoft, par vous ou, pour un compte professionnel ou scolaire, par votre administrateur.

Seuls l'adresse et le nom de l'expéditeur changent. MailVault se connecte toujours avec le compte que vous avez configuré, et aucun en-tête Reply-To n'est ajouté, donc les réponses reviennent à l'alias.

Comment connecter Fastmail ou un autre compte JMAP ?

Choisissez Fastmail lors de l'ajout d'un compte et collez un jeton d'API avec les accès Mail et Submission depuis les paramètres Fastmail. Pour un autre serveur, choisissez JMAP et utilisez son mot de passe ou son jeton d'API. MailVault découvre l'URL de session lorsque le domaine la publie ; sinon, saisissez l'URL de session HTTPS complète. Confirmez tout serveur découvert qui vous est inconnu avant l'envoi des identifiants. Les nouveaux e-mails arrivent par push, avec interrogation périodique en secours, et les adresses d'envoi proviennent des identités du serveur. Fastmail propose également une option IMAP avec mot de passe d'application.

Comment ajouter une adresse iCloud ou un compte Apple ?

Choisissez iCloud Mail en ajoutant un compte, saisissez votre adresse iCloud complète et collez un mot de passe pour app. iCloud Mail n'accepte pas le mot de passe habituel de votre compte Apple depuis d'autres apps. Créez le mot de passe pour app sur account.apple.com, sous Connexion et sécurité, puis Mots de passe pour app ; l'authentification à deux facteurs doit être activée. Le bouton d'information à côté du champ du mot de passe dans MailVault explique les mêmes étapes. Si la connexion échoue par la suite, un changement du mot de passe de votre compte Apple l'a révoqué : créez-en un nouveau. Consultez le guide pas à pas.
