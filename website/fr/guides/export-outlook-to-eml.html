Guides de sauvegarde des e-mails · 15 octobre 2026

Exporter les e-mails Outlook en EML

L’export Outlook dépend de la version utilisée. Le nouvel Outlook et Outlook sur le web permettent d’enregistrer des messages individuels. Outlook classique utilise une autre procédure d’export, et une sauvegarde de boîte aux lettres en PST n’est pas un dossier de fichiers EML. Pour toute une boîte en fichiers EML individuels, archivez le compte connecté avec une application de bureau compatible.

Enregistrer un message individuel dans le nouvel Outlook ou Outlook sur le web

  1. Ouvrez le message dans le volet de lecture ou dans sa propre fenêtre.
  2. Dans le nouvel Outlook, choisissez Autres actions → Enregistrer sous. Sur le web, ouvrez le menu Autres actions du message et cherchez Enregistrer sous ou Télécharger, selon l’interface.
  3. Choisissez une destination si nécessaire. Vérifiez l’extension du fichier enregistré, puis ouvrez-le dans une application de messagerie pour contrôler le message et les pièces jointes.

Consultez les instructions d’enregistrement de Microsoft selon la version si vos menus diffèrent. Enregistrer un message n’exporte pas le reste de sa conversation ou de sa boîte aux lettres.

Exporter une boîte Outlook.com ou Microsoft 365 en EML

  1. Installez MailVault et ajoutez le compte via la connexion Microsoft. Les comptes Outlook.com utilisent Microsoft Graph dans MailVault ; Microsoft 365 prend aussi en charge la connexion de compte OAuth de l’application. Les politiques de l’organisation peuvent empêcher l’accès.
  2. Examinez la boîte de réception, les messages envoyés et les dossiers personnels. Confirmez que les e-mails nécessaires sont bien disponibles dans le compte connecté ; les archives en ligne et boîtes partagées peuvent nécessiter un accès distinct pris en charge.
  3. Sélectionnez les dossiers et dates dans les opérations en masse, choisissez Archiver et laissez le téléchargement se terminer. Utilisez uniquement Archiver pour votre première sauvegarde.
  4. Passez à la source Coffre et vérifiez les anciens messages et leurs pièces jointes. Les messages archivés sont enregistrés localement en fichiers .eml individuels.

Vérifiez l’archive avant de vous y fier

  1. Passez la source des messages à Coffre, plutôt que Serveur ou Tout. Recherchez un ancien message que vous reconnaissez.
  2. Déconnectez-vous du réseau et ouvrez quelques messages archivés de différents dossiers et années. Ouvrez aussi leurs pièces jointes. Un objet dans une liste ne prouve pas que le corps du message est enregistré.
  3. Dans les réglages, ouvrez Sauvegarde et restauration et utilisez Exporter la sauvegarde. Choisissez un emplacement sur un second disque. Le ZIP contient le coffre, les comptes et les réglages ; il exclut les messages qui existent uniquement sur le serveur.
  4. Vérifiez que le ZIP s’ouvre, contient des fichiers .eml et inclut les dossiers que vous vouliez conserver. Pour les e-mails importants, testez la restauration d’une copie dans une installation distincte avant toute suppression.

Courte démo : vérifier que les e-mails sont disponibles dans le coffre

Démo avec des e-mails fictifs, montée à partir des enregistrements de démonstration macOS existants. La connexion au compte et certains préparatifs ont lieu hors champ ; il ne s’agit pas d’une connexion en direct à un fournisseur.

Lire la description de la démo

L’enregistrement montre une recherche dans une archive locale préparée. Ouvrez les résultats enregistrés et testez les pièces jointes hors ligne avant de vous fier à votre sauvegarde. Tous les e-mails de la démo sont fictifs.

Et si vous avez déjà un fichier PST ou MSG ?

PST est un conteneur de données Outlook ; MSG est un autre format de message individuel. Renommer l’un ou l’autre en .eml ne le convertit pas. Gardez le fichier original, utilisez Outlook ou un convertisseur qui prend explicitement en charge le format, et validez une conversion d’essai avant de traiter l’ensemble. Les instructions d’archivage d’un compte connecté avec MailVault présentées ici n’importent ni ne convertissent les fichiers PST. Ces indications sur la structure des fichiers concernent le format Maildir utilisé par défaut. Paramètres → Stockage propose aussi le stockage JMAP, qui conserve les octets des messages d’origine avec des enregistrements JSON et déduplique les messages identiques.

Pour la sauvegarde native de boîte aux lettres de Microsoft, consultez Sauvegarder vos e-mails Outlook. Pour la procédure sur Mac, consultez sauvegarder les e-mails Outlook.com sur Mac. Si le problème est le stockage, poursuivez avec libérer de l’espace dans Outlook.com.

Téléchargez MailVault gratuitement pour créer votre première archive locale. L’archivage manuel est gratuit ; l’archivage automatique, les sauvegardes planifiées et Archiver et supprimer nécessitent Premium.
