Guides de sauvegarde des e-mails · 15 octobre 2026

Sauvegarder Gmail en fichiers EML

Sur cette page

  • Sauvegarder toute une boîte Gmail en fichiers EML individuels

  • Sauvegarde Gmail en EML ou Google Takeout

Pour sauvegarder Gmail en .eml, utilisez Télécharger le message pour un e-mail individuel, ou archivez votre boîte mail avec une application de bureau qui enregistre chaque message en EML. Google Takeout est une autre solution de sauvegarde utile, mais son export utilise MBOX plutôt que des fichiers EML individuels. Choisissez le format nécessaire avant de commencer.

Enregistrer un message Gmail sans rien installer

  1. Ouvrez Gmail dans un navigateur sur ordinateur et ouvrez le message souhaité.
  2. Ouvrez le menu à trois points Plus du message, puis choisissez Télécharger le message.
  3. Conservez le fichier .eml téléchargé et ouvrez-le dans une application de messagerie de bureau pour vérifier son contenu. Répétez pour les autres messages nécessaires.

Ces étapes suivent les instructions de téléchargement des messages de Google. Cette option est pratique pour un reçu ou quelques messages importants ; la répéter pour toute une boîte mail prend du temps.

Sauvegarder toute une boîte Gmail en fichiers EML individuels

  1. Installez MailVault et ajoutez votre compte Google via la connexion Google. Examinez les autorisations demandées. Pour un compte professionnel ou scolaire, votre administrateur peut restreindre l’accès des applications tierces.
  2. Choisissez les dossiers ou libellés nécessaires. Incluez les messages envoyés et les anciens dossiers, pas seulement la boîte de réception. Vérifiez les réglages de visibilité IMAP de Gmail si un libellé manque.
  3. Ouvrez les opérations en masse, sélectionnez votre période, puis Archiver. Les e-mails sont enregistrés localement sans supprimer les copies du serveur. Commencez par une petite période pour vérifier le résultat.
  4. Attendez la fin de l’archivage avant de fermer l’ordinateur ou de commencer un nettoyage. Les comptes volumineux peuvent nécessiter plusieurs sessions à cause des limites de téléchargement du fournisseur.
  5. Ouvrez les réglages de stockage des e-mails de MailVault pour trouver votre coffre. Les messages archivés sont stockés en fichiers .eml dans une structure Maildir ; ne renommez ni ne déplacez les fichiers à l’intérieur du coffre actif. Ces indications sur la structure des fichiers concernent le format Maildir utilisé par défaut. Paramètres → Stockage propose aussi le stockage JMAP, qui conserve les octets des messages d’origine avec des enregistrements JSON et déduplique les messages identiques.

Vérifiez l’archive avant de vous y fier

  1. Passez la source des messages à Coffre, plutôt que Serveur ou Tout. Recherchez un ancien message que vous reconnaissez.
  2. Déconnectez-vous du réseau et ouvrez quelques messages archivés de différents dossiers et années. Ouvrez aussi leurs pièces jointes. Un objet dans une liste ne prouve pas que le corps du message est enregistré.
  3. Dans les réglages, ouvrez Sauvegarde et restauration et utilisez Exporter la sauvegarde. Choisissez un emplacement sur un second disque. Le ZIP contient le coffre, les comptes et les réglages ; il exclut les messages qui existent uniquement sur le serveur.
  4. Vérifiez que le ZIP s’ouvre, contient des fichiers .eml et inclut les dossiers que vous vouliez conserver. Pour les e-mails importants, testez la restauration d’une copie dans une installation distincte avant toute suppression.

Courte démo : créer une sauvegarde distincte de votre coffre

Démo avec des e-mails fictifs, montée à partir des enregistrements de démonstration macOS existants. La connexion au compte et certains préparatifs ont lieu hors champ ; il ne s’agit pas d’une connexion en direct à un fournisseur.

Lire la description de la démo

Une fois les messages archivés, choisissez un emplacement de sauvegarde et lancez la sauvegarde. L’enregistrement montre des e-mails fictifs et une destination préparée. Une seconde copie protège contre la perte de l’ordinateur ; les messages présents uniquement sur le serveur doivent d’abord être archivés.

Sauvegarde Gmail en EML ou Google Takeout

Utilisez EML pour obtenir des fichiers de messages individuels et une archive consultable avec recherche. Utilisez Google Takeout pour un export de compte préparé par Google. Les e-mails de Takeout sont en MBOX ; télécharger un ZIP de Takeout ne les transforme pas en EML. MailVault prend aussi en charge l’import MBOX dans Sauvegarde et restauration si vous avez déjà un export.

Ni le téléchargement des messages ni leur déplacement vers les archives de Gmail ne libère de l’espace. Pour en récupérer, lisez comment libérer de l’espace Gmail sans perdre d’e-mails après avoir vérifié les deux copies locales. Pour une comparaison plus large des formats, consultez télécharger tous les e-mails Gmail.

Téléchargez MailVault gratuitement pour créer votre première archive locale. L’archivage manuel est gratuit ; l’archivage automatique, les sauvegardes planifiées et Archiver et supprimer nécessitent Premium.
