Boîte Outlook.com / Hotmail pleine ? Voici la solution

6 min de lecture

Outlook.com (le nom actuel de ce qui s'appelait Hotmail) donne 15 Go de stockage aux comptes gratuits, partagés avec OneDrive. Une fois plein, le courrier entrant est rejeté et des avertissements de stockage apparaissent dans l'interface web comme dans les applications Outlook de bureau et mobiles. Le remède proposé par Microsoft est de vous vendre plus de stockage via un abonnement Microsoft 365 — mais si vous préférez régler le problème plutôt que louer de l'espace indéfiniment, voici le tableau complet.

1. Regardez où est passé votre stockage

Dans Outlook.com, allez dans Paramètres → Général → Stockage pour voir la répartition entre Courrier et OneDrive. Si OneDrive est le plus gros consommateur, faire le ménage dans le courrier n'aidera pas beaucoup — il faudra traiter les fichiers OneDrive à part. Si c'est le courrier, ce sont presque toujours les pièces jointes qui sont en cause, pas le texte des messages.

2. Videz les Éléments supprimés et le Courrier indésirable

Comme la plupart des fournisseurs, Outlook.com garde les messages supprimés dans le dossier Éléments supprimés jusqu'à ce que vous le vidiez, et ils comptent dans votre quota jusque-là. Faites un clic droit sur Éléments supprimés et Courrier indésirable dans la liste des dossiers et choisissez « Vider le dossier » pour récupérer cet espace immédiatement.

3. Triez par taille et évacuez les vieux messages lourds en pièces jointes

Utilisez la recherche d'Outlook.com avec hasattachments:yes et triez par taille pour trouver vos plus gros e-mails. Une poignée de vieux e-mails à grosses pièces jointes — PDF, vidéos, images disque — occupe en général bien plus de place que des milliers de courts messages texte réunis.

4. Demandez-vous si vous avez vraiment besoin de Microsoft 365

Microsoft 365 Basic démarre à un prix mensuel bas et regroupe 100 Go de stockage avec les applications Office, ce qui peut valoir le coup si vous vouliez déjà les applications. Mais si vous l'achetez uniquement pour régler une boîte pleine, vous payez un abonnement pour repousser un problème qui reviendra quand le nouveau quota, plus grand, sera plein à son tour.

5. Archivez en local, puis supprimez sur le serveur

L'approche qui rompt vraiment le cycle : téléchargez sur votre ordinateur une copie des anciens e-mails que vous voulez garder, confirmez qu'elle est complète, puis supprimez ces e-mails d'Outlook.com. Votre quota se libère durablement, et vous gardez chaque message, consultable et accessible hors ligne, sans frais récurrent pour conserver votre historique.

Outlook.com et Hotmail gèrent tous deux IMAP : n'importe quel outil d'archivage IMAP peut donc faire l'affaire. MailVault est une option gratuite et open source pour macOS et Linux : connectez votre compte Outlook.com ou Hotmail avec la connexion OAuth de Microsoft (sans bricoler de mot de passe), sélectionnez les dossiers voulus, et MailVault télécharge chaque message dans un fichier .eml individuel sur votre disque, organisé dans une structure Maildir standard. Une fois l'archive vérifiée — ouvrez quelques e-mails, contrôlez les pièces jointes, cherchez quelque chose dont vous vous souvenez — vous pouvez supprimer sans risque les originaux dans Outlook.com et récupérer votre quota.

L'archivage manuel est gratuit et illimité dans MailVault. Si vous préférez qu'il tourne automatiquement selon un calendrier plutôt que d'archiver par lots, c'est une fonctionnalité premium à $4/mois ou $25/an — 14 jours d'essai gratuit sur la formule annuelle.

Questions fréquentes

Combien de stockage gratuit Outlook.com offre-t-il ?

15 Go, partagés entre le courrier et OneDrive. Vous pouvez voir la répartition dans Paramètres → Général → Stockage.

Vider les Éléments supprimés dans Outlook.com libère-t-il de l'espace tout de suite ?

Oui. Contrairement à certains fournisseurs qui attendent un nombre de jours donné, vider à la main les dossiers Éléments supprimés et Courrier indésirable d'Outlook.com libère cet espace immédiatement.

Hotmail et Outlook.com, est-ce la même chose ?

Oui, en pratique. Microsoft a rebaptisé Hotmail en Outlook.com il y a des années ; les anciennes adresses @hotmail.com et @live.com fonctionnent toujours et utilisent le même stockage et les mêmes réglages Outlook.com.

Puis-je archiver mon courrier Outlook.com sans payer Microsoft 365 ?

Oui. Outlook.com prend en charge l'accès IMAP standard : n'importe quel outil d'archivage IMAP, y compris l'offre gratuite de MailVault, peut télécharger votre courrier en local sans aucun abonnement Microsoft 365.
