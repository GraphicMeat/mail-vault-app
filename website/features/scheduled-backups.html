Features/Scheduled backups

Scheduled backups Premium

Backups that run themselves.
So you never have to remember.

Set a schedule once and MailVault keeps your local copy current, then shows per folder how much is safely backed up.

Download MailVaultTry the live demo ↗

How it works

  • Your scheduleDaily, weekly or custom, per account, at the hours you pick.
  • Health checksServer, local and external counts per folder, so you can see what is actually safe.
  • Quiet hoursBackups run while the app is idle.

Premium. Part of MailVault Premium. See what Premium includes →
